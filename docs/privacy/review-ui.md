## 0. 한 줄 요약

높음 0 · 중간 4 · 낮음 10. 원문 대조는 상수·화면 모두 차이 0(새 문장은 묶음 3·4 보고서에 적힌 것뿐). 가리기(개정 4)·SQL 단계별 동작·관리자 화면·대비·넘침은 문제없음. **고칠 것**: 가입하지 않기 확인 창 뒤의 창이 눌리는 문제(M1)와 엑셀 파일을 바꿔도 보호자 동의 체크가 남는 문제(M2)는 코드 몇 줄이라 배포 전에 고치기를 권함. M3·M4는 사용자 결정이 필요(처리방침 시행(SQL ③) 전까지).
