## 새 문장(글자 그대로)

- ② 맨 앞 점검(지침 예문 그대로): `이메일 모양 아이디(또는 이메일로 스스로 가입한) 계정이 %개 있어 멈췄습니다. 이대로 ②를 실행하면 이 계정이 구글처럼 '인증 전'으로 묶여 기록 저장이 막힙니다. 이 메시지를 알려 주세요(아무것도 바뀌지 않았습니다).`
- ② 끝 점검(바꿈): `별명을 정하지 않았는데 이름이 구글이 준 이름 그대로인 구글 등 관리자가 %개 있습니다. 이 파일 전체를 되돌렸습니다 — 이 메시지를 알려 주세요.`
- `admin-create-member`·`import-users.mjs`: 새 문장 없음(기존 문구 재사용). 다만 기존 문구가 화면과 조금 다르다: 화면 `member-import.ts`는 "영문·숫자와", 함수는 "영문 소문자·숫자와". 함수가 화면보다 먼저 거부하는 일은 없다(화면이 먼저 거른다).

## 확인하지 못한 것 · 메인 에이전트께

- 실 DB에 이메일 모양 계정이 있는지는 모른다. 사용자가 `test-queries.sql` 2-2) 또는 ② 머리말 E)로 ② 전에 본다. **총괄이 실제 이메일 + 비밀번호로 로그인하는 계정이면 총괄도 여기서 세어져 ②가 멈춘다.** 그때는 따로 정해야 한다.
- 구글 이름이 가입 뒤 바뀌어 `raw_user_meta_data`와 지금 이름이 다르면 2-5가 이름을 바꾸지 않는다. 그 관리자는 확인 창에서 별명을 정할 때 바뀐다.
- `update … from member_directory, auth.users`, 맨 앞 점검의 `auth.identities` 읽기는 실제로 실행해 보지 못했다(SQL Editor = postgres라 읽을 수 있다고 봄 — `setup-owl-class.sql`도 `auth.users`를 읽음).
