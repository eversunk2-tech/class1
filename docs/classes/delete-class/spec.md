# 학급 삭제 (2026-10-22 사용자 요청 — "학급 정리 후에 학급 삭제(목록에서 완전 삭제)도 가능하도록")

> **사용자 승인(2026-10-22)**: 권한 = 그 학급 담임과 총괄, 과제·선생님 글은 학급과 함께 지우기, 화면 글은 아래 그대로("글은 이대로").
>
> 계획(Claude 작성). 사용자 확인 뒤 Build → Review → 커밋 → 비교 사진 → 배포. SQL은 새 파일(앞선 마이그레이션은 모두 실행됨 — 고치지 않음).

## 지금 상태 (저장소 SQL로 확인)
- `classes`를 가리키는 외래키: `class_teachers.class_id`(cascade), `class_notices.class_id`(cascade — 선생님 글), `profiles.class_id`·`member_directory.class_id`(set null), `assignments.class_id`(**restrict** — 과제가 있으면 학급을 못 지움). 과제를 지우면 제출물(`assignment_submissions`)은 cascade로 함께 지워진다.
- 학급을 지우는 기능은 없다(개설 `create_class`·이름 바꾸기 `rename_class`·보관 `archived_at`만). 학급 정리(`admin-clear-students`)는 학생 계정·기록만 지우고 "남는 것: 학급(이름), 선생님 글, 과제(내용), 선생님 계정"(처리방침 8-4).

## 하려는 것
1. **새 SQL** `supabase/migrations/20261022000000_class_delete.sql`(추가만 — 기존 정책·함수를 바꾸지 않음):
   - `admin_class_delete_preview(p_class_id uuid) → jsonb` — `{ class_name, students, assignments, notices }`(학생 = 그 학급 `class_id`인 프로필 전부, 탈퇴 처리된 학생 포함). 권한은 학급 정리와 같게: 그 학급 담임(`class_teachers`) 또는 총괄.
   - `admin_delete_class(p_class_id uuid, p_confirm_name text) → jsonb` — 같은 권한, 학급 이름(앞뒤 공백 뺌)이 맞아야 함, **학생이 1명이라도 있으면 거부**(먼저 학급 정리), 그 학급의 과제(→ 제출물)를 지운 뒤 학급을 지움(→ 담임 연결·선생님 글 cascade). `{ ok, assignments, notices }`. 학급 정리 기록(`class_cleanup_log` — 지운 인원수, 학급 이름 글자)은 남는다(외래키 없음).
   - `security definer`·`set search_path = ''`·`authenticated`만 실행, 재실행 안전, 맨 끝 자체 점검.
2. **화면**: 관리자 '내 학급' 카드의 학급마다 [학급 정리] 옆에 **[학급 삭제]**. 학생이 남아 있으면 단추를 끄고 까닭을 보인다. 학급 정리를 다 마친 창에도 **[이어서 학급 삭제]**. 확인 창은 학급 정리처럼 학급 이름을 그대로 입력해야 켜지는 빨간 단추. SQL 전(함수 없음)이면 단추를 숨긴다.
3. 문서: 처리방침 8-4의 "남는 것: 학급(이름), 선생님 글, 과제(내용), 선생님 계정"은 학급 정리만 했을 때의 사실이라 그대로 두고, 새 글(아래)은 원문 8-9로 더한다.

## 그대로 두는 것·알아 둘 것
- 선생님 계정은 남는다(담임 연결만 사라짐). 그 선생님이 먼저 맡은 다른 학급이 없으면 **자유게시판이 더 이상 보이지 않는다**(선생님이 쓴 글은 지우지 않고 남음 — 학생 글은 학급 정리 때 이미 지워짐). 다시 학급을 개설하면 그 게시판이 다시 보인다(게시판은 선생님 단위 — 09-28 담임교사별 게시판 설계).
- 학습게임 글·블로그 글은 학급과 상관없어 그대로.

## 화면 글(제안 — 사용자 확인)
- 단추: `학급 삭제` / 학생이 남았을 때 설명: `학생이 남아 있어요. 먼저 [학급 정리]를 해 주세요.`
- 확인 창 제목: `학급 삭제 — '{학급 이름}'`
- 본문: `이 학급을 목록에서 완전히 지웁니다. 이 학급의 과제 {n}개와 선생님 글 {m}개도 함께 지워져요. **되돌릴 수 없어요.**`
- 입력: `학급 이름을 그대로 입력해 주세요.` / 단추 `[학급 삭제]` `[취소]`
- 끝났을 때: `'{학급 이름}' 학급을 삭제했어요.`
- 학급 정리 끝난 창의 단추: `이어서 학급 삭제`
- 서버 거부(학생이 남음): `학생 계정이 {n}명 남아 있어요. 먼저 [학급 정리]로 학생 계정과 기록을 지운 뒤 학급을 삭제해 주세요.`
- 권한 없음: `이 학급의 담임 선생님이나 총괄 선생님만 학급을 삭제할 수 있어요.` / 이름 다름: `학급 이름이 맞지 않아요. 학급 이름을 그대로 입력해 주세요.`

## 배포 순서
SQL(사용자, SQL Editor) → 공개 키로 함수가 비로그인 거부인지 확인 → 화면 push(사용자 확인) → 사용자가 빈 연습용 학급으로 확인.
