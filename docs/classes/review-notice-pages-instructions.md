## 확인할 것
1. **요청대로**: 좌우 반씩일 때 오른쪽(접은 제목 + 쪽 넘기기) ≤ 왼쪽 '최근 과학 수업' 내용 높이, 다 들어가면 쪽 넘기기 없음, 넘치면 쪽으로, 쌓일 때 5개씩. 글 0·1·3·5·6·7·12·30·101개 × {1920×1080, 1440×900, 1280×800, 1180×820, 1024×768, 768×1024, 390×844, 375×812} × {사이드바 펼침·접힘}. 두 줄 제목 섞임, 아주 긴 제목(100자).
2. **빠지거나 겹치는 글 없음**: 모든 쪽을 넘겨 보면 글이 최신순으로 한 번씩만 보이는지(창 크기를 바꿔 다시 나눌 때도), 마지막 쪽.
3. **쪽 넘기기**: 마우스·터치·키보드, 초점이 누른 버튼에 남음, `aria-current`·`aria-label`·스크린리더 안내, 끝에서 꺼짐, 44px, 페이지 스크롤이 튀지 않음, 펼친 글은 쪽을 넘기면 접힘. 휴대폰에서 4쪽 이상이면 "2 / 6" 모양(Build가 정함 — 쓰기 좋은지 판정).
4. **다시 재기**: 창 크기·사이드바 접기·글꼴·왼쪽 내용 변화, `ResizeObserver` 반복 경고 없음, 처음 그릴 때 깜박임(나누기 전 모습이 보이는지), 보이지 않는 측정용 사본이 화면·스크린리더·Tab에 나오지 않는지, 성능(글 100개).
5. **그대로여야 할 것**: 불러오는 중·빈 목록·오류·잠금(로그인 안내) 화면, 날짜 없음, 본문 글자 그대로 + 주소 링크, 비로그인 = 총괄 글·학생 = 자기 반 글(가짜 RLS), 로그인 ↔ 로그아웃 전환 때 이전 목록을 치움, 홈 다른 칸과 배치.
6. 어두움, 움직임 줄이기, 가로 넘침 0, 콘솔 오류 0, 외부 요청 0. `npm run lint`·`npx tsc --noEmit`(사본에서).
