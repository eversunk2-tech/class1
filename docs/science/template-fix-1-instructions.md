# Build 서브에이전트 지침: 과학 앱 공통 틀 수정 1 (2026-09-23, 사용자 승인)

## 배경
2학기 2단원 리뷰에서 공통 틀(`scripts/templates/science-sim/`, `scripts/templates/class1-record.js`) 문제 4가지가 나왔다. 사용자가 **공통 틀 수정과 모든 앱 사본 동기화를 승인**했다(1학기 1단원 앱 포함).
**절대 조건**: 저장 키(`:vN`)를 올리지 않는다. 저장 구조(`app_progress.state`, `app_results.detail`/`detail.qa`)를 바꾸지 않는다. 학생의 진행 중 입력과 완료 결과가 그대로 남아야 한다. 모든 변경은 **하위 호환**이어야 한다(기존 앱 사본이 고친 틀로 그대로 동작).

## 고칠 것
1. **(가장 중요) 실험 도중 탭 전환·새로고침 뒤 "기록이 두 가지예요" 충돌 창**
   * 증상·원인: `public/apps/sci-6-2-2-4/fix-1-report.md`와 `public/apps/sci-6-2-2-4/review.md`(중간 2) 참고. 탭이 숨겨지면 `sim3d`가 애니메이션을 즉시 끝내고, 페이지를 떠날 때 보낸 저장(keepalive) **뒤에** `experiment.js`/앱 코드가 기록을 써서 로컬과 서버 내용이 달라진다. 다시 열면 `persist.js` reconcile이 "둘 다 바뀜"으로 보고 충돌 창을 띄운다.
   * 목표: 이런 **가짜 충돌**이 뜨지 않게 한다. 데이터 손실은 절대 금지, 진짜 충돌(다른 기기에서 진행)은 지금처럼 학생이 고르게 둔다.
   * 방향(택1 또는 조합, 근거를 보고서에 적을 것): ① 떠날 때 저장 이후의 쓰기를 막거나(숨김 상태에서 실험 진행·기록 중단) ② keepalive 저장 뒤 들어온 쓰기를 `dirty`로 확실히 표시하고, reconcile에서 **서버 내용이 로컬 내용에 그대로 포함될 때(로컬이 서버의 확장일 때)**는 충돌 창 없이 로컬을 올린다. 비교는 `canon()` 기준으로 키 단위 비교.
2. **확인하기 뒤 `기록하기` 버튼이 하단 단계 막대(`.ss-footer-nav`)에 가려짐** — 공통 틀에서 스크롤 여백(`scroll-margin-bottom`)이나 `main` 아래 여백을 주어 모든 화면에서 버튼이 막대 위에 보이게.
3. **휴대폰 가로(812×375 등)에서 공통 머리말이 화면을 거의 차지** — 화면 높이가 낮을 때(예: `@media (max-height: 480px)`) 머리말·진행바를 낮게(글자·여백 축소, 필요하면 접기).
4. **`SciSim.josa`가 숫자로 끝나는 말에 틀린 조사**("실험 1를") — 숫자 읽기의 받침을 따른다(1·3·6·7·8·0은 받침 있음, 2·4·5·9는 없음). 한글·숫자가 아닌 글자는 지금처럼 받침 없는 쪽.

## 절차
1. `scripts/templates/science-sim/**`와 필요하면 `scripts/templates/class1-record.js`를 고친다. README도 함께 갱신.
2. **모든 앱 사본에 복사**: `public/apps/sci-*/science-sim/`, `public/apps/sci-*/class1-record.js` (지금 17개 앱 모두 정본과 동일함). 복사 뒤 `diff -r`로 전부 일치 확인.
3. 회귀 점검(앱은 수정하지 않는다 — 틀 때문에 앱이 깨지면 틀 쪽을 고친다): 최소 5개 앱(`sci-6-1-1-1`, `sci-6-1-2-5`, `sci-6-2-1-2`, `sci-6-2-2-3`, `sci-6-2-2-4`)을 로그인 가짜 세션으로 **끝까지** 진행. 확인: 저장 키 그대로, 진행 저장·복원, 완료 저장(`detail.qa`) 모양 그대로, 콘솔 오류 0.
4. 1번 문제 재현 시나리오를 **고치기 전/후로 각각** 실행해 결과를 보고서에 적는다(실험 실행 중 탭 숨김 → 새로고침, 기록 직후 새로고침, 오프라인 후 복귀). 진짜 충돌(서버 기록을 다른 내용으로 바꾼 뒤 로컬도 바꿈)에서는 **여전히 충돌 창이 떠야** 한다.
5. 태블릿 가로·세로, 375px 세로, 812×375 가로, 다크모드에서 2·3번이 고쳐졌는지 확인(스크린숏 근거).
