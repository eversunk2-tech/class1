# Build 서브에이전트 지침: 마치기 조건 강화 (2026-09-23 사용자 요청)

대상: 과학 차시 앱 **전부**(실험 23개 중 sim 20개 + 조사 3개). 공통 틀 `scripts/templates/science-sim/`·`science-guide/`를 고치고 **23개 앱 사본에 동기화**(`diff -r` 확인). 앱 고유 파일(app.js·data/lesson-config.js)은 되도록 건드리지 않는다.

## 배경
지금은 정리하기(마지막 단계)에서 `ㄴㅇㄹㄴㄹㅎ`처럼 적으면 되짚기 카드가 뜨지만, 뒤에 단계가 없어 **'학습 마치기'가 그냥 눌린다**. 또 '더 탐구하고 싶은 점'이 선택이라 대부분 비워 둔다.

## 바꿀 것
1. **정리하기 답이 통과해야 '학습 마치기'가 된다.**
   * 마치기를 누르면 `SciSim.AnswerCheck`로 정리하기 답(결론)을 검사한다. **block 판정(무의미·주제 무관)이면 마치지 못한다.** 누른 사람에게 까닭과 무엇을 고쳐야 하는지 안내(6학년 말, 답 누설 금지)를 보여 준다.
   * rethink(틀렸지만 주제에 맞음)는 지금 규칙 그대로 — 질문당 한 번 되짚고, 그대로 두면 마칠 수 있다.
   * Gemini를 쓸 수 없으면(오프라인·한도·오류·시간 초과) **로컬 규칙의 확실한 무의미만** 막는다(지금 원칙 그대로).
   * 같은 질문에서 3번째 block부터는 "🙋 선생님과 확인했어요" 버튼으로 마칠 수 있다(기존 규칙과 같게).
2. **'더 탐구하고 싶은 점'을 필수로 바꾼다.**
   * 비워 두면 마칠 수 없다(안내 문구: 무엇을 적으면 되는지 예시 없이 짧게).
   * 검사는 **느슨하게**: 정답이 없는 질문이므로 **무의미한 글자·완전히 주제와 무관한 내용만** 막고 그 밖에는 모두 통과. 내용이 아쉽다는 이유로 되짚지 않는다(rethink 없음).
   * Edge Function `check-answer`도 이 단계용 느슨한 기준(판정 ok/block만, rethink 금지)을 받도록 고친다. 프롬프트에 "정답 여부를 따지지 말 것"을 분명히 적는다. **함수를 고치면 사용자가 다시 배포해야 하므로 보고서에 명시**한다(아직 한 번도 배포되지 않았을 수 있다).
   * 저장 구조(`detail.qa`)의 궁금한 점 항목 모양은 바꾸지 않는다(이제 항상 값이 있을 뿐).
3. **"제출" 안내를 눈에 띄게.**
   * 마지막 화면에 기본으로 보이는 안내: **"'학습 마치기'를 눌러야 선생님에게 제출돼요."** 버튼 옆·위처럼 놓치지 않는 자리에, 색만이 아니라 글자로도 구분되게. 이미 마친 뒤에는 "제출했어요" 상태를 분명히 보여 준다.

## 반드시 지킬 것
* 저장 키(`:vN`)·저장 구조(`app_progress.state`, `app_results.detail`/`detail.qa`)를 **바꾸지 않는다**. 예전에 저장된 기록도 그대로 열려야 한다.
* 학생이 갇히지 않게: 몇 번이든 고쳐 쓸 수 있고, 3번째 block부터 교사 확인 버튼, Gemini 장애 시 차단 없음.
* 7분 기준을 크게 넘기지 않게(검사 대기 시간 제한은 기존 값 유지).
* 체험 모드(잠금 꺼짐·비로그인)에서도 같은 규칙으로 동작하되, 서버 호출은 하지 않는다(로컬 규칙만).
* git 명령 금지, 실 DB·Storage 쓰기 금지, 실제 Gemini 호출 금지(가짜 응답), 자기 전용 headless 브라우저만, `localStorage.clear()` 금지.

## 검증
* 정리하기: 무의미 입력 → 마치기 거부, 딴 이야기(가짜 Gemini block) → 거부, 제대로 쓴 답 → 마치기 성공, rethink 뒤 그대로 제출 → 성공, 3번째 block에서 교사 버튼 → 성공.
* 궁금한 점: 비움 → 거부, `ㅇㅇㅇㅇㅇㅇ` → 거부, "집에 가고 싶다"(가짜 block) → 거부, 평범한 한 줄("왜 그런지 더 알고 싶다") → 통과.
* 로그인 학생은 `app_results` 저장이 예전 모양 그대로인지 확인. 체험 모드는 저장 호출 0건.
* 앱 최소 5개(sim 4 + guide 1), 태블릿·375px·다크·콘솔 오류 0, `npm run build`.
