1. **기록 뒤 자동 진행 0**: 조건마다 📝 기록하기 → 고른 조건·장면이 **그대로**, 다른 조건 선택·실행·재생이 **저절로 일어나지 않음**(`8f29ba0`에서는 공통 틀 `advance()`와 `sci-6-2-2-1`·`sci-6-2-2-4`의 `onRecorded`가 자동 선택). **공통 틀 변경(2026-09-27, 사용자 "모든 실험 앱")**: 정본 `experiment.js`·`style-common.css`·`README.md`를 Claude가 고쳐 20개 사본에 맞췄다 — 기록 뒤 다음 칸 조건 버튼에 `is-next` + "👉 다음"(단계 이름 뒤 " · ") — 알림(검은 바탕 알림)에는 다음 칸 안내를 넣지 않는다(사용자 "가운데 상단에 검은 배경으로 뜨는 알림 메시지에서 '다음 안내' 부분은 삭제해줘. 너무 길어지는 것 같아" — 알림 글이 예전과 같은지 확인), 학생이 그 칸을 고르거나 채워지면 사라짐, 같은 조건을 더 재야 하면 안내 없음. 이 동작이 네 앱에서 맞는지, 앱에 우회 코드(기록 뒤 방금 칸 다시 고르기)나 틀과 겹치는 다음 칸 안내가 남지 않았는지, 안내 알림이 사실만 말하는지. 모든 칸을 **직접 골라** 기록할 수 있는지. 표시의 모양(밝음·어두움·크게 보기 좁은 조작 칸·휴대폰)과 접근성(글자로도 알림, 움직임 없음).
2. **재생 연출**: 실행하는 동안 대상만 움직이고 측정 그림·값은 끝에 한 번(도중에 나타났다 다시 나타나지 않음) — 빨리 감기 바·초시계처럼 측정 과정 자체는 예외.
3. **관찰 글**: 보기를 고르기 전, 보기 바로 위 글·캡션·이름표·HUD에 **정답 보기와 같은 말이 보이지 않음**. 맞는 보기로 확인 → 실제 상태 글 드러남, **틀린 보기로 확인 → 계속 숨김**. 장면 자체의 대체 설명(`aria-label`·2D 설명)은 상태를 말해도 됨(접근성). **예외(사용자 결정 2026-09-27)**: `sci-6-2-2-2`의 '따뜻한 정도' 표시(불꽃 둘레 붉은 번짐 + "가까이 · 따뜻함 ●●●" / "멀리 · 따뜻함 ●○○")는 화면으로 볼 수 없는 현상을 알려 주는 관찰 수단이라 **그대로 둔다** — 발견으로 적지 말고, `8f29ba0` 판과 겉모양·문구·자리·나타나는 때가 같은지만 확인한다.
4. **장면 속 글자**: 바뀌는 값이 3D 이름표로 뜨지 않음, 3D 이름표가 장면 가장자리에서 잘리지 않음(`sci-6-2-2-3` 위쪽 이름표 — review-dock R1), 토글·장면 안 막대·드래그 안내 줄·이동 화살표(확대 뒤)와 앱 HUD·배지·이름표가 서로 가리지 않음(`sci-6-2-2-3` 휴대폰 기본 화면의 "⏩ 빨리 감기(모형)" 배지 ↔ 토글 — R2), `scenePanel`을 넘긴 앱은 막대 윗줄에 값이 맞게.
5. **직접 조작**: 3D 물체 누르기(마우스·합성 터치) = 버튼과 같은 결과(조건 카드 선택 표시·관찰 카드·저장값), 실행 중·고를 수 없는 때의 탭 무시, 짧은 탭 ↔ 돌리기 구분, 누를 수 있다는 안내. 특히 `sci-6-2-2-2` 관찰 항목 탭, `sci-6-2-2-4` 종이·석회수 병 탭(새로 넣은 것).
