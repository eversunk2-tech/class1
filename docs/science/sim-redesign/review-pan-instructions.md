# 검토 지침(Review pan) — 확대한 3D 장면 이동 화살표 (2026-09-26, spec 개정 8)

당신은 **Review** 담당이다. **코드를 고치지 않는다**(발견만 기록). 이 기능은 사용자가 직접 요청한 것이고, 검토·수정 뒤 사용자 확인을 받아 배포한다 — 학생에게 바로 보일 문제(화살표가 장면·버튼을 가림, 눌러도 안 움직임·반대로 움직임, 장면을 잃어버림, 돌리기·고르기·끌기가 망가짐, 콘솔 오류)를 가장 먼저 찾고, 배포를 막아야 하면 "높음"으로 분명히.

먼저 읽기: `CLAUDE.md`(과학 차시 앱 규칙 — "시점을 옮기거나 확대해도 방향이 뒤집히지 않게", "장면 속 글자", 서브에이전트 규칙), `docs/science/sim-redesign/spec.md` 끝의 **개정 8**(사용자 말 그대로 — 합격 기준), `pan-instructions.md`, **`pan-report.md`**(바꾼 것·수치·앱별 확인), 정본 README "추가 기능" 절, `git diff -- scripts/templates/science-sim/`(정본)과 20개 사본(`public/apps/sci-*/science-sim/` — 정본과 같아야 한다), 앱 `style.css`를 고쳤다면 그 diff.

## 사용자 요청(합격 기준)
"실험 화면을 줌인해서 원하는 부분만 확대했을 때, 상하좌우 원하는 곳으로 화면이동이 가능하면 좋겠어. 화면 상하좌우의 끝 쪽에 반투명한(실험 장면을 가리지 않는 수준으로) 화살표가 생겨서 그것을 누르면 누르는 만큼 화면에서 원하는 부분으로 이동이 되게 해줘"

## 확인할 것
1. **보이는 때**: 20개 실험 앱 × {1024×768, 1180×820, 768×1024, 810×1080, 1920×1080, 812×375, 375×812} × {기본 화면, 크게 보기} — 처음 시점에는 화살표 없음, 확대(휠·두 손가락에 해당하는 `controls` 확대)하면 4개가 장면 칸 가장자리 가운데에 나타남, "🎥 처음 방향으로"·두 번 탭 뒤 처음 시점 + 화살표 숨김. 2D 대체 화면(`?no3d=1`)에는 없음. 앱이 카메라를 옮기는 연출(`sci-6-2-3-3` 나침반 다가가기, `sci-6-2-1-5` 확대 화면, `sci-6-2-1-3` 남쪽 하늘 시점) 뒤에 화살표가 맞는 때에 나타나는지(연출만으로 "확대됨"으로 잘못 보여 장면을 가리지 않는지 포함).
2. **움직임**: ▲▼◀▶ 각 방향 한 번 누름 = 한 칸(화면 기준 — ◀를 누르면 장면의 왼쪽 부분이 보임, **좌우·위아래가 뒤집히지 않음**), 누르고 있으면 계속, 손가락을 떼거나 포인터가 벗어나거나 `pointercancel`·창 전환이면 **바로 멈춤**(멈추지 않고 계속 흘러가는 경우가 없는지 — 터치 흉내 `Input.dispatchTouchEvent`로도), 키보드 Enter/Space 한 칸. 한도에서 멈추고 장면을 잃어버리지 않음(끝까지 눌러도 실험 물체가 화면에 일부라도 남는지). 회전해 둔 상태에서 눌러도 화면 기준으로 움직이는지.
3. **새는 입력 없음**: 화살표를 누를 때 장면이 돌아가거나, 물체가 골라지거나(`onPick`), 더블탭으로 초기화되거나, 끌기(태양 `sci-6-2-1-2`·손전등 `sci-6-2-1-4`·지구본 `sci-6-2-1-5`)가 시작되지 않는지. 반대로 화살표 근처에서 장면 돌리기·확대·고르기·끌기가 전처럼 되는지.
4. **가림·겹침**: 화살표 ↔ "⛶ 전체 화면 보기" 토글·"모형" 배지·HUD(앱마다 다름)·드래그 안내 글·장면 안 막대(실행·기록하기·측정값)·앱 이름표(DOM)·알림 — 겹침 0(수치로). 반투명이 장면을 가리지 않는 수준인지(밝음·어두움 스크린숏), 누르는 곳 44px 이상, 초점 표시, `aria-label`, 대비.
5. **흐름**: 앱 6개 이상(`sci-6-2-3-3`, `sci-6-2-1-5`, `sci-6-2-1-2`, `sci-6-1-1-1`, `sci-6-2-2-3`, `sci-6-1-2-4`)에서 확대·이동한 채로 고르기 → 실행 → 관찰 → 기록 → 표에 들어감, 크게 보기 켜고 끄기·방향 바꾸기·창 크기 바꾸기(`resize`) 뒤에도 화살표 상태가 맞는지.
6. **회귀 없음**: 화살표를 뺀 요소 위치가 커밋 `08f2fa8` 사본(`git archive 08f2fa8 public`을 스크래치에 풀어 자기 서버 8797로)과 같은지 — 앱 6개 이상 × 1024×768·768×1024 × 두 모드, `getBoundingClientRect` 비교. 처음 시점의 3D 그림(스크린숏)도 같아야 한다. **단 `sci-6-2-1-3`은 다른 작업(fix-2 — 위선 삭제·태양 고도 그림, 사용자 요청)이 `app.js`를 동시에 고치고 있어 3D 그림이 `08f2fa8`과 다를 수 있다** — 이 앱은 그림 비교에서 빼고(요소 위치만), 그 차이는 발견으로 적지 않는다.
7. **성능·정리**: 누르지 않을 때 `requestAnimationFrame` 반복이 돌지 않는지(배터리), 앱을 떠나거나 단계를 바꿀 때 누름 상태가 남지 않는지, 이벤트 처리기가 겹겹이 붙지 않는지(크게 보기 여러 번 켜고 끄기 뒤).
8. `diff -r` 정본↔20개 사본(조사 앱 3개 `science-guide`는 대상 아님 — 바뀌지 않았는지), `npm run lint`, `node --check`(바뀐 JS), `git diff --check`, 임시 코드·`console.log`·`debugger`·`localStorage.clear()` 없음, README가 기능을 맞게 설명.
