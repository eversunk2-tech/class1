# 크게 보기 개편 보고서(dock) — "장면 + 옆 조작 칸" 한 화면 실험실 (2026-09-26)

지침: `dock-instructions.md`(spec 개정 6). 정본 `scripts/templates/science-sim/`을 고친 뒤 실험 앱 20개 `science-sim/`에 복사했고, 앱 파일은 필요한 6개 앱(2-1-2·2-1-3·2-1-4·2-1-5·2-2-2·2-2-3)만 최소로 고쳤다. **`sci-6-1-1-1`~`-4`의 앱 파일은 건드리지 않았다**(사본 동기화만). 측정 조건·값·문항·저장 키·`detail`·과학 색은 그대로. git commit/push·실 DB 쓰기·`npm run build`·내려받기 안 함.

## 0. 요약
* 크게 보기를 켜면 실험 영역이 **머리말 아래~아래 이동 막대 위 화면 전체에 고정**되고, 그 안에 **장면 + 조작 칸**(기본 화면 오른쪽 패널 그대로)이 겹치지 않게 놓인다 — 가로 화면은 조작 칸이 **오른쪽**, 세로 화면은 **아래**(장면 칼럼 60%). **페이지는 스크롤되지 않고**(scrollTop 늘 0) 조작 칸만 그 안에서 스크롤된다.
* '실험 방법 알아 두기'·안내 줄(+ 2-2-2·2-2-3의 안전 안내)은 조작 칸 맨 위로(접기 상태 그대로), 모형 설명은 맨 끝으로, 관찰 카드는 원래 순서(조건 카드 다음). 실행 뒤에는 **조작 칸 안에서만** 관찰 카드가 보이게 스크롤. 장면 안 막대(측정값·실행·기록하기)는 그대로.
* 20개 앱 × 8크기 새 크게 보기: 띠 채움·겹침 0·페이지 스크롤 0·가로 스크롤 0·콘솔 오류 0 **160/160**(휴대폰 가로 2개 앱의 조작 칸 안 가로 넘침은 고쳐 다시 확인). 머리말 접힘·어두움·2D도 통과. 기본 화면(끔)은 커밋 `9d2dc16`과 **요소 위치 차이 0**.
* 앱 수정: `sci-6-2-1-2`(시간 바·측정값 카드를 조작 칸으로), `sci-6-2-2-2`·`sci-6-2-2-3`(시간 바 카드를 조작 칸으로), `sci-6-2-1-5`(관찰 카드 숨김 규칙 되돌림), `sci-6-2-1-3`·`-4`·`-5`·`-2`(2D 칸 맞춤 정리) 등.

## 2. 걷어 낸 것
* `enlarge()`의 페이지 맞춤: `fit()`의 `--ss-scene-h` 계산(`MIN_SCENE_H`·`SCENE_GAP`·`sceneShare`), `resize`·방향 감시로 다시 맞추기, 머리말·아래 막대 `ResizeObserver`, 켤 때 `scrollIntoViewSafe(장면)`, 관찰 카드를 패널 맨 앞으로 옮기기(`observe` 옵션은 받아도 무시).

* 앱 CSS: 2-1-5 가로 크게 보기 관찰 카드 숨김, 2-1-2·2-1-3·2-1-4·2-1-5의 vh 기준 크게 보기 2D 최대 높이(fix-B) → 칸 맞춤으로 교체.
