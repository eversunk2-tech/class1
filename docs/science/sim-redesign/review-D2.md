## 3. 확인 항목 1~13

1. **기록 뒤 자동 진행 0 — 합격.** 세 앱 모든 칸에서 기록 뒤 고른 조건·장면·실행 버튼 글자 그대로(6-2-3-3 실험 1은 "🔌 스위치 열기" 그대로), 다음 칸 버튼에 "👉 다음"(6-2-3-1 (가)→(나)…금속, 6-2-3-2 전구→전동기→버저, 6-2-3-3 스위치→전지 1개→…→바꾼 뒤 오른쪽 — 교과서 순서, `suggestNext` 안 씀). 알림은 "📝 기록했어요: …" 또는 단계 완료 "이제 ○○이 열렸어요"(전부터 있던 틀 문구)뿐. 전 판은 매번 저절로 다음 칸(쌍 631-2).
2. **재생 연출 — 합격.** 6-2-3-3 실험 2 상태 표시: "스위치를 닫아요" → "스위치: 닫힘 · 전지 2개" → 끝에 한 번 "붙은 고리: 8개"(중간 숫자 없음). 6-2-3-1은 손잡이·막대만 움직이고 불·흐름 화살표(모형)는 끝에. 6-2-3-2는 손잡이만 움직이고 끝에 두 회로가 켜짐(측정 그림·값 없음).
3. **관찰 글 — 합격(L1).** 보기 고르기 전 글은 중립(6-2-3-1 "👀 스위치를 닫은 뒤 장면에서 전구를 살펴보세요.", 6-2-3-2 "👀 두 회로의 ○○을 비교해 보세요.", 6-2-3-3 사진 설명 "스위치를 열었을/닫았을 때의 실험 화면(모형)", 상태 표시 "🔌 스위치: 열림/닫힘"), 틀린 보기 → 계속 숨김, 맞는 보기 → "본 모습: …" 드러남. 장면 위 글(6-2-3-1 "🔌 스위치를 닫았어요", 2D "② 스위치를 닫았어요. 전구를 잘 살펴보세요.")도 결과 없음. 결과는 캔버스·2D 그림 `aria-label`에만(허용).
4. **장면 속 글자·겹침 — 태블릿 합격(L2·L7·L8).** 태블릿 4크기 × 크게 보기·기본 × 장면 3개(처음·실행 뒤·실험 2/버저/나침반)에서 3D 이름표 잘림·가림 0, DOM 겹침 0 — 예외는 L2(6-2-3-2 버저 소리 나는 동안 세로 태블릿). 나침반 다가간 화면의 ▲ ↔ 이름표: 전 판 768×1024 900px²·810×1080 622px²·'전자석' 잘림 → 지금 0(쌍 633-3).
