## 1. 요약
* 장면을 **나무(모형, 높이 10 cm) + 작은 사람(장식) + 백엽상**으로 새로 만들었다. 해·빛줄기 8개·모든 그림자·그림자 끝·그림자 길이 선·작은 호·햇빛 조명을 **태양 방향 벡터 d 하나**(`applySun(d)`)에서 계산한다 — 12개 시각에서 어긋남 0(각도 오차 ≤ 0.000001°).
* **태양 끌기**(마우스·터치) ↔ 시간 바·눈금 버튼 양방향, 놓을 때 ±3분이면 눈금에 맞춤, 끄는 동안 카메라 고정. 하늘의 시각 점 누르기, 2D에서도 해 끌기.
* 측정값(시각·태양 고도·그림자 길이·기온) + 📝 기록하기를 **`scenePanel`**로 넘겨 크게 보기에서는 장면 안 막대에서 기록한다(review-A2 N1 해소: 세로 태블릿 기본 크게 보기에서 기록하기가 첫 화면 안). 3D 값 이름표 3개·각도기·실·자는 없앴다.
* 측정 조건·값·문항·저장 키(`sci621sim2:v1`)·`detail`/`detail.qa` 모양은 그대로(가짜 로그인으로 실제 저장 요청 본문까지 확인).

## 2. 바꾼 것
**장면(3D, `app.js` build3D)**
* 땅(모래색 원판 + 잔디 무늬), 나무 = 줄기 + 원뿔 3단(저폴리곤, 꼭대기 y = 10). 원뿔마다 높이/반지름 > tan 51.7°라 **그림자의 가장 먼 끝 = 나무 꼭대기의 그림자**(확인: 나무 그림자 최원점 = 10 ÷ tan 고도, 12개 시각 모두).
* 작은 사람(높이 3.7, 노란 모자) · 백엽상(다리·비늘살 상자·지붕, 문은 북쪽으로 열림, 속에 15~30 °C 눈금 온도계 + 빨간 액주 — 기온 숫자는 패널에만). 두 물체 자리는 9:30~15:30 1분 간격 계산으로 나무 그림자·옅은 빛줄기와 1.8 이상 떨어지게 골랐다.
* 하늘(모형)은 **나무 꼭대기를 중심으로 한 반지름 16의 반구** → 해 = 꼭대기 + 16·d, 해 중심·나무 꼭대기·그림자 끝 P = 꼭대기 − (10/d.y)·d가 한 직선(audit의 "태양 위치와 빛줄기 시작점 기준이 다름" 제거).
* 빛: 옅은 빛줄기 7가닥(모두 d와 평행, 하늘 쪽은 투명하게 사라짐, 그림자 끝 옆 ±4.5·±9, 끝 너머 4, 1.3배 거리 ±6에 닿음) + 나무 꼭대기를 지나 그림자 끝에 닿는 **또렷한 주황 빛줄기 1개**.
* 그림자: 물체 조각마다 꼭짓점을 d 방향으로 땅에 투영한 볼록 껍질(나무 4조각·사람 3·백엽상 7). 같은 물체 조각이 겹친 곳이 두 번 어두워지지 않게 조각마다 높이를 0.02씩 달리해 깊이 검사로 한 번만 그린다(polygonOffset은 swiftshader에서 얼룩이 생겨 쓰지 않음).
* 그림자 길이 선(밑동→P, 초록 + 흰 테두리)·그림자 끝(초록 점 + 흰 고리)·**작은 호**(빨강, 반지름 3.1 < 나무 키의 1/3, 땅 방향과 빛줄기 사이, 각 = asin d.y).
* 3D 글자는 안 바뀌는 것만: 동·서·남·북, 매시 30분 시각(해가 그 점에 있으면 잠시 숨김), "나무(모형) 높이 10 cm"(꼭대기 오른쪽 — 빛줄기가 늘 꼭대기 위·아래로만 지나가 가리지 않음), "백엽상(속에 온도계)". "태양" 이름표는 뺐다(해가 경로 이름표를 덮던 것 방지).
* 처음 시점: 북쪽에서 동쪽으로 14°, 높이 26°(왼쪽 동·오른쪽 서). 폭 480px 미만(휴대폰)은 조금 멀리·오른쪽으로 옮긴 틀(왼쪽 위 버튼 자리를 피함). 카메라가 스스로 움직이는 곳은 없다(처음 방향으로·두 번 탭만 — 방향 뒤집힘 없음).

**조작·표시**
* `v.draggable(sunMesh)`: 포인터 레이에 각도로 가장 가까운 하루 경로의 분 → `setMinute()`(시간 바와 같은 길). 6px 움직이기 전에는 시각을 바꾸지 않음(누르기만 해도 튀지 않게). 하늘 시각 점·이름표는 `pickable` → 그 시각으로 1초 빨리 감기. 시간 바 놓을 때 눈금 맞춤도 같은 `snapToTick()`.
* 측정값 패널: `scenePanel = .vals-scene`(값 4칸 + 기록하기 + 안내 한 줄). 원래 자리는 측정값 카드 안 — 앱은 카드만 옮기고(가로 좌우 배치면 오른쪽 패널 맨 위, 그 밖은 시간 바 아래) scenePanel 노드는 공통 틀만 옮긴다(예전 `vp`를 matchMedia로 옮기던 코드 정리). 크게 보기 동안 카드에는 출처 줄·남중 안내만 남아 한 줄 글로 보인다.
* 기록 알림을 짧게("📝 10:30 기록: 43.5° · 10.5 cm · 23.0 °C") — 태블릿에서 한 줄(51px)이라 머리말을 접어도 장면과 겹침 0(fix-A의 이 앱 5,396px² → 0).
* 2D: 위 = 남쪽 하늘(해 끌기·시각 점 누르기, 시각 글자는 점 아래·지금 시각은 숨김), 아래 = 나무와 그림자 옆모습(나무·사람과 각 그림자, 빛줄기·평행 빛줄기 3, 치수선, 그림자 끝, 호) + 백엽상 속 온도계. 바뀌는 값 글자는 그림에 없음(화면 읽기용 설명에만).
* `lesson-config.js`: `intro`(측정기 막대기 → 나무 10 cm, 호·그림자 끝 설명, 해 끌기)와 `modelNote`만 바꿈(글 약 110자 늘어남). 다른 13개 설정 값은 예전 파일과 같음(비교 스크립트).
* `style.css`: 막대 안 측정값 모양, 2D 새 모양, 휴대폰 장면 240→270px, 2D 높이 조금 낮춤(토글 때문에 늘어난 2D 위 여백 보정), 휴대폰 빨리 감기 배지를 위쪽 줄로(오후 해를 가리지 않게).

## 7. 공통 틀에 필요했던 것(고치지 않음 — 제안)
1. **좁은 화면 크게 보기의 값 카드 자리**: `.ss-scene-panel-card`가 패널 맨 앞이라, 1열 배치에서 앱이 장면 아래 붙인 카드(시간 바)·보기 도구·모형 설명 **뒤**에 온다 → 휴대폰 크게 보기에서 값·기록하기가 장면에서 멀다. `scenePanelAfter: node` 같은 자리 옵션이나 "장면 칸 바로 뒤" 기본값 제안.

3. 좁은 화면 3D 안내 글에 붙는 " · 페이지를 위아래로 움직일 때는 3D 화면 바깥을 밀어요"가 2~3줄이 되어 270px 장면 아래쪽을 많이 쓴다(짧게 하면 좋음). 2D 위 여백 98px는 2D 그림이 가운데 좁게 놓일 때는 빈칸이 된다(이 앱은 2D 그림 높이를 조금 줄여 맞춤).
4. review-A2 L1(알아 두기가 펼쳐진 채 들어오면 막대가 첫 화면 밖)은 그대로 — 학생이 한 번 내리거나 접으면 된다.
