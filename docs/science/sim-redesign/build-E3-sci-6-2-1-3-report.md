  * '비우고 마치기' 사진은 전·후가 같다(둘 다 막음).

## 2. 저장 — `detail.qa` 전·후
* **가짜 로그인으로 처음부터 끝까지**(768×1024, 같은 입력): 예상 → 12달 → 분석 → 정리 → 비우고 마치기(막힘) → 알맞은 글 → 마침.
* 전·후의 `app_results` POST 본문은 **두 곳만** 다르다.
  * `details.qa[5].label`: "궁금한 점(선택)" → "궁금한 점"
  * `details.qa[5].question`: "더 알아보고 싶은 점이 있다면 한 줄로 적어 보세요. (비워 두어도 마칠 수 있어요)" → "이번 실험을 하고 나서 더 탐구하고 싶은 점이나 궁금한 점을 한 줄로 적어 보세요."
* 그대로인 것:
  * 궁금한 점 항목의 `stage` "conclude"·`id` "curiosity"·`kind` "text"·`answer`
  * `qa` 6항목 순서, `detail` 키(predict·hintsOpened·source·records·analysis·conclusion·curiosity·qa), `detail.curiosity`
  * 마지막 `app_progress` state(시각 뺌, 차이 0), 진행 저장 횟수(17/17), 로컬 키
* 정리하기부터 한 가짜 로그인 흐름(1024×768: 비우기 → "ㅋㅋㅋ" → 주제 무관 → 알맞은 글)도 같은 결과다.
* **선생님 화면**(`node_modules/jiti`로 `extractResponses`·`groupByStage`, 스크래치에서만):
  * 매핑 파일이 없어서 두 판 모두 `source=qa`, 6항목, extras 0이다.
  * 묶음: [예상하기] [실험하기 — 12행 표] [기록·분석하기 2] [정리하기 = 결론 + 궁금한 점].
  * 이름은 전 "궁금한 점(선택)", 후 "궁금한 점"이다.
  * '질문별 보기'는 문구까지 보고 같은 질문을 묶는다(`questionIdentity`). 그래서 옛 결과와 새 결과의 궁금한 점은 **두 질문으로 따로** 나온다. 결론은 한 질문으로 묶인다(`sci-6-2-3-2` 때와 같은 방식).

## 6. 참고 — 범위 밖이라 고치지 않은 것
* **R1(공통 틀 `lesson.js:451-467`)**: 체험 모드에서 **정리하기 단계에서 새로 고침**하면 마치기 칸 아래에 "로그인이 풀렸어요. 다시 로그인하면 이어서 하고 결과도 저장돼요."가 나온다.
