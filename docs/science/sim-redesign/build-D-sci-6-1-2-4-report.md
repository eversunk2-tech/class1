* **2D**: 위 8번. 3D ↔ 2D 4번 전환: 캔버스 늘 1개 이하, 크게 보기 2D 초시계 칸 오른쪽 위(위·오른쪽 11px), 다시 3D에서 둘레 바닥 누르기 됨, 오류 0.

## 5. 탭 고르기(`lib/taps.mjs` 12항목, `lib/taps2d.mjs` 8항목)
처음 안 고름 → 초록 몸체 = 초록(조건 버튼 눌림·바닥 고리·실행 버튼 글) → 노랑 **둘레 바닥**(몸체 밖, 레이가 투명 판에 먼저 맞음) = 노랑 → 빈 트랙(둘레 밖) = 그대로 → 초록 둘레 바닥 = 초록 → 실행 중 노랑 = 무시 → 관찰 카드 → 같은 자동차 몸체·둘레 바닥 = **카드 유지** → 노랑 몸체에서 90px 끌기 = 돌리기만 → 빈 곳 두 번 탭 = 처음 방향·고르기 없음·카드 유지 → 관찰 중 노랑 둘레 바닥 = 노랑(버튼처럼 카드 닫힘).
* **3D 120/120**: 1024×768 크게 보기·기본(마우스), 768×1024 크게 보기·기본(터치), 1180×820(마우스), 810×1080(터치), 375×812·812×375 크게 보기·기본(터치). 전(`8f29ba0`)은 둘레 바닥 누르기가 없다.
* **2D 48/48**(1024×768·768×1024 크게 보기·기본, 375×812·812×375 기본): 차선 누르기 = 그 자동차, 실행 중 무시, 관찰 중 같은 자동차 차선·버튼 = 카드 유지, 다른 자동차 버튼 = 전환, 키보드 Enter = 고르기. 812×375 크게 보기 2D는 7/8 — 칸 안을 굴리면 2D 그림이 왼쪽 위 토글 밑을 지나가 버튼 가운데를 누르면 토글이 눌림(HEAD 틀 사본도 같음 — 아래 8-1).

## 8. 공통 틀에 알릴 것(고치지 않음)
1. **크게 보기 2D를 칸 안에서 굴리면 그림이 왼쪽 위 토글 밑을 지나간다**(토글은 장면 칸 위에 고정, 2D는 칸 안에서 스크롤) — 휴대폰 가로 크게 보기(기본 끔)에서 버튼이 토글 밑에 오면 토글이 눌린다. 모든 앱 공통.
2. **터치 보정**: 휴대폰 세로 크게 보기(기본 끔)에서 토글 바로 아래(약 6px)를 손가락으로 누르면 브라우저(Chrome 터치 보정)가 토글로 옮겨 눌러 크게 보기가 꺼졌다(시험에서 확인). 토글 아래 몇 px 여백이나 휴대폰 크게 보기 정리(review-dock L4)와 함께 보면 좋음.
3. (review-D1 L2와 같음) 조작 칸의 조건 버튼은 **이미 고른 자동차를 다시 눌러도** 관찰 카드를 닫는다 — 이 앱은 3D·2D 누르기에만 앱 가드를 두었다. 공통 틀 `pick`/`select`가 "같은 선택이면 아무것도 안 함"이면 모든 앱이 같아진다.
