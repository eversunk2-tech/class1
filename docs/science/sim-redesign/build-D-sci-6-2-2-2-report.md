## 8. 공통 틀에 필요했던 것(고치지 않음)
1. **`experiment.js` 기록 뒤 자동 선택**(`advance()`, 단계를 마쳤을 때 다음 단계 첫 칸 고르기) — 이 앱도 해당(실험 단계가 하나뿐이라 `advance()`만). 공통 틀에서 없앨 예정(Claude 알림). 스크래치 사본으로 `advance(s, p)` 한 줄만 빼 보니(Claude의 정본 수정 전 흉내) 이 앱은 기록 뒤 조건·장면(따뜻한 정도 표시 포함) 그대로이고 저장 본문도 같았다. 이 앱의 알맞은 안내 순서는 같은 물질의 다음 관찰 항목(불꽃의 모습 → 따뜻한 정도 → 그 밖에 관찰한 것, 불이 붙은 채 이어서)이라 새 `suggestNext`를 쓸지 Claude가 정하면 된다(기본 규칙이면 다른 물질의 같은 항목을 안내).
2. (낮음) `sim3d.js` 탭 고르기는 숨긴 물체도 맞힌다(three.js Raycaster는 `visible`을 안 봄) — 이 앱은 숨은 빛 번짐 판이 불 붙기 전 양초 둘레 10×10을 가로챘다. `draggable`처럼 숨긴 물체(자신·조상 `visible === false`)는 건너뛰면 앱마다 막을 필요가 없다.
3. (낮음) 같은 조건을 다시 골라도(`pick`·`select` → `afterSelect`) 관찰 카드가 닫힌다 — 관찰 중 장면을 누르면 결과를 잃음. 이 앱은 앱에서 막았다(`pickFrom`). 공통 틀 `ctx.onPick`에서 선택이 안 바뀌면 무시하면 20개 앱에 같이 적용된다.
4. (낮음, 새 안내와 관련) 알림(`.ss-toast`)이 `left: 50%`라 폭이 화면 절반으로 줄어 태블릿 세로(768)에서 약 344px보다 긴 알림은 두 줄 → 크게 보기(머리말 접힘)에서 장면 위쪽을 약 23px 덮는다(§5). 정본에 넣는 중인 알림 끝 " · 👉 다음: ○○"가 붙으면 이 앱의 "📝 기록했어요: 알코올 · 그 밖에 관찰한 것 · 👉 다음: …"은 태블릿 세로에서 두 줄이 된다. `left: 0; right: 0; margin: 0 auto; width: max-content`면 `max-width: min(92vw, 520px)`까지 한 줄.
