# Build 서브에이전트 지침: 디자인 개편 1단계 — 토큰·글꼴·사이드바·머리말·홈 (2026-09-24 사용자 승인)

설계: `docs/design/redesign/spec.md` — **끝의 "개정 1"이 열린 질문보다 우선**. `CLAUDE.md`(정적 export 제약, basePath 규칙)도 읽는다.

## 이번 단계 범위 (spec §9의 1단계)
1. **디자인 토큰**(spec §1): `src/app/globals.css`에 새 보라 `--primary`, 배경 그라데이션, 메뉴별 카드 그라데이션 토큰, 반경·그림자·글자 크기 단계. 밝은/어두운 모드 둘 다. 기존 토큰 이름은 유지하고(다른 화면이 깨지지 않게) 대응표대로 값·추가 토큰만 바꾼다.
2. **글꼴**(spec §2 + 개정 1): 본문 Pretendard를 npm 패키지 `pretendard`로 자체 호스팅(설치 허락됨 — `npm install pretendard`, `package.json`·lock 갱신 OK). 정적 export에서 동작하는 방식(`next/font/local` 또는 CSS import, basePath 문제 없는지 확인)으로, 필요한 굵기만. 제목 Jua는 지금 방식 유지. 한글이 실제로 Pretendard로 그려지는지 브라우저에서 확인(계산된 글꼴 확인).
3. **사이드바·머리말**(spec §4.1·4.2): 새 디자인. 메뉴 아이콘은 `public/illustrations/3d/*.webp`(이미 있음, 새로 받지 말 것) — `withBasePath()`로 경로. 활성 항목 구분은 배경·글자 굵기(색만으로 구분 금지).
4. **홈**(spec §4.3 + 개정 1): 히어로(Display 제목, 핵심 낱말 색 강조, 설명, 보라 알약 CTA **"오늘의 과학 탐구 시작하기" → `/science/`**, 오른쪽 `public/illustrations/mascot/owl-wave.webp`), 기능 카드 3개(그라데이션 + 3D 아이콘 + 동그란 화살표 버튼), 정보 카드 줄(3D 아이콘 칩). 첫 화면 마스코트만 `loading="eager"`, 나머지 이미지는 lazy, 모든 `<img>`에 `width`/`height`와 `alt`(장식이면 `alt=""` + `aria-hidden`).
5. 로그인 잠금 상태의 홈 안내 카드("로그인하면 볼 수 있어요")도 새 디자인에 맞춘다(기능은 그대로).

## 하지 말 것
* 참고 사이트(똑똑! 수학탐험대)의 그림·로고·문구·캐릭터를 가져오지 않는다. 느낌만.
* 이번 단계 밖의 화면(과학수업·게시판·게임·글·로그인·내 학습·관리자)은 **토큰 변경으로 자연히 바뀌는 것 외에** 손대지 않는다. 다만 토큰 변경 때문에 그 화면들이 깨지면(대비 부족·겹침) 고치고 보고한다.
* 과학 앱(`public/apps/**`, `scripts/templates/**`)은 건드리지 않는다(3단계).
* 이미지를 새로 내려받거나 만들지 않는다(마스코트·아이콘은 준비돼 있음).
* 서버 기능 금지(정적 export), 절대경로 하드코딩 금지.
* git 명령 금지, 실 DB 쓰기 금지, 자기 전용 headless 브라우저(자기 포트)만, `localStorage.clear()` 금지.

## 검증
* `npm run lint`, `npx tsc --noEmit`, `npm run build` 통과.
* 화면: 1440×900, 태블릿 1024×768·768×1024, 휴대폰 375×812 — 밝은/어두운 모드. 가로 스크롤 0, 콘솔 오류 0.
* 글자 대비 WCAG AA(본문 4.5:1, 큰 글씨 3:1) — 특히 그라데이션 카드 위 글자, 보라 버튼 글자, 다크모드.
* `prefers-reduced-motion`에서 움직임 꺼짐, 키보드 초점 보임.
* 다른 화면(과학수업·게시판·게임·로그인·관리자) 한 번씩 열어 토큰 변경으로 깨지지 않았는지.
* **스크린숏**을 스크래치 디렉터리에 남긴다(홈 1440 밝음/어두움, 768 세로, 375) — Claude가 사용자에게 보여 준다. 파일 경로를 보고서에 적는다.
