# Build 지침: 1단계 보강 — 홈을 "더 화려하게" (2026-09-24 사용자 요청)

1단계 결과를 본 사용자가 **"더 화려하게"**를 골랐다. 참고 사이트(똑똑! 수학탐험대)의 풍성한 느낌에 더 가깝게 홈을 다듬는다. **그 사이트의 그림·문구·캐릭터는 여전히 가져오지 않는다.**

## 새로 준비된 3D 소품 (Claude가 받아 둠 — 새로 받지 말 것)
`public/illustrations/3d/`에 추가: `star.webp`, `sparkles.webp`, `planet.webp`, `rocket.webp`, `light-bulb.webp`, `atom.webp`(보라 네모 배지 모양이라 떠 있는 소품보다는 배지·칩에 어울림), `magnet.webp`, `microscope.webp` (각 192px). 라이선스 파일은 이미 있음(`LICENSE-fluent-emoji.txt`, 같은 출처).

## 바꿀 것 (홈 중심, 공용 컴포넌트는 다른 화면이 깨지지 않게)
1. **첫 화면(히어로)**
   * 배경: 하늘색 대신 **흰색 → 연보라** 그라데이션 + 흐린 보라·분홍·하늘 빛 번짐(블러 원) 2~3개. 테두리는 아주 옅게.
   * 부엉이(`owl-wave.webp`)를 **지금보다 크게**(데스크톱에서 히어로 높이의 90% 안팎), 발밑에 부드러운 보라 빛 원판(글로우)을 둔다.
   * 부엉이 주변에 **떠 있는 3D 소품 4~5개**(별·반짝이·행성·로켓·시험관 등)를 크기·기울기를 달리해 배치하고, 천천히 위아래로 떠다니는 애니메이션(각기 다른 속도·지연). `prefers-reduced-motion: reduce`면 움직임 없음. 소품은 장식용(`alt=""`, `aria-hidden`), lazy가 아니라 히어로와 함께 로드되지만 용량이 작다.
   * 제목: 더 크게(데스크톱 Display), 핵심 낱말("배움터")은 보라 그라데이션 글자 + **형광펜 밑줄**(연노랑 반투명 띠). 한 낱말 더 강조해도 좋다(예: "함께").
   * 설명 아래 버튼 2개: 주 버튼 "오늘의 과학 탐구 시작하기"(보라 그라데이션 알약, 그림자, 올리면 살짝 떠오름) + 보조 버튼(흰 알약, 예: "자유게시판 구경하기" → `/board/`).
   * 휴대폰·태블릿 세로: 부엉이 위, 소품은 2~3개로 줄이고 겹치지 않게.
2. **메뉴 카드 3개**: 3D 아이콘 더 크게(약 1.3~1.5배), 아이콘 뒤 흰 반투명 원, 오른쪽 아래 화살표 버튼에 **점선 원 장식**(참고 사이트처럼 버튼 둘레 링), 올리면 카드가 살짝 떠오르고 그림자 진해짐, 아이콘은 살짝 커짐(움직임 줄이기면 없음).
3. **통계 칸·정보 카드**: 모서리 더 둥글게, 부드러운 색 그림자, 통계 숫자 더 굵게 + 메뉴 색, 칸마다 3D 아이콘을 원형 파스텔 배경 위에 올림. 정보 카드 제목 옆 3D 아이콘 칩 크기 키움, "더 보기" 알약에 메뉴 색.
4. **섹션 제목**("어디로 가 볼까요?" 등): 앞에 작은 3D 반짝이 아이콘, 글자 크기 조금 키움.
5. 페이지 배경: 본문 영역 전체에 아주 흐린 보라 빛 번짐이 한두 군데 보이게(스크롤해도 과하지 않게).

## 지킬 것
* 대비 AA 유지(특히 연보라 배경 위 흐린 글자, 형광펜 위 글자, 다크모드). 다크모드에서는 흰색 배경 대신 짙은 남보라 그라데이션 + 같은 빛 번짐.
* 성능: 애니메이션은 `transform`/`opacity`만, 이미지에 `width`/`height`. 첫 화면 레이아웃 흔들림(CLS) 없게.
* 다른 화면(과학수업·게시판·게임·로그인·관리자)이 공용 컴포넌트 변경으로 깨지지 않는지 확인.
* 과학 앱(`public/apps/**`, `scripts/templates/**`) 손대지 않기. 이미지 새로 받지 않기. git 금지, 실 DB 쓰기 금지, 자기 전용 headless 브라우저만, `localStorage.clear()` 금지.
