# Plan 서브에이전트 지침: 사이트 디자인 전면 개편 (2026-09-24)

사용자 요청: 사이트 디자인 수준을 **"똑똑! 수학탐험대"(https://www.toctocmath.kr/, KERIS 운영)와 흡사한 느낌**으로 올린다.
**그 사이트의 캐릭터·로고·그림·문구·이미지는 절대 가져오지 않는다**(다른 기관의 저작물). 느낌(색·모양·배치·글꼴 인상)만 참고한다.

## 참고 사이트 관찰(Claude가 직접 본 것, 1440px 기준)
* 배경: 연보라 → 흰색의 아주 은은한 그라데이션, 곳곳에 흐린 보라 원형 빛.
* 머리말: 흰 반투명 바, 왼쪽 로고 + 두 줄 설명, 오른쪽 알약 모양 흰 버튼(아이콘+글자, 연한 테두리·그림자).
* 첫 화면: 왼쪽에 아주 굵은 두 줄 제목("초등 수학, 더 쉽고 재미있게 탐험해요!") — 핵심 낱말만 보라·주황 등 색으로 강조, 아래 작은 설명 두 줄, 보라 그라데이션 알약 버튼(아이콘+글자). 제목 옆에 3D 캐릭터(아이+로봇)와 떠 있는 3D 소품(주사위·% 구슬·별). 오른쪽은 모서리가 크게 둥근(약 24px) 큰 배너 카드(장면 그림 위 굵은 흰 글자), 아래 작은 점 페이지 표시.
* 기능 카드 3개: 가로로 긴 큰 카드, 각각 다른 파스텔 그라데이션(복숭아·하늘·연보라), 가운데 큰 3D 물건, 굵은 색 제목 + 회색 설명, 아래 동그란 흰 버튼 안에 화살표(둘레에 점선 원 장식).
* 정보 카드 3개: 흰 둥근 카드, 왼쪽 위 3D 아이콘 + 굵은 제목, "더보기 +" 작은 알약, 목록 앞에 보라 알약 배지("주요").
* 오른쪽 아래 떠 있는 3D 로봇 도우미와 말풍선, 오른쪽 옆 작은 떠 있는 배너 카드.
* 전체 인상: 둥글고 두꺼운 모양, 부드러운 그림자, 보라 계열 주색, 3D 입체 그림, 큰 굵은 글씨, 넉넉한 여백.

## 사용자 결정
1. **그림**: 메뉴·카드·빈 화면에는 **무료 3D 아이콘(Microsoft Fluent Emoji 3D, MIT 라이선스)**, 첫 화면에는 **우리 반 전용 마스코트(AI로 새로 만듦)**. 마스코트는 Claude가 따로 후보를 만들어 사용자가 고른다 — spec에는 마스코트가 들어갈 자리·크기·자세(인사, 태블릿 들기, 생각하기, 축하하기 등)·파일 형식만 정한다.
2. **메뉴**: 왼쪽 사이드바 **유지**(모양만 새 디자인).
3. **범위**: 사이트 전체(홈·과학수업·자유게시판·학습게임·글 보기·검색·로그인·비밀번호 변경·내 학습 활동) + **과학 앱 23개는 공통 틀(`scripts/templates/science-sim/style-common.css`, `science-guide/style-common.css`)의 색·글꼴·버튼 모양만** 맞춘다(앱 동작·저장·내용은 그대로). 관리자 화면은 색·글꼴만.

## spec.md에 담을 것 (`docs/design/redesign/spec.md` 하나만 작성)
1. **디자인 토큰**: 색(주색 보라 계열 + 메뉴별 파스텔 그라데이션 4종, 밝은/어두운 모드 둘 다 — 지금 다크모드 지원을 유지), 배경 그라데이션, 모서리 반경 단계, 그림자 단계, 여백 단계, 글자 크기 단계. `globals.css`의 기존 토큰 이름과의 대응표.
2. **글꼴**: 한국어 굵은 제목용(아주 굵고 둥근 인상) + 본문용. 라이선스(OFL 등)와 불러오는 방법(정적 export에서 동작하는 방식 — `next/font` 또는 자체 호스팅), 용량. 과학 앱(정적 HTML)에서는 어떻게 같은 글꼴을 쓸지.
3. **3D 아이콘 목록**: Fluent Emoji 3D에서 쓸 아이콘을 메뉴·카드·빈 화면·배지별로 표로(이모지 이름, 원본 경로 `assets/<Name>/3D/<name>_3d.png`, 쓰일 곳). 저장 위치(`public/illustrations/3d/`), 라이선스 고지 방법(MIT 전문 파일), 크기·형식 최적화(WebP 변환 여부)와 basePath 처리. **다운로드는 하지 않는다**(사용자 허락 후 Claude가 한다).
4. **화면별 설계**(와이어프레임 수준, 텍스트로): 사이드바, 머리말, 홈(첫 화면 제목+마스코트 / 기능 카드 3개 / 정보 카드 줄), 과학수업(학기·단원·차시 목록), 자유게시판 목록·글, 학습게임 목록·실행 화면, 글 보기, 검색, 로그인·비밀번호 변경, 내 학습 활동, 관리자(색·글꼴만). 태블릿 가로·세로·휴대폰 375px에서의 배치.
5. **과학 앱 공통 틀**: 바꿀 CSS 변수·버튼·카드·단계 막대 모양. 앱 동작·저장 구조를 건드리지 않는 범위와 점검 방법.
6. **접근성**: 글자 대비(WCAG AA), 색만으로 정보 전달 금지, 움직임 줄이기(`prefers-reduced-motion`), 키보드 초점 표시.
7. **성능**: 이미지 용량 예산, lazy loading, 첫 화면 그림 크기.
8. **단계별 작업 계획**: 1단계(디자인 토큰·글꼴·사이드바·홈 — 사용자에게 먼저 보여 줌) → 2단계(나머지 화면) → 3단계(과학 앱 공통 틀) → 4단계(관리자 색). 단계마다 Build/Review 분리, 확인할 화면 목록.
9. **열린 질문**(추천안 포함).
