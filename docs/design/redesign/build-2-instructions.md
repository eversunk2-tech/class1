1단계(홈) 결과를 사용자가 승인했다("좋아"). 같은 디자인 언어로 나머지 화면을 바꾼다.
설계: `docs/design/redesign/spec.md` §4.4~4.8(+ 끝의 "개정 1"), 1단계 보고서 `build-1-report.md`(개정 1·2)의 토큰·컴포넌트를 그대로 재사용한다.

## 범위
1. **과학수업** (`src/components/science/science-view.tsx` 등, 학기→단원→차시→상세)
   * 히어로에 `owl-tablet.webp`(태블릿 든 부엉이) + 떠 있는 과학 소품(현미경·자석·전구·원자 배지 등, `public/illustrations/3d/`).
   * 학기·단원 카드: 그라데이션·큰 둥근 모서리·3D 아이콘, 차시 목록: 둥근 카드 + "실험 앱"(시험관 아이콘)·"조사 도우미"(돋보기 아이콘) 배지.
   * 1단계에서 발견한 hover 떠오름 끊김(`science-view.tsx:40` 부근)도 고친다.
2. **자유게시판** `/board/`(목록·글·글쓰기) · **학습게임** `/games/`(목록·글·업로드·실행 화면)
   * 목록 카드·글 상세·댓글·좋아요·신고 버튼을 새 모양으로. 게임 실행 화면은 **보안 구조(샌드박스 iframe·CSP 래퍼·"게임 시작" 버튼)를 절대 바꾸지 않고** 겉모양만.
3. **글 보기** `/post/`, **검색** `/search/`: 본문 가독성 우선(줄 간격·글자 크기), 표지·태그 알약.
4. **로그인** `/login/`, **비밀번호 변경** `/reset-password/`: 가운데 카드 + `owl-wave`(작게) 또는 3D 소품, 입력칸·버튼 새 모양. 로그인 흐름·오류 문구·리다이렉트는 그대로.
5. **내 학습 활동** `/me/learning/`: 요약 카드·기록 목록·피드백 대화. 완료 표시에 `owl-cheer.webp`를 작게.
6. **빈 화면·오류 안내**(`EmptyState` 등 공용): 옛 상자 그림 대신 `owl-think.webp`(생각하는 부엉이). 오류 전용 그림은 spec대로 유지해도 되지만 톤을 맞춘다.
7. **로그인 잠금 안내 카드**(`LoginGate`): 1단계 모양 유지·다른 화면에서도 일관되게.

## 지킬 것
* 기능·데이터 흐름·RLS·라우팅·문구 의미는 그대로(겉모양만). 특히 게임 샌드박스, 로그인/잠금/탈퇴/계정 생성 흐름, 관리자 기능.
* 관리자 화면(`/admin/**`)은 이번 단계에서 손대지 않는다(4단계). 다만 공용 컴포넌트 변경으로 깨지면 고치고 보고.
* 과학 앱(`public/apps/**`, `scripts/templates/**`)은 손대지 않는다(3단계).
* 이미지 새로 받거나 만들지 않는다. 3D 아이콘·마스코트는 `public/illustrations/` 것만.
* 대비 AA, 색만으로 정보 전달 금지, `prefers-reduced-motion`, 키보드 초점, 이미지 `width`/`height`·`alt`.
* git 금지, 실 DB 쓰기 금지(가짜 응답으로 로그인 상태 화면 확인), 자기 전용 headless 브라우저만, `localStorage.clear()` 금지.
