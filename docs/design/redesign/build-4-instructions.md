# Build 지침: 디자인 개편 4단계 — 관리자 화면 색·글꼴 (2026-09-24 사용자 승인)

설계: `docs/design/redesign/spec.md` §4.9(+ Q7: 보라가 관리자 화면에 과하면 채도만 낮추기). 사이트 토큰은 1·2단계에서 이미 바뀌었고, 관리자 화면은 그 영향을 받은 상태다.

## 수정 범위
* `src/app/admin/**`, 관리자 전용 컴포넌트(`src/components/admin/**`, 관리자에서만 쓰는 `src/components/learning/**` 부분). 공용 컴포넌트는 **다른 화면이 바뀌지 않는 방식**으로만(관리자 영역 한정 클래스 등).
* 관리자 화면은 **색·글꼴·모서리·그림자만** 새 디자인에 맞춘다. 3D 아이콘·마스코트는 넣지 않는다(spec §3.2: 관리자 메뉴 아이콘은 lucide 유지).
* 1단계 보고에서 찾은 hover 떠오름 끊김(`src/app/admin/(dashboard)/…/admin-overview.tsx:161` 부근)을 고친다.
* 관리자 화면의 보라가 과하게 장난스러우면 관리자 영역에서만 채도를 낮춘다(새 전역 토큰 추가 없이, 영역 한정 CSS). 판단 근거를 보고서에 적는다.

## 반드시 지킬 것
* 기능·데이터·권한 흐름은 그대로(회원 추가·엑셀 일괄·탈퇴·비밀번호 초기화·로그인 잠금 스위치·학생 응답·피드백·일괄 칭찬·신고 처리·글쓰기). 확인 대화상자·위험 버튼(탈퇴 등)은 **위험 색(빨강)이 분명히** 남아 있어야 한다.
* 표·목록의 가독성 우선(밀도 높은 화면), 대비 AA, 키보드 초점, 375·태블릿·데스크톱.
* 과학 앱(`public/apps/**`, `scripts/templates/**`)은 손대지 않는다(3단계 담당이 동시에 작업 중). 학생 화면(홈·과학수업·게시판·게임 등)이 바뀌지 않게.
* git 금지, 실 DB 쓰기 금지(가짜 관리자 세션·가짜 응답), 자기 전용 headless 브라우저·자기 포트만, `localStorage.clear()` 금지.
