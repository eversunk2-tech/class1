## 2. 만든 것(요약)

- **예상하기**: 질문 1개(5글자 이상)와 힌트 2개(spec 문구 그대로). 힌트에는 답이 없다.
- **실험하기**: 물질(양초/알코올) × 관찰 항목(불꽃의 모습/따뜻한 정도/그 밖에 관찰한 것) = 6칸이고, 칸마다 한 번씩 관찰한다.
  - 실험하기 맨 위에 안전 안내 한 줄을 늘 보인다(spec 3.0 문구). "⚠️ 실제 실험에서 지켜요" 4줄은 접을 수 있게 따로 두었다.
  - ▶를 누르면 불이 없는 물질은 먼저 점화기로 불을 붙인다(약 2.3초). 알코올램프는 뚜껑을 열어 옆에 둔 뒤 붙인다.
  - **불꽃의 모습**: 카메라가 불꽃에 다가간다. 불꽃은 위아래로 길쭉하고 계속 흔들린다. 둘레의 빛 번짐과 점광원으로 주변이 밝아진다. 양초 불꽃은 노란색·붉은색, 알코올 불꽃은 푸른색·붉은색이다. 관찰 카드에는 작은 불꽃 그림과 "🎨 색 이름 보기"(교과서 표현 "노란색, 붉은색 등")를 넣었다.
  - **따뜻한 정도**: 불꽃 둘레에 붉은 번짐이 생기고 "가까이 · 따뜻함 ●●●"과 "멀리 · 따뜻함 ●○○" 표시가 나온다. 온도 숫자는 없고 "모형"이라고 밝혔다. 두 표시는 두 기구 사이(안쪽)에 두어 화면 밖으로 나가지 않는다.
  - **그 밖에 관찰한 것**(개정 1 시간 바): 불을 붙인 뒤 시간 바(0~10분, 모형)를 끌면 양초가 짧아지고, 촛농이 흘러내리고, 윗면에 녹은 촛농이 고인다. 알코올 양은 줄고 불꽃은 계속 탄다. 수치는 보여 주지 않는다. 대신 "처음 그대로예요 / 조금 / 꽤 / 많이 줄었어요"라고 글로 알려 주고, "🏷 모형: 줄어드는 빠르기는 실제와 다를 수 있어요."를 늘 표시한다. 5분(점선)을 넘겨 봐야 📷 버튼이 작동한다. 그 전에 누르면 안내가 뜨고 시간 바 카드가 강조된다. 📷를 누르면 같은 자리에서 찍은 "처음(불을 붙인 직후)"과 "나중(약 N분 뒤, 모형)" 사진을 나란히 보여 준다. 3D는 `Sim3D.snapshot`, 2D는 같은 SVG를 잘라 만든 그림을 쓴다.
  - 관찰 카드는 보기 고르기다. 보기 순서는 칸마다 다르게 고정했다. **확인하기**로 맞아야 **📝 기록하기**가 켜지므로 기록은 늘 교과서 표현과 같다. 틀리면 다시 볼 곳만 알려 준다.
  - 시간 바는 터치·마우스로 끌 수 있고, 키보드(←/→ 0.5분, PageUp/PageDown 2분, Home/End)도 된다. 손잡이는 44px이고, `aria-valuetext`가 시간·양·불꽃 상태를 읽어 준다. 끄는 동안 화면 갱신은 requestAnimationFrame으로 묶었다. 세로·좁은 화면에서는 실험 화면 바로 아래에, 가로(좌우 배치)에서는 오른쪽 패널의 실행 버튼 위에 둔다.
  - "🧯 불 끄고 처음 상태로" 버튼은 두 불을 끄고 시간을 0으로 되돌린다. 기록과 "시간 바를 움직여 봄" 여부는 그대로 남는다.
- **기록·분석하기**: 관찰 항목 3행 × 물질 2열로 된 내 기록 표, 그리고 퀴즈 2개(spec 3.4. 1번은 여러 개 고르기, 고른 오답마다 피드백).
- **정리하기**: 결론 1개를 적고 제출하면 모범 답안(spec 원문)이 나온다. 궁금한 점 한 줄은 선택이다. 마치면 `app_results`에 저장한다.
- `detail`: `predict`, `hintsOpened`, `records[{substance, method, result}]`, `timeBar{candle, alcohol}`(움직여 본 가장 늦은 시각), `analysis`, `conclusion`, `curiosity`, `qa`(spec 8절 표 그대로: predict q1 / experiment records(table: 물질·관찰 항목·관찰 결과) / analyze q1·q2 / conclude conclusion / curiosity q1). 실제 흐름에서 약 2.5천 자다(JSON 기준, 제한 16,000자).

## 3. spec과 다른 점

1. **단계 4개**: spec 6절 초안은 궁금한 점을 5번째 단계로 두었다. 이 앱은 2학기 1단원 앱들처럼 정리하기 안에 선택 한 줄로 넣었다(`CLAUDE.md` "마지막의 궁금한 점은 선택 입력 한 줄"). `qa`의 stage는 spec대로 `"curiosity"`다.
2. **퀴즈 정답 피드백의 "맞아요!"를 뺐다**: 공통 틀이 앞에 "⭕ 맞았어요!"를 붙이기 때문이다(1단원 fix에서 고친 중복 문제). 보기는 틀 형식에 맞춰 id·label로 바꿨다(`light/heat/samecolor/more`, `less/same/more`).
3. **본문 3.2의 "⏩ 빨리 감기 2~3초"는 개정 1의 시간 바로 대신했다**. 사진 비교(스냅샷)는 그대로 살렸다. "나중" 사진은 지금 시간 바 위치에서 찍는다. 5분이 안 되면 움직여 본 가장 늦은 시각이나 5분에서 찍는다.
4. **관찰 보기는 확인을 통과해야 기록한다**(공통 틀의 `check` 훅). 분석 문항이 "내 기록"을 보고 답하게 되어 있어서, 기록이 항상 교과서 값과 같도록 했다.
5. **머리말에 단원 이름을 쓰지 않았다**: "6학년 2학기 · 2단원 · 탐구 2"로만 적었다. spec 3.0이 다음 차시 용어("연소" 등)를 어디에도 쓰지 말라고 해서다. 단원 이름을 넣고 싶으면 Claude가 판단해 주세요.
6. 열린 질문 4(양초 불꽃 바깥쪽을 조금 더 밝게)를 반영했다. 3D 양초 불꽃 윗부분을 연노랑으로 조금 밝게 했고 수치는 쓰지 않았다.
7. `detail`에 `timeBar`(시간 바를 얼마나 움직여 봤는지)를 더했다. 관리자 응답 매핑 파일(`src/data/app-responses/sci-6-2-2-2.ts`)은 만들지 않았다. 앱 폴더 밖이고, 2학기 1단원 앱들에도 아직 없다. `qa`만으로 "학생 응답" 화면에 표시된다.

공통 틀 변경이 필요한 곳은 없었다. 참고로 휴대폰에서는 공통 틀이 3D 도움말 뒤에 "페이지를 위아래로 움직일 때는…"을 붙인다. 그래서 도움말이 세 줄이 되어 장면 아래쪽을 조금 가린다. 앱 쪽 도움말은 한 줄로 줄여 두었다.
