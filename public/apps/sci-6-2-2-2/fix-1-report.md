## 2. 다시 확인한 것

자기 전용 headless Chrome에서 가짜 세션과 가짜 Supabase 응답으로 확인했다. 이번에는 Chrome을 `--host-resolver-rules=MAP *.supabase.co 127.0.0.1:9`로 띄웠고, 첫 페이지 로드 전에 Fetch 가로채기를 켰다. 그래서 가로채기를 벗어난 요청이 있어도 실제 서버에 닿을 수 없다. 공유 브라우저와 `localStorage.clear()`는 쓰지 않았다.

- 전체 흐름을 끝까지 진행했다(1024×768 3D, 768×1024 3D, 375×812 다크·터치 3D, 768×1024 다크 `?no3d=1`). 모두 완료했고 콘솔 오류 0, 가로 스크롤 0, 3D↔2D를 4번 전환해도 캔버스가 쌓이지 않았다.
- 6칸 기록이 새 정답 문구와 같다. 틀린 보기를 고르면 기록하기가 꺼진 채로 남는다.
- 분석 문항이 1개다. 오답을 고르면 "양초와 알코올의 불꽃 색깔을 표에서 다시 비교해 보세요."가 나온다. 정답 하나를 빠뜨리면 "표의 '그 밖에 관찰한 것' 줄을 다시 보세요."가 나온다. 세 개를 다 고르면 정답이다. 마치기 요약은 "분석 질문: 1/1 맞힘"이다.
- 결론 칸의 안내 글과 시작 도움 줄이 보인다. 마치면 `app_results`가 저장되고 detail.qa는 5항목이다.
- 빨리 감기 바: 눈금은 "처음(불 붙인 직후) / 나중"이고, End 키를 누르면 aria-valuetext가 "한참 지난 뒤, 알코올 양: 처음보다 많이 줄었어요, …"다. 가운데 점선까지 끌면 사진 비교가 열린다.
- 금지어를 다시 찾았다. 머리말의 단원 이름("2. 물질의 연소", 조정자 결정) 말고는 산소·발화점·이산화·지도서 등이 0건이다.
