## 1. 지도서 분석

### 1.1 차시 개요 (지도서 196쪽)
- 학습 목표: ① 양초와 알코올이 탈 때 나타나는 현상을 관찰할 수 있다. ② 물질이 탈 때 나타나는 공통적인 현상을 설명할 수 있다.
- 성취기준 `[6과14-02]` 물질이 연소할 때 나타나는 공통적인 현상을 관찰하고, 연소의 조건을 찾을 수 있다(단원 개관 181쪽). **이 차시는 "공통적인 현상 관찰"까지만 다룬다 — 연소의 조건은 4~5차시(다음 차시) 내용**(1.8 참고).
- 교수·학습 흐름(196쪽 활동 흐름표, 40분): 도입 5분(케이크용 초 경험 이야기) → 전개 30분([탐구 활동] 양초·알코올이 탈 때 나타나는 공통적인 현상 관찰하기, 물질이 탈 때 나타나는 공통적인 현상 정리) → 정리 5분(공통적인 현상 정리하기). `CLAUDE.md`의 예상하기→실험하기→기록·분석하기→정리하기 4단계와 자연스럽게 대응된다.
- 탐구 목표(197쪽): "양초와 알코올이 탈 때 나타나는 공통적인 현상을 관찰할 수 있다." 탐구 태그: **자료 수집 및 비교 분석 | 결론 도출 및 적용**.

### 1.2 준비물 및 안전 (196쪽)
- 모둠: 양초, 촛대, 알코올램프, 점화기, 그림 도구. 개인: 실험복, 보안경, 면장갑.
- 안전 수칙(196, 197, 199쪽): 실험 전 비상구·소화기·모래 보관함 위치 확인 / 불을 다룰 때 면장갑 착용, 화상 주의 / 불꽃 근처에 탈 수 있는 물질 두지 않기 / 환기가 잘 되는 곳에서 실험 / 불꽃 관찰 시 신체 일부를 가까이하지 않기(불꽃 윗부분이 가장 뜨거움) / 화상 시 즉시 얼음·찬물로 식힌 뒤 치료.
- 알코올램프 사용법(200쪽): 알코올은 에탄올만 사용(메탄올 금지), 70~80%만 채움, 심지 길이 0.5~1 cm, 불을 끌 때 면장갑 낀 손으로 뚜껑을 옆에서 살며시 덮기. **이 앱은 시뮬레이션이므로 실제 화기 취급 절차를 학생이 조작하게 하지 않고, 안전 수칙은 "실제 실험은 선생님과 함께" 한 줄 안내로만 다룬다**(`CLAUDE.md` 과학 앱 규칙 "공통" 항, "안전·표현" 지시).

| 따뜻한 정도 | 주변이 따뜻해진다. 불꽃에 가까울수록 더 따뜻해진다 | 주변이 따뜻해진다. 불꽃에 가까울수록 더 따뜻해진다 |

- 지도서 199쪽 차시 평가 문항 2(공통적인 현상 두 가지 고르기, 정답 ①②): ① 빛이 난다 ② 열이 난다. → 이 앱 분석 단계 문항 1의 근거.
- 지도서 199쪽 평가 문항 1(옳지 않은 것 고르기, 정답 ⑤ "알코올이 타는 동안 알코올의 양은 변하지 않는다"): **"양은 변하지 않는다"는 오개념 오답**으로, 실험 관찰 "그 밖에 관찰한 것" 카드와 분석 단계 문항 2에 그대로 반영한다.
- 촛불 온도 세부(겉불꽃 1,400℃·속불꽃 1,200℃·불꽃심 900℃, 200쪽 보충 자료)는 6학년 성취기준 범위를 넘는 심화 내용이므로 **이 앱에서 수치로 다루지 않는다**(9절 참고). "불꽃에 가까울수록 더 따뜻하다"는 정성적 사실만 쓴다(197쪽 "정확한 온도 변화보다 열이 난다는 것을 아는 정도로 지도한다"는 지도상 유의점과 일치).

### 1.4 오개념 및 지도상 유의점 (197, 198, 199쪽)
1. **"물질이 탈 때 발생하는 열은 정확한 온도로 측정해야 안다"는 오해** → 197쪽 지도 길잡이: "정확한 온도의 변화보다 양초(알코올)가 탈 때 열이 난다는 것을 알 수 있는 정도로 지도한다." → 3D 장면은 온도계 숫자가 아니라 "가까울수록 따뜻함이 커지는" 정성적 모형(빛·색 그라데이션)으로 표현한다.
2. **"타는 동안 물질의 양은 변하지 않는다"는 오개념**(199쪽 평가 문항 1의 오답 선지) → 실험 카드와 분석 문항에서 명시적으로 확인시킨다(1.3 참고).
3. 관찰 시 불꽃을 붙이기 전과 비교하며 관찰하도록 지도(197쪽) → 예상하기 단계에서 "불을 붙이기 전에는 어땠는지" 떠올리게 하는 문구를 넣을 수 있다(3.1 참고).

### 1.5 평가 (지도서 199쪽)
- 평가 목표: [지식·이해] 물질이 탈 때 나타나는 공통적인 현상을 설명할 수 있다 / [과정·기능] 양초와 알코올이 탈 때 나타나는 공통적인 현상을 관찰할 수 있다 / [가치·태도] 흥미와 관심을 가졌다.
- 서술형 문항 3(199쪽): "가스레인지로 요리할 때 / 정전이 되어 촛불을 켤 때, 물질이 탈 때 나타나는 어떤 현상을 이용한 것인지" → 예시 답안 "물질이 탈 때 발생하는 열/빛을 이용하여 …" — **이 내용(일상 속 활용 예)은 교과서 41쪽 "함께 풀어요"에 속하며 정리하기의 발전 질문 성격이라, `CLAUDE.md` 새 기준("정리하기는 발전 질문 없음")에 따라 이 앱에서는 다루지 않는다**(9·10절 참고).

### 1.6 이전·다음 차시 연계 (스포일러 주의)
- **이전(탐구 1, `sci-6-2-2-1`, "서로 다른 물질을 섞으면 어떻게 될까?")**: 물질을 섞을 때 성질이 달라지는 변화/달라지지 않는 변화. 이 차시와 직접 연결되지 않으므로 재언급하지 않는다.
- **다음(4~5차시, "물질이 타려면 무엇이 필요할까?", 탐구 3 예정)**: 연소의 조건(탈 물질, 산소, 발화점 이상의 온도)을 다룬다. **이 앱에서는 "왜 타는지", "무엇이 있어야 타는지"를 절대 언급하지 않는다** — 오직 "탈 때 어떤 현상이 나타나는가"만 다룬다.
- **다음 다음(6차시, "연소 후의 변화가 궁금해!")**: 연소 생성물(물, 이산화 탄소)을 다룬다. 이 앱에서 생성물 관련 실험(푸른색 염화 코발트 종이, 석회수)은 절대 언급하지 않는다.
- 산과 염기 단원(1학기 1단원)에서 이미 촛불·알코올램프 점화기 사용법을 다룬 적이 있으므로, 점화기 사용법 자체는 짧게만 안내한다.

## 3. 화면 설계 (예상하기 → 실험하기 → 기록·분석하기 → 정리하기(+궁금한 점))

### 3.0 공통 전제
- 태블릿 가로·세로, 큰 터치 영역, 6학년 눈높이 한국어. 로그인 필수(로그인 안 했으면 활동 화면 대신 로그인 안내), `app_progress` 자동 저장·이어서 하기.
- "연소", "발화점", "산소" 등 다음 차시 용어는 **어디에도 등장하지 않는다**(1.6 참고). "지도서"라는 말도 쓰지 않는다(출처 표기는 "교과서·실험관찰").
- 불꽃·열기 표현은 3D 장면에서 "모형" 배지로 밝힌다(정확한 온도 수치를 보여주지 않음, 1.3·1.4 참고).
- 실험하기 도입에 안전 안내 한 줄: "실제 실험에서는 선생님과 함께, 안전 장비(면장갑·보안경)를 착용하고 진행해요. 이 화면은 안전한 모형 실험이에요."

### 3.1 예상하기 (탐구형 질문 1개)
- 질문: "양초나 알코올에 불을 붙이면 어떤 현상이 나타날지 예상해 봅시다." (최소 글자 수 5자 안내)
- 힌트(답을 말하지 않고 순서대로 열림):
  1. "케이크용 초에 불을 붙여 본 적이 있나요? 그때 불꽃 주변이 어땠는지 떠올려 보세요."
  2. "불이 켜지기 전과 켜진 뒤, 주변의 밝기와 온도가 어떻게 달라질지 생각해 보세요."

### 3.2 실험하기
- 조건(factor) 1 **물질**: 양초 / 알코올(알코올램프).
- 조건(factor) 2 **관찰 항목**(실험관찰 24~25쪽 표의 3개 행을 그대로 씀, 1.3 참고): 불꽃의 모습(모양·밝기·색깔) / 따뜻한 정도 / 그 밖에 관찰한 것(시간에 따른 변화).
- 칸 수: 2 × 3 = **6칸**, 반복 측정 없음(1회씩, `CLAUDE.md` 측정 규칙 — 같은 조건 반복 없음·조건은 실험관찰에 제시된 것을 모두 다룸).
- 실행(run) 연출:
  - **불꽃의 모습** 칸(물질별 첫 관찰): 점화기로 불을 붙이는 애니메이션(2~3초) → 불꽃이 안정적으로 타는 모습(2초). 카메라 드래그로 회전 가능.
  - **따뜻한 정도** 칸: 이미 켜진 불꽃 옆에 "가까이"·"멀리" 두 지점을 표시하고, 각 지점에 온도 대신 **따뜻함 정도를 색 그라데이션(붉은빛 번짐)으로 표현하는 모형** 연출(2~3초). 수치·온도계는 쓰지 않는다.
  - **그 밖에 관찰한 것** 칸: "⏩ 빨리 감기(모형)"으로 여러 시간이 지난 모습을 짧게 보여준다(양초 길이·알코올 양이 줄어드는 트윈, 2~3초). **스냅샷(전/후 비교)** 기능으로 불 붙이기 직전 사진과 빨리 감기 후 사진을 나란히 보여준다(`Sim3D.snapshot`, 지도서 199쪽 지도 길잡이 3의 "사진을 찍어 전후를 비교" 권장을 그대로 구현).
- 관찰 카드(보기 고르기, `type: "choice"`, 3.3 참고): 칸마다 정답 1개 + 오답 2개.
- 안전상 관찰하지 않는 칸(`skipCells`)은 없음(모든 칸이 안전한 관찰 내용).

### 3.3 관찰 카드 보기 문구 (지도서 표현을 그대로 조합, 6절 config 참고)
- **불꽃의 모습 · 양초**: 정답 "위아래로 길쭉한 모양이고, 불꽃 주변이 밝아지며, 색깔은 노란색·붉은색이다" / 오답 "동그란 모양이고, 불꽃 주변이 어두워지며, 색깔은 흰색이다" / 오답 "모양이 계속 바뀌지 않고, 색깔은 초록색이다".
- **불꽃의 모습 · 알코올**: 정답 "위아래로 길쭉한 모양이고, 불꽃 주변이 밝아지며, 색깔은 푸른색·붉은색이다" / 오답 "동그란 모양이고, 불꽃 주변이 어두워지며, 색깔은 흰색이다" / 오답 "모양이 계속 바뀌지 않고, 색깔은 초록색이다".
- **따뜻한 정도 · 양초/알코올(공통)**: 정답 "불꽃에 가까울수록 더 따뜻하다" / 오답 "거리와 상관없이 따뜻한 정도가 같다" / 오답 "불꽃에서 멀수록 더 따뜻하다".

### 3.4 기록·분석하기
- 표(관찰 방법형 매트릭스, 행=관찰 항목 3개, 열=물질 2개): 학생이 고른 보기 문구를 칸에 표시.
- 보기 고르기(퀴즈) **2개**(규칙 "1~2개" 범위):

## 7. 3D 장면 스케치 (`sim3d.js` 활용)

- 배경: 실험대(책상) 위 평평한 판 — 산과 염기 단원 앱(`sci-6-1-1-*`)의 실험대 모델을 재사용/참고.
- 물체: 촛대+양초(원통, 심지), 알코올램프(유리 용기+심지+뚜껑), 점화기(탭하면 불꽃 이펙트).
- 조명: 기본 조명 + 불이 붙으면 불꽃 위치에 포인트 라이트 추가(노란빛 or 푸른빛, 물질에 따라 색 다르게 — 1.3 참고).
- 따뜻한 정도 연출: 불꽃 주변에 반투명 붉은빛 구체(그라데이션, 가까울수록 진하게) — "모형" 배지 필수(수치 온도 아님을 명시).
- 그 밖에 관찰한 것 연출: `v.tween`으로 양초 높이 축소/알코올 액면 낮아지는 애니메이션(2~3초, "⏩ 빨리 감기(모형)" 라벨) + `v.snapshot()`으로 시작 전/빨리 감기 후 사진 2장을 나란히 비교(지도서 199쪽 권장 방식 반영, 6절 참고).
- 드래그 회전 가능(터치), `Sim3D.create({ viewDir: […] })`로 살짝 위에서 내려다보는 기본 시점.
- `?no3d=1` 또는 3D 컨텍스트 유실 시 2D 대체 화면(정면 그림 + 같은 관찰 카드)도 준비한다(`build2D`).

| curiosity | q1 | 물질이 탈 때 나타나는 현상에 대해 더 궁금한 점이 있으면 적어 보세요. | text | 학생 입력(선택) |

`records` 항목은 `predict.qa`/`quiz.qa`/`conclude.qa`/`curiosity.qa`가 자동으로 만들지 않으므로 6-1-1-1 패턴대로 `app.js`가 직접 `{ stage: "experiment", id: "records", label: "내 관찰 기록", question: "…", kind: "table", answer: { columns, rows } }` 모양으로 넣는다.

## 9. 공통 틀 확장 필요: **없음**

- `type: "choice"` 관찰 카드(6-1-1-1 패턴), `Sim3D.snapshot`/`cameraPose`(6-1-2-1 확장), `Quiz`의 `multi`·`wrongBy`, `TableChart.renderMatrix` 모두 기존 정본 기능으로 충분하다.
- 불꽃 온도 세부(겉불꽃/속불꽃/불꽃심)·연소 조건·생성물은 이 차시 범위 밖이라 애초에 화면에 넣지 않으므로, 이를 위한 새 기능도 필요 없다.

## 10. 열린 질문 (사용자가 고를 수 있게, 추천안 포함)

1. **"그 밖에 관찰한 것" 정답 문구에 "불꽃이 계속 흔들린다"도 포함할지?** 추천: 포함하지 않음 — 이미 2개 사실(길이 줄어듦, 촛농/양 감소)을 담고 있어 문장이 길어지면 읽기 부담이 커진다. 대신 3D 연출에서는 불꽃이 계속 흔들리는 모습을 시각적으로 보여준다(채점 대상은 아님).
2. **알코올램프 점화 동작을 실제 절차(가스 점화기로 옆에서 스치듯 이동)까지 재현할지?** 추천: 단순화 — 점화기 아이콘을 탭하면 바로 불이 붙는 것으로 처리(모형 배지 불필요, 조작 자체의 단순화이지 과학적 사실 왜곡이 아님).
3. **1.5의 서술형 문항(가스레인지·정전 시 촛불처럼 일상 속 활용 예)을 정리하기에 발전 질문으로 넣을지?** 추천: 넣지 않음 — `CLAUDE.md` 새 기준이 "정리하기는 발전 질문 없음"을 명시하므로 제외. 필요하면 별도 차시(6차시 이후 "함께 생각해 보세요"류)에서 다루는 것을 제안.
4. **촛불 색 온도(겉불꽃/속불꽃/불꽃심, 200쪽 보충 자료)를 3D 불꽃 그라데이션 색에 은근히 반영할지(수치 언급 없이 시각 효과로만)?** 추천: 반영해도 좋음 — 노란 불꽃의 바깥쪽을 살짝 더 밝게 표현하는 정도는 사실 왜곡 없이 볼거리를 더한다. 다만 필수는 아니므로 Build 단계 재량.
