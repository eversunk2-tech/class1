## 2. spec과 다른 점
- **localStorage 키**: spec §3.5 예시(`:intro`, `:conclusion`)와 조금 다르다. 실제 키(접두사 `sci6115guide:v1`): `predict`·`hints`(도입), `refOpen`, `worksheet`, `share`, `quiz`, `conclude`(결론·발전 질문), `curiosity`, `step`, `meta`. 공통 모듈의 기본 키를 그대로 썼다(동작 차이 없음).
- **정리 틀 최소 조건**: spec §8-1 추천안대로 "3줄 이상 + 산성 1개 이상 + 염기성 1개 이상"(config `requireEach`)으로 구현.
- **복습 카드**(§3.1): 용어만 — "앞에서 지시약의 색깔 변화를 보고 여러 가지 용액을 산성 용액과 염기성 용액으로 분류해 보았어요." 용액 목록은 넣지 않았다(도입 질문 답 누설 방지). 질문 **아래**에 둔다.
- **다른 모둠 발표 → 예시 답**: 예시 발표(1모둠 레몬즙, 2모둠 제빵 소다)와 지도서 예시 답(하수구 세정제)이 서로 다른 모둠 이야기라서, "여러 모둠 가운데 두 모둠의 예시예요" 안내와 "예시 답은 하수구 세정제를 조사한 모둠의 발표를 들은 경우예요(지도서 150, 153쪽)" 비교 도움말을 붙였다.
- **정리 질문 구성**: 보기 3문항을 모두 '확인'하면 결론·발전 질문(순서대로 열림)이 나온다(시범 앱 분석→정리와 같은 방식). 문항 1 문구를 "이용한 용액의 성질이 다른 하나는?"으로 조금 다듬었다.
- 비교 도움말(`compareTip`) 두 개를 더했다: 결론("성질이 다르다 + 그 성질을 이용한다"), 발전 2("정답이 하나가 아니에요, 생선 비린내에 레몬즙을 뿌리는 것처럼…" — 지도서 150쪽 사실).
- 조사 팁의 누리집 링크는 새 창 + "선생님과 함께 확인하며 열어요" 안내(지도서 148쪽 인터넷 윤리). 검색어 칩은 복사만(탐구 6 spec §8-2 추천과 같은 정책을 틀 기본값으로).

## 3. 확인한 것 / 못 한 것
**확인한 것**(`public/`를 정적 서빙한 `/apps/sci-6-1-1-5/index.html`, 내 탭에서):
- 전체 흐름 끝까지: 도입 미입력 시 막힘 → 힌트 3개 순서대로 → 정리 틀(빈 칸 줄은 안 셈, 산성만 3줄이면 "염기성…" 안내로 막힘, 줄 더하기/지우기, 비교 버튼 잠김→열림, 비교 표 "내 기록" 표시) → 발표 준비(대본 10자 미만 막힘, 알게 된 점 제출 후 예시 답 비교) → 퀴즈 오답/정답 피드백, 3문항 확인 전 결론 잠김 → 결론·발전 1·2 순서 공개(10자 미만 막힘) → 궁금한 점 미입력 시 마치기 막힘 → 마치기.
- 비로그인: 로그인 안내+링크, "로그인하지 않아서 결과는 저장되지 않았어요", supabase.co 요청 0건. 저장 호출은 `Class1Record.save`를 가짜로 바꿔 ok(“✅ 결과를 저장했어요”)와 invalid("적은 글이 너무 길어서…") 문구 확인, detail 내용·크기(보통 약 0.9천 자) 확인.
- 새로고침 복원(단계·입력·줄·비교 열림·참고 카드 펼침), 앞 단계로 가서 정리 틀을 고쳐 조건이 깨지면 뒤 단계가 다시 잠김, "처음부터 다시 하기"(이 앱 키만 지워짐).
- 태블릿 가로 1024×768, 세로 768×1024, 휴대폰 375×812(모든 단계 `scrollWidth = 375`, 비교 표만 표 안에서 가로 스크롤), 다크모드(375, 1024).
- 검색어 칩 실제 클릭 → 클립보드 복사·안내 문구(받침 조사 맞음). 학생 입력 `<img onerror>` → 글자로만 표시(img 요소 0개).
- 콘솔 오류/경고 0. 화면 문구에 pH·중성·중화·화학식·트리메틸아민 없음(검색). `innerHTML` 사용 없음. 상대경로만.
- 지도서 PDF 148~155쪽(PDF 45~52쪽) 텍스트를 추출해 8개 용액·이용 예·제산제·하수구 세정제·에듀넷 문구를 대조(spec 값과 일치).
- 공통 틀: 정본 ↔ 앱 사본 diff 없음. "같은 파일" 6개는 science-sim과 byte 단위로 같음(확인 시점 기준).

**못 한 것**
- 실제 태블릿 터치, iPad Safari, 실제 로그인 저장(`app_results` insert)·RLS(실 DB 쓰기 금지).
