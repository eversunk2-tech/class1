## 5. 브라우저·보안·품질

- **전체 흐름**(dev 서버 `/class1/apps/sci-6-1-1-5/index.html`, 내 탭 하나만 씀): 도입 미입력이면 다음 단계가 막힘(토스트) → 힌트 3개 순서대로 → 정리 틀이 산성만 3줄이면 "염기성…" 안내로 막힘, 비교 버튼 잠김→열림 → 발표 대본 10자 미만 막힘, 알게 된 점 짧으면 막힘 → 퀴즈 오답/정답 피드백, 3문항 확인 전에는 결론 잠김 → 결론·발전 1·2가 순서대로 공개 → 궁금한 점 미입력이면 마치기 막힘 → 마치기(비로그인 문구, 가짜 save로 성공 문구).
- **뷰포트**: 1024×768, 768×1024(다크), 375×812에서 5단계 모두 `scrollWidth`가 뷰포트와 같음(가로 스크롤 없음). 375px에서 높이 40px 미만인 터치 대상은 로그인 안내 글 링크(17px) 하나뿐.
- **다크모드**: 배경 `rgb(17,22,31)`, 카드와 경고 카드 대비 정상(768 스크린샷).
- **콘솔**: 앱 오류 0건. 404 1건은 내가 폴더 주소를 fetch해서 생긴 것(i5).
- **자원 로드**: 스크립트·CSS 19개 모두 200(`/class1/apps/sci-6-1-1-5/…`). supabase-js 2.116.0 SRI를 직접 계산해 보니 `integrity`와 일치.
- **XSS**: 정리 틀에 `<img src=x onerror=alert(1)>`을 넣음 → 비교 표 "더 찾았어요" 문구, 발표 요약에서 글자로만 표시(main 안 img 0개). 코드에 `innerHTML`/`insertAdjacentHTML` 없음. `**굵게**`는 config 문구에만 `SciSim.rich`(DOM 생성) 사용.
- **접근성**: 정리 틀 성질 선택은 글자 버튼(radiogroup + aria-labelledby), 참고 카드는 아이콘+글자(색만으로 구분하지 않음), 상태 안내는 aria-live. 흠은 M1의 초록 ✔(색+기호)이 틀린 정보를 긍정하는 것.
- **공통 틀 사본 일치**: `diff -r scripts/templates/science-guide public/apps/sci-6-1-1-5/science-guide` 차이 없음. sci-6-1-1-6 사본도 정본과 같음. `class1-record.js`도 정본과 같음. 틀 버그 2건은 세 곳 모두에 남아 있음(D3).
- **RLS**: 이 앱은 새 테이블이 없고 `app_results`만 class1-record로 쓴다(기존 정책). 실 DB 쓰기는 하지 않았다.

## 6. 확인한 것 vs 못 한 것

**확인한 것**
- 지도서 148~155쪽, 106~107쪽 원문과 config의 모든 사실·문구·정답·모범 답안 대조(2절)
- 앱 폴더의 모든 파일과 공통 모듈(worksheet, share-prep, ref-cards, tips-panel, lesson, quiz, conclude, predict, persist) 코드 읽기
- 브라우저 전체 흐름, 게이트, 되돌아가서 조건이 깨졌을 때 다시 잠김, 새로고침 복원, 처음부터 다시 하기(다른 키 보존), 3개 뷰포트, 다크모드, 콘솔, XSS, SRI, 자원 경로
- 틀 버그 2건이 정본·5·6 사본에 남아 있는지(코드와 diff)

**못 한 것**
- 실제 태블릿 터치, iPad Safari, 가로·세로 회전
- 실제 로그인 저장(`app_results` insert)과 RLS 동작(실 DB 쓰기 금지)
- 클립보드 복사 실제 붙여 넣기(백그라운드 탭이라 권한 영향). `durationSec`가 0으로 나온 것은 백그라운드 탭이 `document.hidden`이어서다(버그 아님)
- 스크린샷이 스크롤 아래 영역을 잡지 못해, 비교 표 등 아래쪽은 DOM·계산된 스타일로 확인
- `next build` 정적 export 결과물(`out/`)로 열기(dev 서버의 basePath 경로로 대신 확인)

정리: 테스트로 만든 `sci6115guide:v1:*`와 `other:keep` localStorage 키는 지웠다. 뷰포트와 색 구성표는 되돌렸고, 내 탭은 닫았다. 지도서 추출 임시 파일도 지웠다.
