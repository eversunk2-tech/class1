# Build(수정) 서브에이전트 지침: sci-6-1-2-5 측정 단순화 (2026-09-22 사용자 요청)

## 사용자 요청
* 측정을 여러 번 해서 시간이 오래 걸리고 집중력이 떨어진다. **자동차별로 거리 측정 1번, 시간 측정 1번씩만** 간단하게 측정해 실험 결과를 정리하게 한다.
* **측정값은 학생에게 반올림을 시키지 않는다. 처음부터 소수 첫째 자리까지만 수치를 제시한다.**

## 앱별 방향


* 탐구 5(속력): 학생이 실험하는 파랑·초록 자동차는 각각 **거리 1번, 시간 1번**만 측정(값은 소수 첫째 자리: 파랑 122.0 cm·5.0초, 초록 100.0 cm·4.2초 — 현재 앱의 자동차-자료 대응을 확인해 그대로 유지). 계산기에 거리 ÷ 시간을 누르면 **결과를 소수 첫째 자리로 바로 표시**(24.4, 23.8 cm/s) → 기록. 학생이 반올림한 값을 입력·확인하는 단계 삭제(나눗셈 식을 계산기로 직접 누르는 활동은 유지). 빨강·노랑 교과서 예시 값(27.0, 17.2 cm/s)과 네 대 비교 분석은 유지. 반올림 관련 안내·힌트·피드백 문구 정리.

## 공통
* `CLAUDE.md` 과학 차시 앱 규칙(7분 기준, 질문 수) 계속 준수. 측정·기록 흐름이 짧아진 만큼 관련 안내문도 줄인다.
* 탐구 3·4·5 수치 일관성: 탐구 3 = 5.0초에 135.0 / 122.0 cm, 탐구 4 = 100.0 cm에 4.2 / 5.8초, 속력 27.0 / 24.4 / 23.8 / 17.2 cm/s. 화면의 모든 수치 표시는 소수 첫째 자리 형식으로 통일.
* 반복 측정·평균·오차 관련 코드와 문구(분석 질문·피드백·모범 답안 포함)를 정리한다. 남은 분석 질문이 여전히 학생 자신의 기록으로 답할 수 있게.
* 공통 틀 사본·`class1-record.js`·`config.js` 수정 금지. 저장 키를 `:v4`로 올린다(`sci6` 접두사 유지).
* `spec.md` 개정 절에 "개정 3 (측정 1회·소수 첫째 자리)"를 덧붙인다(기존 본문 삭제 금지).
* 수정 범위: `public/apps/sci-6-1-2-5/**`(위 제외 파일 빼고). git commit/push·실 DB 쓰기 금지.
