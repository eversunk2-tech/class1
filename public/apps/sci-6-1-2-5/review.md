## 5. 보안·품질

* **XSS**: 앱과 틀에 `innerHTML`/`insertAdjacentHTML` 사용이 없다. `SciSim.rich`는 텍스트 노드와 `<strong>`만 만든다. 결론에 `<img src=x onerror=alert(1)>`를 넣어 제출하니 글자 그대로 보였고 img는 0개였다.
* **SRI**: three.module.js, OrbitControls.js, supabase.js 2.116.0의 sha384를 CDN에서 직접 받아 계산했다. index.html:19-20, 27, 33, 122의 값과 모두 같다. crossorigin="anonymous"도 있다.
* **저장 payload**: detail JSON은 약 1,077자로 16KB보다 훨씬 작다. 키는 predict, records, transports, analysis, conclusion, extension, curiosity다. 학생 글은 입력칸 maxlength 1000이라 최대 약 5KB다. localStorage 키는 `sci612sim5:v1:*` 13개이고 합계 약 1.6KB다.
* **접근성**: 자동차 버튼에 이름과 색 칩이 함께 있어 색만으로 구분하지 않는다. 계산기 단추에 aria-label("나누기", "계산하기 =")이 있고 결과는 aria-live로 알린다. 관찰 메시지·교통수단 피드백도 aria-live다. 2D 차선 이름 버튼은 aria-pressed를 쓴다.
* **콘솔**: 모든 실행(가로·세로 다크·375 모바일·no3d)에서 오류·경고 0건이다. 지도서 값 자체 검사(app.js:46-48)도 조용했다.
* **RLS**: 새 테이블이 없고 `app_results`를 class1-record.js로만 쓴다. 이 앱에서 바꾼 정책은 없다.

## 6. 확인한 것 vs 못 한 것

**확인한 것** (자체 헤드리스 Chrome 153, CDP 포트 9583, 전용 프로필. 공유 Browser 패널과 다른 에이전트의 탭·프로세스는 건드리지 않았다. 이 앱의 localStorage 키만 지웠다)
* 지도서 220~231쪽 원문 전체 대조와 쪽 오프셋(+180) 확인. 모든 속력을 직접 계산하고 반올림 확인.
* 전체 흐름을 1024×768 라이트에서 끝까지 진행했다. 예상 게이트 → 힌트 3개 → 1단계 빨강·파랑(틀린 값 안내와 기록 잠김 → 맞는 값 → 계산기 식 자동 → `=` → 27.0/24.4) → 2단계 잠금 해제 → 초록·노랑(23.80952381 → 23.8, 17.24137931 → 17.2) → 분석 표·막대 → 교통수단 5가지(거꾸로 나누기 안내, 144.8÷2 오채점 발견 M1) → 퀴즈 4개(오답 → 정답 피드백) → 정리 3개(XSS 입력) → 궁금한 점 → 마치기(가짜 save로 detail 확인. 저장 실패 문구와 완료 카드 확인).
