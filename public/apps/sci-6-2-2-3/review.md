* "🕯 실험 장치 처음 상태로": 기록(2/4)은 남고 ㉠을 고르면 다시 "덮기"부터.
* 새로고침 복원, 앞 단계 이동, 결론 제출 뒤 마치기, "처음부터 다시 하기" 버튼 있음.
* 다크모드(375 3D, 768 2D): 2D 그림·HUD·시간 바·오개념 카드 모두 잘 읽힘.

## 소요 시간

**기계 측정**(자동 진행, 읽기·생각 시간 없음): 흐름 전체 약 33~38초(1024 3D 38.2초, 768 터치 35.9초, 375 다크 34.6초, 2D 32.8초). 실험하기 부분 약 27초(덮기 1.3초, 가열 연출 3.4초 포함).

**사람 추정**(화면 글의 70%를 읽음. 보통 400음절/분·입력 40자/분, 느린 학생 250음절/분·입력 25자/분, 탭 1.5/2초, 관찰·분석에서 한 번씩 틀린 뒤 다시 고름). 화면 음절 수는 실측: 실험 안내 569, 관찰 카드·피드백 223, 분석 280, 정리 188 + 모범 답안 41.

| 단계 | 보통 학생 | 느린 학생 |
|---|---|---|
| 예상하기(힌트 1개, 20자) | 약 1:05 | 약 1:40 |
| 실험하기(안내 + 덮기·시간 바 + 가열 + 4칸 관찰·확인·기록) | 약 2:15 | 약 3:25 |
| 기록·분석하기(표 2개 + 보기 2개) | 약 0:40 | 약 1:05 |
| 정리하기(오개념 카드 + 30자 결론 + 모범 답안 + 마치기) | 약 1:35 | 약 2:25 |
| **합계** | **약 5:35** | **약 8:35** |

Build의 추정(보통 4:35 / 느린 6:45)보다 입력 속도를 느리게 잡아서 길게 나왔다. 두 추정을 합치면 **보통 학생 약 4분 30초~5분 40초로 7분 안**, **느린 학생 약 6분 45초~8분 30초로 7분 경계**다. 차이는 대부분 두 번의 타이핑(예상·결론)에서 생긴다. 실험 조작 자체는 짧다. 실제 시간은 수업에서 확인해야 한다(2-5 앱처럼 그대로 둘지 사용자가 판단).
