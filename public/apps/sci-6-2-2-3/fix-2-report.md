## 2. 공통 틀 T1~T3과 하위 호환
* **T1 `runLabel` → `{ text, disabled }`**: `disabled: true`면 그 글자로 꺼진다. 틀 안에서 실행 버튼을 켜는 곳은 `draw()` 하나뿐(조건 바꾸기·실행 끝 `setBusy(false)`·기록·비우기·`exp.refresh()`가 모두 이것)이라 그때마다 `runLabel`을 다시 불러 정한다. 크게 보기 막대는 같은 엘리먼트를 옮기므로 상태가 하나다. 실행 중에는 예전처럼 `busyLabel`. 꺼 둔 조건에서는 `run()`도 멈추고 '다시 실행' 버튼을 숨긴다. **호환**: 문자열이면 `{ text: 문자열, disabled: false }`로 예전과 같다(모든 앱의 `runLabel`은 순수 함수 — 6-2-3-3의 `markSwitchRun`은 같은 조건에서 같은 결과라 한 번 더 불러도 같음). `retryLabel` 앱은 틀린 답 뒤에만 `runOff`를 부른다.
* **T2 `exp.observe(sel)`**: 실행 중·잠긴 단계·`skipCells`·조건 미완성(숨긴 보기 포함)이면 `false`. 값이 다르면 `select`처럼 바꾸고(`afterSelect`), 같은 칸 카드가 열려 있으면 그대로(`true`), 아니면 `trial = { sel, observed: null }` + `showObserve()`(실행 끝과 같은 카드·같은 스크롤 규칙). `scene[cellKey]` 저장, 기록 뒤 0.45초 조작 칸 올림 예약은 취소. **호환**: 새 API라 부르지 않으면 아무 일도 없다. 올림 예약은 핸들을 저장하게만 바꿨다(새 기록 전에 남은 예약을 지우는 것 외 동작 같음 — 기록은 0.45초 안에 두 번 일어날 수 없다).
* **T3 `columns: 1`**: `.cols-1` 클래스와 CSS 한 줄뿐. 다른 앱은 이 값을 안 쓴다.
