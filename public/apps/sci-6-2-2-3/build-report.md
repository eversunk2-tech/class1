## 2. 구현 요약
* **4단계**(예상 → 실험 → 기록·분석 → 정리). 궁금한 점은 본보기 앱처럼 정리하기 안의 선택 한 줄(결론 제출 뒤 보임).
* **예상하기**: 질문 1개(교과서 42쪽), 힌트 3개(spec 그대로, "산소"·"발화점" 없음), 5글자 이상.
* **실험하기**: 조건 고르기 하나에 보기 4개(㉠ 산소 공급 없음 / ㉡ 산소 공급 있음 / 성냥의 머리 부분 / 성냥의 나무 부분). 공통 틀 단계 잠금으로 실험해요 1(㉠·㉡)을 모두 기록해야 실험해요 2가 열린다.
  * **실험해요 1**: ▶ "두 촛불에 아크릴 통 덮기" → 크기가 같은 두 통이 동시에 내려와 덮는다(㉡ 통 안에는 묽은 과산화 수소수+아이오딘화 칼륨 비커, 기포 = 산소(모형)).
    덮으면 **시간 바**(모형, 시각 숫자 없음)가 켜진다. 끌면(터치·마우스·←/→·Home/End, 손잡이 44px, `aria-valuetext`, requestAnimationFrame으로 묶어 그림) ㉠ 불꽃이 점점 작아져 42% 지점에서 꺼지고 ㉡은 끝까지 탄다. "⏩ 끝까지 빨리 감기" 버튼도 있다.
    **시간 바를 끝까지 가야** 관찰 카드가 나온다(개정 1). 그 뒤에도 시간 바를 앞뒤로 끌어 다시 비교할 수 있다.
  * **실험해요 2**: ▶ "알코올램프로 철판 가운데 가열하기" → 램프에 불이 붙고 철판 가운데에서 열이 퍼지는 모습(모형) 약 3.4초 빨리 감기 → 머리 부분에 불이 붙고, 그 뒤 나무 부분은 불꽃 없이 색만 검게 변한다. 두 조각은 **철판 가운데로부터 같은 거리**(점선·"가운데로부터 같은 거리" 표시). 모래 상자, 장면 아래 뜨거움 주의 문구.
  * 같은 실험의 두 번째 조건은 장치를 다시 덮거나 다시 가열하지 않고 "▶ ○ 가까이 보기"로 그 부분에 다가간다(7분 기준). 처음부터 다시 하려면 "🕯 실험 장치 처음 상태로"(기록은 남음).
  * **관찰 카드**: "지금 모습"(아이콘+글자: 불꽃 있음/없음, 색이 검게 변함 — 시간 바를 끌면 실시간으로 바뀜) + 보기 2개(spec 그대로) + 확인하기. 맞아야 기록하기가 켜진다(공통 틀 `check`, 틀리면 다시 볼 곳 안내). 실험해요 2에서 맞히면 "발화점" 용어 한 줄.
  * 장면 오른쪽 위 HUD에 두 대상의 지금 모습, "⏩ 빨리 감기(모형)" 배지, "모형" 배지·모형 안내 문구. 패널에 내 기록 2×2 표(누르면 그 조건 고르기), 접이식 안전 수칙.
* **기록·분석하기**: 표 2개(실험 1: 조건 × 내 관찰 결과, 실험 2: 성냥 부분 × 내 관찰 결과, 글자 표·그래프 없음) + 보기 고르기 2개(spec 문구·피드백).
* **정리하기**: 오개념 카드("약 17 %", 채점 없음) → 결론 1개 → 모범 답안 비교(비교 도움말) → 궁금한 점(선택 한 줄) + 접이식 시스투스 읽을거리 → 학습 마치기.
* **완료 `detail`**: `predict`, `hintsOpened`, `records[{experiment, condition, result}]`, `analysis`, `conclusion`, `curiosity`, `qa`
  (`predict:q1:text`, `experiment:records:table`(열: 실험/조건/관찰 결과), `analyze:q1·q2:choice`, `conclude:conclusion:text`, `curiosity:curiosity:text` — spec 8절 표와 같음).
* **저장·복원**: 장면 상태(`sim`: 덮었는지·시간 바 위치·끝까지 봤는지·가열했는지·보이는 실험)와 고른 조건(`curSel`)을 store에 저장(공통 틀 Sync로 `app_progress`까지). 3D/2D 화면은 이 상태를 그리기만 해서 3D↔2D 전환·새로고침 뒤 같은 모습으로 돌아온다.

## 3. spec과 다른 점(판단)
1. **단계 수**: spec config 초안의 5단계 대신 본보기 2학기 1단원 앱과 같은 4단계(궁금한 점은 정리하기 안 선택 한 줄). `qa`의 stage는 spec 8절대로 `"curiosity"`.
2. **관찰 기록 방식**: 개정 1·공통 지침대로 타이핑 없음. spec의 보기 고르기를 두되 "확인하기"를 통과해야 기록된다(틀린 결과가 기록되지 않음 → 기록 값은 항상 spec 표와 같음). 관찰 카드에 "지금 모습"을 보여 준다.
3. **실험 반복 줄이기**: 같은 실험의 두 번째 조건은 장치를 다시 덮지/가열하지 않고 가까이 보기만(한 번의 실험에서 두 대상을 함께 관찰하는 실제 실험과도 같다).
4. **미니 진행 표**: 공통 틀 `miniTable`은 행·열 조건이 같아야 해서 쓰지 않고, 앱 전용 "내 기록" 2×2 표로 만들었다(공통 틀 변경 없음).
5. **시간 바 수치(모형)**: ㉠이 꺼지는 자리 42%, 불꽃이 작아지기 시작하는 자리 6%는 화면 연출용 모형 값이다(시각·초 숫자는 어디에도 보이지 않음). ㉡은 시간 바 끝까지 탄다.
6. **가열 연출 순서**: 머리 부분에 불이 붙은 뒤 나무 부분 색이 검게 변해 가게 했다(발화점 차이가 헷갈리지 않게). 화면에 "탄화" 용어는 쓰지 않고 "색깔만 검게 변한다"만 쓴다.
7. **꺼진 촛불 위 흰 김**: ㉠이 꺼진 직후 잠깐 흰 김이 올라가는 모양만 보여 주고 이름을 붙이지 않았다(다음 차시 내용·"생성물" 언급 없음). 없애도 되는 연출이다.
8. **문구 조정**: 분석 정답 피드백 앞의 "맞아요!"를 뺐다(공통 틀이 "⭕ 맞았어요!"를 붙임). 나무 부분 발화점 안내는 "이렇게"를 뺀 문장. 결론 비교 도움말 한 줄, 궁금한 점 placeholder 추가. 실험 안내는 3문단으로 줄였다.
9. **3D 시점**: 공통 틀의 처음 시점은 실험해요 1에 맞추고, 실험해요 2로 바뀌면 앱이 조금 위·가까운 시점으로 옮긴다("처음 방향으로"도 실험 2에서는 그 시점). 휴대폰(가로 480px 미만)에서는 3D 이름표를 1.45배 키운다.
