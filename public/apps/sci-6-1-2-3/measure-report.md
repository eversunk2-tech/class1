# measure-report — sci-6-1-2-3 측정 단순화 (2026-09-22)

수정 파일: `app.js`, `data/lesson-config.js`, `index.html`, `style.css`, `spec.md`(끝에 "개정 3" 절 추가만). `science-sim/`, `class1-record.js`, `config.js`는 그대로. 커밋·실 DB 쓰기 없음.

## 바뀐 흐름
실험하기: ▶ 두 자동차 동시에 출발(5.0초 실제 시간, 📸 사진 뒤에도 계속 달림) → 사진 카드 → **📏 측정하기**(공통 틀 `check` 훅, 입력 칸 0개) → "● 빨간색 자동차 135.0 cm / ■ 파란색 자동차 122.0 cm" 표시 → **📝 기록하기**(측정 전에는 꺼져 있음). 오차 없는 지도서 값. 기록 `{ time: 5, red: 135, blue: 122 }`, 화면 표시는 모두 소수 첫째 자리(5.0초, 135.0 cm).

## 삭제한 코드·문구
* 코드: `noise` 무작위 오차와 x.5 회피, `measure` 입력 범위, `zoomSVG`·확대 버튼, 입력 확인 리스너(`read-check`), `offCars`·`recheck-note`(index.html 요소 포함), `obsRun`, 기록 `actual`/detail `photo`, 관련 CSS(`zoom-*`, `zm-*`, `read-check`, `recheck`, `obs-photo`).
* 문구: "반올림해 일의 자리까지(cm) 읽어 기록", "사진을 확대해… 반올림해 기록해요", "잴 때마다 조금씩 다른 것은 실제 실험의 작은 오차", "다시 재 보고 싶으면 한 번 더 달려 보세요", 입력 경고(정수로 적어요 / 눈금과 차이가 커요), 분석 화면 재확인 안내.
* 5초 → 5.0초(예상 질문, 조건 버튼, 실행 버튼, 타이머, 사진 캡션, 표 열, 그래프 범주, 분석 1·2 문장·피드백, 완료 카드). 그래프·표 값 `digits: 1`.
* 저장 키 `sci612sim3:v4`.

## 확인한 것
자기 전용 headless Chrome(스크래치 프로필, 포트 8773 정적 서버) + 가짜 세션 + 가짜 Supabase(CDP Fetch 가로채기, 실제 네트워크 0건).
* 1024×768 3D, 800×1100 3D, 375×812 다크·터치 3D, `?no3d=1` 2D: 모두 끝까지 완료, 콘솔 오류 0, 가로 스크롤 0, 다크 배경 rgb(17,22,31), 3D 캔버스 1개(2D 0개).
* 측정 전 기록하기 꺼짐, 다음 단계 막힘("…이동 거리를 측정해 기록해야…"). 측정 후 135.0 / 122.0 cm 표시.
* 분석 1 정답 피드백에 "135.0 cm… 122.0 cm", 분석 2 '멈춘 곳' 오답 피드백 확인. 결과 저장(app_progress GET/POST/PATCH, app_results POST completed).
* 새로고침 복원: 달리기 도중 새로고침 → 실험하기 단계·예상 답 복원, 다시 달려 정상 진행. 마친 뒤 새로고침 → 정리하기·완료 카드·결론 복원, 로컬 키 `sci612sim3:v4:*`.
* 화면 글 전체에서 "반올림/평균/오차" 0건, 소수 둘째 자리 이상 수치 0건. 소스 grep도 같음(3D 좌표 상수 제외).
