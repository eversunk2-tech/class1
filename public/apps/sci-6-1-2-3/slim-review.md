## 시간표
측정: 자기 전용 headless Chrome(CDP)에서 가짜 세션과 가짜 Supabase 응답(페이지 안 fetch 가로채기, 실제 DB 요청 0건)으로 끝까지 5번 진행했다(1024×768 3D, 800×1100 3D, 375×812 다크·터치 3D, `?no3d=1`, 다시 1024×768). 기계 시간에는 자동화 대기(3D 준비 1.5초 등)도 들어 있다.
사람 시간은 추정이다. 단계마다 화면에 새로 나타난 문장 줄의 한글 음절 수를 셌다(예상 148, 실험 596, 분석 505, 정리 350). 그중 70%를 읽는다고 보고 아래 속도를 적용했다.
* **보통 학생**: 읽기 450음절/분, 입력 60자/분, 서술 전 생각 8초, 탭 1.5초, 눈금 읽기 6초/값, 보기 문항 6초, 틀려서 다시 고르기 1번
* **느린 학생**(읽기·타자 느림): 읽기 300음절/분, 입력 40자/분, 생각 12초, 탭 2초, 눈금 10초/값, 보기 10초, 다시 고르기 2번
* 답 길이: 예상 25자, 결론 30자

## 수업 목표·수치 일관성
* 지도서 4차시 목표(인쇄 206쪽): "같은 시간 동안 이동한 물체의 빠르기를 비교하는 방법을 설명", "이동 거리를 측정하고 빠르기 비교"가 남아 있다. 사진 확대 → 눈금 읽기 → 기록 → 비교 → 결론 순서다.
* 수치: 참값 135 / 122 cm(27.0 / 24.4 cm/s × 5초)이고 오차는 ±1 cm 이내다. 측정 예: 134.1 → 134, 135.4 → 135, 122.4 → 122. 탐구 5의 표(135 / 122 cm)와 맞는다.
* 다음 차시 용어: 모든 단계의 화면 글에서 "속력", "÷", "cm/s"가 한 번도 나오지 않는다.
