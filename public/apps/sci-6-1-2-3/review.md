**과학적 정확성 결론**: 화면의 사실·수치는 모두 지도서와 맞거나 일반 과학 지식으로 옳다. 5초 참값 135 / 122 cm(207, 211쪽)가 참속도 27.0 / 24.4 cm/s와 정확히 맞고, 3초(81 / 73.2)와 8초(216 / 195.2)도 거리 = 속도 × 시간으로 일관된다. 실측 18회 모두 참값 ±1 cm 이내였고(예: 빨강 5초 134.2~135.9, 파랑 3초 72.7~73.1), 가장 작은 차이(3초, 약 8 cm)에서도 순위는 바뀌지 않는다. 화면 어디에도 '속력', 거리÷시간, cm/s·m/s·km/h가 나오지 않는다(주석에만 있음). 1초 거리 표 5개 값은 210쪽 원자료로 다시 계산해도 맞다(5.5/19.59 = 0.28, 100/9.58 = 10.4, 139.39 km/h = 38.7, 389.46 km/h = 108.2, 480.23 km/h = 133.4 m/s). "평균적인 빠르기가 아님" 안내(208쪽 지도 길잡이 6)도 붙어 있다. Build가 바꾼 **발전 질문 2 모범 답안은 사실이다**: 사이클 아워 레코드(1시간 동안 달린 거리)와 육상 1시간 달리기(세계육상 공인 종목)는 실제로 같은 시간 동안 간 거리로 겨루는 기록이고, spec 원안의 "정해진 시간 동안 … 여러 육상·수영 경기"는 대부분 같은 거리 경기라서 고친 판단이 옳다. 남은 문제는 값이 아니라 **표현과 교수 설계(D1~D3)**다.

## 5. 보안·품질

- XSS: 예상 질문 2에 `<img src=x onerror=alert(1)>`, 발전 2에 `<script>alert(1)</script>`를 넣었다. 글자 그대로 보이고 새로고침 뒤에도 `main img` 0개, 정리하기 안 `img`·`script` 0개였다. 앱과 공통 틀에 `innerHTML` 사용 없음(persist.js:118 주석뿐). 앱은 SVG를 `createElementNS`·`textContent`로 만든다.
- CDN SRI: three.js 0.169.0(importmap integrity + modulepreload integrity·crossorigin), supabase-js 2.116.0(script integrity·crossorigin) 있음.
- 저장 크기: textarea 6개 모두 maxlength 1000. 최악(6개 모두 따옴표 1000자) + 기록 18개 + 분석 6문항으로 detail을 만들어 보니 JSON 13,607자로 `DETAIL_MAX_CHARS` 16,000 안이다. 기록은 칸마다 3회로 제한되어(가장 오래된 회차를 덮어씀) 늘어나지 않는다.
- 접근성: 확대 버튼 `aria-expanded`, 점 그림·확대 사진 `role="img"`와 aria-label, 참고 표 caption·scope, 자동차를 색과 모양(●/■)으로 함께 구분, 그래프 계열도 테두리로 구분. 다크모드 배경 rgb(17,22,31), 경주로 그림은 사진처럼 밝은 바닥 유지.
- 공통 틀 사본: `diff -r scripts/templates/science-sim public/apps/sci-6-1-2-3/science-sim` 결과 차이 없음.
- 콘솔 오류: 전체 흐름과 새로고침 뒤 0건.

## 6. 확인한 것 vs 못 한 것

**확인한 것** (개발 서버 `http://localhost:3000/class1/apps/sci-6-1-2-3/index.html`, 공유 Browser 패널의 내 탭만 사용)
- 지도서 206~213쪽 전체와 단원 개관(180~185쪽)을 텍스트로 뽑아 화면의 모든 사실, 수치, 분석 정답·피드백, 모범 답안, 힌트와 대조했다. 1초 거리 표는 210쪽 원자료로 다시 계산했다.
- 전체 흐름(창 800×969 세로형): 예상(힌트 3개) → 실험 18회(빨강 5초 1회는 일부러 141 cm) → 분석 표(틀린 회차 알림 확인)·그래프 → 분석 6문항 오답 피드백 후 정답 → 결론·발전 2 제출 → 궁금한 점 → 마치기(비로그인 안내, "18번, 6/6").
- 실측값 18개 모두 참값 ±1 cm 이내, 순위 역전 없음. 입력 확인: 6 cm 차이면 "다시 확인" 안내, 소수 입력이면 반올림 안내.
- 실제 시간: 3D 5초 실행의 타이머가 벽시계 0.5초마다 0.5초씩 증가, 2D 3초 실행도 같음. 실행 시간 = 선택 시간 + 약 2~2.5초(준비·카메라·셔터).
- 휴대폰 375×812 다크(3D): 달리는 동안 3D 캔버스가 화면 167~465px에 계속 보임. 모든 단계 scrollWidth = 375(가로 스크롤 없음).
- `?no3d=1`(1024×768): 캔버스 0개, 토글 "3D를 쓸 수 없는 기기예요"(비활성), 2D 실행·타이머 정상, scrollWidth 1024.
- 3D↔2D 12번 전환: 캔버스 0/1개 반복, 누적 없음. 새로고침 복원 확인. 확대 화면(1 mm 눈금, 앞부분 점선) 캡처 확인.
- 끝난 뒤 이 앱 키(`sci612sim3:*`)만 지우고 내 탭을 닫았다. 다른 앱 키는 건드리지 않았다.
