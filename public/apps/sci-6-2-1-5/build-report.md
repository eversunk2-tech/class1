## 2. 구현 요약
* 4단계(예상 → 실험 → 기록·분석 → 정리). 궁금한 점은 본보기 앱처럼 정리하기 안의 선택 한 줄(결론 제출 뒤 보임).
* **실험(개정 1)**: 조건 ① 자전축(수직/기울임) × ② 위치(가·나·다·라) = 8칸. 1단계(수직 4칸)를 다 기록해야 2단계(기울임)가 열린다(공통 틀 phase 잠금).
  위치를 고르고 ▶ → 지구본이 궤도를 따라 공전 방향으로 약 1.5초 이동(자전하며, "⏩ 빨리 감기(모형)" 표시) → 측정기가 전등을 정면으로 향하도록(남중) 맞춘 뒤 전등 쪽 가까운 시점으로 다가가 그림자를 보여 준다 →
  관찰 카드 **값 패널**에 "그림자 길이 1.4 cm"와 **확대 눈금(0.1 cm 눈금, 모형)** → **기록하기**(타이핑 없음, 공통 틀 `fields: []`). 기록하면 다음 빈칸이 자동으로 골라진다.
* 값은 spec 표 그대로: 수직 1.4/1.4/1.4/1.4, 기울임 1.4/0.8/1.4/3.5 cm(소수 첫째 자리). 8칸 모두 "내 기록".
* **과학 규칙**: 지구본을 `자리(궤도 이동)` → `기울기(우주 기준 고정)` → `자전` 세 트랜스폼으로 나눠, 공전하는 동안 자전축 방향이 절대 바뀌지 않게 했다.
  공전은 위에서 볼 때 시계 반대 방향(가→나→다→라). 기울임일 때 자전축은 늘 같은 쪽(+x)으로 기울어 **나에서 북반구가 전등 쪽(그림자 0.8 cm), 라에서 반대쪽(3.5 cm)**, 가·다는 옆으로 기움(1.4 cm).
  빛은 전등 → 지구본 방향의 평행광(DirectionalLight). 그림자의 방향은 이 빛으로 계산하고, 길이는 교과서 예시 값을 쓴다. 측정기는 북위 37.5°에 붙였다.
* 2D 대체(`?no3d=1`·3D 불가): 교과서 그림처럼 비스듬히 본 타원 궤도, 전등, 가~라, 지구본(자전축 선 + 수직 기준 점선 + 밤 쪽 어둡게 + 측정기 점). 자전축 선은 궤도 어디서나 같은 방향.
* 분석: 표(위치 × 자전축 조건) + 막대그래프(2계열, 범례·무늬) + 보기 2개(spec 문구·피드백 그대로).
* 정리: 오개념 카드(채점 없음) → 결론 1개 → 모범 답안 비교(`compareTip`) → 궁금한 점 선택 한 줄 → 학습 마치기.
* 완료 `detail`: `predict`, `hintsOpened`, `records[{tilt, position, shadowCm}]`, `shadows{조건:{위치:값}}`, `analysis`, `conclusion`, `curiosity`, `qa`
  (`predict:q1:text`, `experiment:records:table`(열: 위치/자전축 수직(cm)/자전축 기울임(cm)), `analyze:q1·q2:choice`, `conclude:conclusion:text`, `conclude:curiosity:text`).
* 새로고침 복원: 단계·기록·지구본 자리(`globeAt`)·고른 조건(`curSel`)을 store로 저장(공통 틀 Sync로 `app_progress`까지).

## 3. spec과 다른 점(판단)
1. **예상 힌트 3 변경**: spec의 "자전축이 기울어져 있으면 … 태양 빛이 닿는 각도가 달라질지"는 질문의 답(기울기 → 남중 고도 달라짐)을 거의 말해 버려서
   "지구본을 들고 전등 둘레를 한 바퀴 돌린다고 상상해 보세요. 우리나라에 세운 막대의 그림자는 어떻게 될까요?"로 바꿨다. 힌트 1·2는 spec 그대로.
2. **단계 수**: spec config 초안의 5단계(궁금한 점 별도) 대신 본보기 앱과 같은 4단계로 두고, 궁금한 점은 정리하기 안 선택 한 줄로 넣었다(CLAUDE.md 새 기준과 같음). `curiosity.qa`의 stage는 본보기처럼 `"conclude"`.
3. **남반구 문장**: spec 3.5의 접이식 안내를 "🌏 더 생각해 볼까요?(선택)" `<details>`로 넣었다(채점·입력 없음).
4. **오개념 카드 마지막 문장**: "다음 질문에서" → "아래 질문에서"(카드가 결론 문항 바로 위에 있어서).
5. 결론 비교 도움말(`compareTip`)을 한 줄 더했다(본보기 앱 방식).
6. 실험 안내·모형 안내 문구는 7분 기준에 맞춰 spec 도입 문구를 줄여 합쳤다(변인 통제·자전축 방향 고정·평행광·크기/거리 미반영·23.5°·빨리 감기·교과서 예시 값은 모두 남김). 안전 수칙(전등 오래 보지 않기·맨손으로 만지지 않기)은 접이식 카드.

* 끝까지 진행(예상 → 8칸 기록 → 분석 2문항(1번은 오답 뒤 정답) → 결론 제출 → 마치기) 성공, 콘솔 오류 0, 가로 스크롤 0:

* 다크모드: body 배경 rgb(17,22,31), 3D 탁자·궤도 색 전환, 2D 궤도 그림·값 패널·눈금 가독성 확인(스크린숏).
* 기록 값: 8칸 모두 값 패널 = spec 표(1.4·1.4·1.4·1.4 / 1.4·0.8·1.4·3.5), 분석 표·`detail.qa` 표도 같은 값. 기록하기는 값이 보이자마자 켜짐(타이핑 없음).
* 잠금·게이트: 1단계 전 "자전축 기울임" → "자전축 수직 실험(4칸)을 모두 기록하면 자전축 기울임 실험이 열려요." / 3칸 기록 뒤 다음 단계 → "(기록한 칸: 3/8)" 안내.
