## 다시 확인한 것
자기 전용 headless Chrome(CDP 포트 9377, 스크래치 프로필)과 개발 서버를 썼다. 가짜 세션과 페이지 안 가짜 fetch로 Supabase 요청에 응답했고, supabase 도메인은 막아 두었다. 실 DB 요청은 0건이다. 공유 브라우저와 `localStorage.clear()`는 쓰지 않았고, 끝난 뒤 Chrome 프로세스는 0개다.
* **전체 흐름 끝까지** 5가지를 진행했다: 1024×768 3D, 768×1024 3D, 375×812 3D 다크(모바일), 768×1024 2D, 375×812 2D(모바일). 모두 기록 4/4, `qa` 6항목, 가로 스크롤 0, **콘솔 오류 0**이었다.
* **기록하기 버튼 위치**는 확인하기 뒤 0.9초에 쟀다. 모든 칸에서 버튼 아래끝이 하단 막대 윗끝보다 위에 있었다.
  * 1024×768: 604–660 또는 631–687, 막대 699
  * 768×1024: 868–924 또는 887–943, 막대 955
  * 375×812: 656–712 또는 675–731, 막대 743
  * 고치기 전(리뷰)에는 665–721 / 921–977 / 736–792로 가려졌다.
* 기록 값: 표·detail이 "아무런 변화가 없다 / 밀가루가 가라앉는다 / 점점 부풀어 오른다 / 보글거리며 기포가 생긴다"로 나왔다. 코드 전체에서 "(기체)"를 검색해도 0건이다.
* 머리말 글자가 새 문구로 표시된다. 학생 화면에 "연소"가 나오는 곳은 머리말 단원 이름 한 곳뿐이다. 이산화 탄소·불꽃·탄다·물리/화학 변화·지도서는 0건이다.
