## 2. 구현 요약
* **예상하기**: 질문 1개(10글자 이상), 힌트 3개는 spec 문구 그대로(결과를 말하지 않음). 안내 한 줄에서 "탄산수소 나트륨(흰 가루)"을 한 번 풀어 씀(열린 질문 4 추천안).
* **실험하기**(관찰 방법형, 2 × 2 = 4칸, 조건마다 1회):
  * 조건 ① 가루 물질(밀가루/탄산수소 나트륨) ② 살펴볼 것(고무풍선의 변화/삼각 플라스크 안의 변화). 3D에서 플라스크나 고무풍선을 눌러도 고를 수 있다. 고른 쌍 아래에 파란 고리가 생긴다.
  * **섞기**(약 3.6초 + 카메라 이동): ① 옆으로 늘어진 고무풍선을 세움 → ② 가루 알갱이가 식초로 떨어짐 → ③ 결과. 밀가루: 가루가 바닥에 가라앉아 쌓이고 식초가 조금 뿌예짐, 고무풍선은 부풀지 않은 채 힘없이 기움. 탄산수소 나트륨: 식초 속에서 방울이 계속 올라오고(윗면 거품 층) 고무풍선이 빠르게 부풂(모형). 끝나면 고른 관찰 대상 쪽으로 카메라가 다가감.
  * **살펴보기**(열린 질문 2 추천안): 이미 섞은 가루에서 살펴볼 것만 바꾸면 애니메이션 없이 카메라만 이동(약 1초). 같은 칸을 다시 실행하거나 관찰 보기를 틀려 "🔁 다시 섞어 보기"를 누르면 그 쌍을 처음 상태로 되돌려 다시 재생. 실행 버튼 글자가 "▶ 고무풍선을 세워 섞기 / 👀 … 살펴보기 / 🔁 다시 섞어 보기"로 바뀌고, 살펴보기일 때는 조건 카드 아래에 "이미 섞었어요" 안내가 뜬다.
  * **관찰 카드**(개정 1): 본 모습을 글로 보여 주고(예: "고무풍선이 조금씩 커지면서 둥글게 부풀고 있어요."), 실험관찰 문구 보기 2개 중 고른 뒤 ✔️ 확인하기 → 본 것과 같아야 📝 기록하기가 켜진다. 틀리면 "방금 본 모습과 다른 것 같아요…" + "🔁 다시 섞어 보기" 버튼. 타이핑 없음.
  * 한 칸을 기록하면 같은 가루의 남은 칸을 먼저 골라 준다(`onRecorded`) → 두 번째 칸은 '살펴보기'만 하면 된다.
  * 알아 두기 카드: 실험 방법 2문단 + 안전 한 줄(유리 기구·맛보지 않기·피부 접촉·환기) + 접었다 펴는 "📚 교과서 속 다른 예(참고)" 4줄(우유+식초, 손난로, 설탕물, 꿀물, 진행 잠금에 넣지 않음).
  * 모형 표시: 틀의 "모형" 배지 + 장면 오른쪽 위 "🏷 모형: 빠르게 보여줘요" 배지(3D·2D 모두 항상) + 장면 아래 모형 안내 문장.
  * 미니 표 2×2, "🧽 실험대 처음처럼 되돌리기"(기록은 그대로).
* **기록·분석하기**: `TableChart.renderMatrix` 관찰 결과 표(가루 물질 × 살펴본 것, 아이콘+글자 ➖/🎈/⬇️/🫧, 색으로 구분하지 않음) + 분석 2문항(spec 문구·정답·오답 피드백 그대로).
* **정리하기**: 결론 1개(제출해야 모범 답안 보임, 비교 도움말) + 궁금한 점 선택 한 줄 + 학습 마치기. 발전 질문 없음.
* 단계 잠금: 실험 ← 예상 10글자 / 분석 ← 4칸 기록 / 정리 ← 분석 2문항 확인 / 마치기 ← 결론 제출.
* 완료 저장 `detail`: `predict`, `hintsOpened`, `records`(가루·대상·결과·시각), `analysis`, `conclusion`, `curiosity`, `qa`(predict/q1 text, experiment/records table(가루 물질·고무풍선의 변화·삼각 플라스크 안의 변화), analyze/q1·q2 choice, conclude/conclusion text, curiosity/curiosity text). 약 2.1천 자.
* 로그인 필수·`app_progress` 자동 저장·로그아웃 삭제·완료 저장은 공통 틀 그대로 연결(앱에서 localStorage를 직접 쓰지 않음).

## 3. spec과 다른 점(작은 것)
1. **머리말·설명에 단원 이름 대신 "2단원"**: spec 3.0이 "연소"라는 낱말을 "어디에도 쓰지 않는다"고 해서 머리말 작은 글자를 "6학년 2학기 · 2단원 · 탐구 1"로, meta 설명도 "2단원 탐구 1"로 적었다. 단원 이름을 보여 주기로 하면 `index.html` 두 곳만 바꾸면 된다(Claude 판단 필요).
2. **분석 정답 피드백의 앞말 "맞아요!" 삭제**: 공통 틀 `quiz.js`가 "⭕ 맞았어요!"를 붙여 "맞았어요! 맞아요!"로 겹쳐서 config에서 "맞아요! "만 뺐다. 나머지 문구는 spec 그대로.
3. **config 형식**: 분석 보기는 틀 형식에 맞춰 `{ id, label }`·`answer: [id]`로 바꿈(보기 글자는 같음). 관찰 카드의 '본 모습' 문장(`seen`), 결과 아이콘, 결론 비교 도움말(`compareTip`), 궁금한 점 예시 문구는 앱에서 더함(학생 기록·채점과 무관).
4. 플라스크 이름표의 "식초", 고무풍선 색(밀가루 쌍 빨강·탄산수소 나트륨 쌍 파랑)은 구분용 모형 색이며 항상 글자 이름표와 함께 나온다.
5. 공통 틀 변경 필요 없음.

## 4. 측정 소요 시간

자동 진행(입력·선택은 즉시, 애니메이션은 실제 시간) 기준 한 번 끝까지 약 **17~26초**. 실행 버튼을 누른 뒤 관찰 카드가 뜨기까지: 섞기 **약 4.9~5.2초**(3D, 스크롤·카메라 이동 포함) / 3.5~4.0초(2D), 살펴보기 **약 1.1~1.5초**(3D) / 0.5초(2D).

## 5. 확인한 것
자기 전용 headless Chrome(CDP 포트 9377, 스크래치 프로필) + 개발 서버 `localhost:3000/class1/apps/sci-6-2-2-1/`. 가짜 세션(localStorage)과 페이지 안 가짜 fetch로 Supabase 요청을 모두 메모리에서 응답했고, `--host-resolver-rules`로 supabase 도메인을 막아 실 DB 요청 0건. 공유 브라우저 탭은 쓰지 않았고 `localStorage.clear()`를 쓰지 않았다.
* **전체 흐름 끝까지(예상 → 4칸 → 분석 2문항 → 결론 → 마치기)** 7가지: 1024×768 3D, 768×1024 3D, 768×1024 3D 다크, 375×812 3D 다크(모바일·터치 에뮬레이션), 1024×768 2D(`?no3d=1`), 768×1024 2D, 375×812 2D 다크. 모두 진행 4/4, 가로 스크롤 0, **콘솔 오류·경고·예외 0**.
* 기록 값: 분석 표·`detail.records`·`qa` 표가 spec 1.3 표와 글자까지 같음(밀가루: 아무런 변화가 없다 / 밀가루가 가라앉는다, 탄산수소 나트륨: 점점 부풀어 오른다 / 보글거리며 기포(기체)가 생긴다).
* 관찰 오답 → 피드백·기록 버튼 꺼짐·"🔁 다시 섞어 보기" 표시, 분석 오답 → spec 피드백, 결론에 `<b>` 입력 → 글자 그대로 표시(innerHTML 미사용).
* 완료 payload: `completed: true`, `detail.qa` 6항목, 궁금한 점 비워도 마쳐짐, `app_progress` 저장 요청 발생.
* 새로고침 복원: 실험 단계·기록 1/4·예상 글 복원, 섞은 장면도 복원되어 같은 가루의 다른 칸이 "👀 살펴보기"로 나옴.
* 3D↔2D 6번 전환: 캔버스 0↔1개, 장면 위 안내 0↔1개(쌓이지 않음). 실험대 되돌리기 후 실행 버튼이 "▶ 섞기"로 돌아옴. 앞 단계 이동·다시 실행 확인.
* 배치: 세로 태블릿 3D·2D — 실행 중 장면이 머리말 아래 한 화면(173–583 px), 실행 후 관찰 카드와 기록 버튼(868–924 px)이 하단 막대(955 px) 위에 보임. 가로 1024×768 — 장면(sticky)과 관찰 카드·기록 버튼(612–668 px)이 한 화면. 375×812 — 관찰 카드·기록 버튼(656–712 px)이 하단 막대(743 px) 위.
* 로그인 없음: "🔒 로그인이 필요해요" 가림막, `sci6…` 로컬 키 0개.
* 화면 글자·aria-label·title·placeholder에서 "연소·탄다·불꽃·이산화·물리 변화·화학 변화·지도서" 검색 0건(코드 주석에만 단원 이름이 있음).
