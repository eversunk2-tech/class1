- 전체 흐름을 확인했다: 예상(힌트 3개) → 실험 8칸(1칸 일부러 틀린 뒤 다시 기록) → 새로고침 복원 → 분석 표(8칸이 지도서와 일치, `#time-note`) → 퀴즈(q1 '두 용액 모두' 오답 피드백 뒤 정답, 4/4) → 결론·발전 2개(모범 답안, XSS 입력 시 img 0개) → 궁금한 점 → 마치기(비로그인 안내, "8칸, 4/4").
