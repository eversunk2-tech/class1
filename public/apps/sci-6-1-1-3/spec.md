## 1. 지도서 분석

### 1.1 차시 개요 (지도서 129, 135쪽)

- 성취기준 `[6과09-02]` 산성 용액과 염기성 용액의 성질을 관찰하고, 산성 용액과 염기성 용액을 섞을 때 용액의 성질 변화를 실험을 통해 추론할 수 있다. (지도서 108, 129, 135, 137쪽 — 이 성취기준은 5차시와 6차시(섞기)에 걸쳐 있으며, **이 차시(5차시)는 "성질 관찰" 부분만** 다룬다.)
- 학습 모형: **순환 학습 모형**(지도서 136~137쪽 교수·학습 과정안) — 탐색(예상하기) → 개념 도입(실험·정리) → 개념 응용(발전 질문) 흐름. `CLAUDE.md`의 예상하기→실험하기→기록·분석하기→정리하기 4단계와 자연스럽게 대응된다.
- 앞 차시(3~4차시, `sci-6-1-1-2`)에서 이미 지시약으로 산성/염기성 용액을 분류했으므로, 이 차시는 **지시약·색깔 변화가 아니라** 산성 용액(묽은 염산)·염기성 용액(묽은 수산화 나트륨 용액)이 **다른 물질과 반응해 녹이는 성질**을 다룬다. 이 차시에서 "지시약" 개념을 다시 등장시키지 않는다.

### 1.2 준비물 (지도서 108, 129, 134쪽)
- 모둠: 묽은 염산, 묽은 수산화 나트륨 용액, 6홈판 2개, 실험 도움판 ②(실험관찰 73쪽), 달걀 껍데기, 조개껍데기, 삶은 달걀흰자, 삶은 닭 가슴살, 핀셋 2개(용액이 섞이지 않도록 홈판마다 핀셋을 따로 사용, 지도서 131, 136쪽)
- 개인: 실험복, 보안경, 실험용 장갑
- 대체 재료(지도서 129쪽 준비물 길잡이): 달걀 대신 메추리알, 삶은 닭 가슴살 대신 두부로 대체 가능.
- 농도 주의(지도서 129쪽): **이 차시의 묽은 염산·묽은 수산화 나트륨 용액은 1 M 정도**로, 다른 차시(예: 3~4차시 0.1 M, 지도서 112쪽)보다 **더 진한 용액**을 쓴다 → "다른 차시보다 안전 교육을 철저히" 명시. 앱의 안전 안내 문구에 이 점을 반영한다.
- 안전(지도서 129, 130, 133, 134쪽): 실험복·보안경·실험용 장갑 필수, 환기가 잘 되는 곳에서 실험, 유리 기구 주의, 용액이 피부/눈에 닿으면 흐르는 물로 충분히 씻고 보건실(필요시 병원 진료), 묽은 염산 냄새를 흡입한 경우 신선한 공기를 마시고 휴식(심하면 병원), 임의로 맛보거나 냄새 맡지 않음, 실험 후 지정된 곳에 폐기(묽은 염산→산, 묽은 수산화 나트륨 용액→알칼리계 폐수통, 지도서 134쪽).

### 1.3 실험 결과표 (반드시 이 값만 사용)

**출처: 지도서 130~131, 133~134쪽(실험관찰 11쪽 결과), 4가지 물질 × 2가지 용액**

| 물질 | 주요 성분 | 묽은 염산(산성 용액) | 묽은 수산화 나트륨 용액(염기성 용액) |
|---|---|---|---|
| 달걀 껍데기 | 탄산 칼슘 | 기포가 발생하며 녹는다 | 변화 없다 |
| 조개껍데기 | 탄산 칼슘 | 기포가 발생하며 녹는다 | 변화 없다 |
| 삶은 달걀흰자 | 단백질 | 변화 없다 | 시간이 지나면서 녹아 흐물흐물해진다 |
| 삶은 닭 가슴살 | 단백질 | 변화 없다 | 시간이 지나면서 녹아 흐물흐물해진다 |

- 위 표는 지도서 131쪽 "정리해요"("달걀 껍데기와 조개껍데기를 산성 용액에 넣으면 기포가 발생하며 녹지만, 염기성 용액에 넣으면 아무런 변화가 없습니다. 삶은 달걀흰자와 삶은 닭 가슴살을 산성 용액에 넣으면 아무런 변화가 없지만, 염기성 용액에 넣으면 시간이 지나면서 녹아 흐물흐물해집니다.")과 134쪽 실험관찰 결과 표(구분×물질 4개, 정확히 동일한 값)에서 그대로 가져왔다.
- **일반 규칙**(지도서 131, 133쪽): 산성 용액(묽은 염산)은 달걀 껍데기·조개껍데기의 주요 성분인 **탄산 칼슘**과 반응하고, 염기성 용액(묽은 수산화 나트륨 용액)은 삶은 달걀흰자·삶은 닭 가슴살의 주요 성분인 **단백질**과 반응한다. 이 성분-반응 관계가 이 차시의 핵심 개념이며, 분석 질문에 반드시 반영한다.
- **시간 차이(중요, 반드시 반영)**: 탄산 칼슘 반응(기포 발생하며 녹음)은 **실험 중 바로 관찰**되지만, 단백질 반응(흐물흐물해짐)은 **수업 시간 안에 나타나지 않는다**(지도서 131, 135쪽 유의점: "묽은 수산화 나트륨 용액과 삶은 달걀흰자 및 삶은 닭 가슴살의 반응은 오래 걸릴 수 있습니다", "홈판의 뚜껑을 닫아 안전한 곳에서 보관하여 변화 과정을 관찰하거나 교사가 미리 실험하여 결과물을 보여 준다"). 실제 교실에서도 학생은 이 반응을 즉시 보지 못하고 지도서 131쪽 "탐구 결과 예시" 사진(일주일 후)으로 확인한다. → 앱의 3D 실험은 이 반응을 **빨리 감기(시간 경과) 연출**로 보여주되, 화면에 "모형: 실제로는 시간이 훨씬 오래 걸려요(예: 여러 날)"라고 반드시 밝힌다.
- 지도서에 이 차시 전용 "오개념" 박스는 없다(118~137쪽 범위 확인 완료). 다만 지도 길잡이에서 반복 경계하는 오해는 "물질이 녹는 것이 우연이거나 재료가 원래 약해서"라는 생각이며, 실제로는 **성분(탄산 칼슘/단백질)과 용액 성질의 반응**임을 분석 단계에서 짚는다.

### 1.4 탐구 과정 단계 (지도서 130~131쪽, 순환 학습 모형 135~137쪽)
1. (도입, 5분) 산성 용액·염기성 용액의 성질 중 아는 것 이야기하기(예: 식초·레몬즙은 신맛, 빨랫비누 물·제빵 소다 용액은 미끈미끈함) → 산성 용액인 식초에 달걀을 일주일 정도 담가 두면 어떻게 될지 예상해 보기(135쪽 "탐색: 예상하기").
2. (전개, 30분) [탐구 활동] 실험 도움판 ②에 6홈판을 각각 올려놓고, 표시된 홈에 묽은 염산과 묽은 수산화 나트륨 용액을 2/3 정도씩 넣는다.
3. 각 홈에 달걀 껍데기, 조개껍데기, 삶은 달걀흰자, 삶은 닭 가슴살을 각각 넣고 변화를 관찰(핀셋 2개 사용, 용액이 섞이지 않도록 주의).
4. 실험 결과를 이야기하고(136쪽 "실험 결과 정리"), 산성 용액과 염기성 용액의 성질을 비교해 설명(136쪽 "개념 도입").
5. (정리, 5분) 실험 결과를 바탕으로 산성 용액과 염기성 용액의 성질 정리(지도서 131쪽), 개념 응용 질문(묽은 염산에 탄산 칼슘을 넣으면 어떻게 될지) 답하기(137쪽).

### 1.5 지도상 유의점 (지도서 129~131, 133, 135~136쪽)
- 이 차시는 다른 차시보다 진한 농도(1 M)의 용액을 사용하므로 안전 교육을 더욱 철저히 한다(129쪽).
- 핀셋 2개를 사용해 용액이 섞이지 않도록 지도(130, 136쪽).
- 삶은 닭 가슴살은 재료 상태·관찰 시기에 따라 용액이 뿌옇게 흐려지거나 이물질이 가라앉는 등 결과가 조금씩 다를 수 있다 — 학생이 실제 관찰한 대로 기록하게 지도(130, 134쪽).
- 실험 결과는 학생이 예상한 결과가 아니라 **실제 관찰 결과**로 기록하도록 지도(136쪽) — 앱의 관찰 단계도 예상과 분리해 실제 결과(지도서 표값)로만 채점한다.
- 단백질 반응은 오래 걸리므로 홈판 뚜껑을 닫아 안전한 곳에 보관하거나 교사가 미리 준비한 결과물(사진)을 보여준다(131, 135쪽) — 위 1.3의 "빨리 감기" 처리 근거.

### 1.6 보충 자료 (지도서 133~134쪽, 앱 발전 질문·모형 설계에 활용)
- 대리암 조각 + 두부 실험(133~134쪽): 대리암 조각(탄산 칼슘)은 묽은 염산에서 표면에 기포가 생기고 크기가 작아지며 용액이 뿌옇게 되고, 묽은 수산화 나트륨 용액과는 반응 없음. 두부(단백질과 유사한 특성)는 반대로 묽은 수산화 나트륨 용액에서 흐물흐물해지고 뿌옇게 흐려짐, 묽은 염산과는 반응 없음. → 달걀 껍데기·조개껍데기·삶은 달걀흰자·삶은 닭 가슴살 결과와 **같은 패턴**임을 확인하는 보충 자료로 발전 질문에 활용.
- 대리암 조각상 훼손(134쪽 보충 자료): 산성비가 대리암(탄산 칼슘)과 반응해 이산화 탄소를 발생시키며 대리암을 녹여 문화재·조각상이 훼손된다 — 실생활 연결 발전 질문 소재로 적합("환경" 단원 성취기준 [6과09-04]는 8차시 몫이라 이 앱에서 산성화 개념까지 확장하지 않고, 어디까지나 "탄산 칼슘 + 산성 용액 반응"의 실생활 예로만 짧게 다룬다).
- 염기성 용액이 단백질을 녹이는 성질과 하수구 세정제 이용(133쪽 보충 자료): 머리카락(단백질)이 막은 하수구를 염기성 세정제로 뚫는 원리 — 발전 질문 소재.
- 식초 + 메추리알 서술형 평가 문항(지도서 132~133쪽): "식초는 산성 용액이고 산성 용액은 탄산 칼슘을 녹인다. 따라서 식초에 메추리알을 넣으면 메추리알 껍데기에서 기포가 발생하며 녹는다." — 결론/발전 질문 모범 답안에 활용.

### 1.7 평가 (지도서 132~133쪽)
- 평가 목표: [지식·이해] 산성 용액과 염기성 용액의 성질을 설명 / [과정·기능] 성질을 관찰하여 비교 / [가치·태도] 안전 수칙을 지키며 적극 참여.
- 지도서 133쪽 평가 문항 2개(①물질-용액 반응 짝짓기, ②식초+메추리알 서술형)를 분석 퀴즈·발전 질문 소재로 각색(원문 그대로 베끼지 않음).
- 차시 평가 방법 및 채점 기준(133쪽): 도달/미도달 피드백 문구를 분석 단계 오답 피드백 톤에 참고.

### 1.8 단원 공통 유의점 (지도서 106쪽, 재확인)
- 산과 염기의 정의, 중성, pH, 중화는 다루지 않는다. 이 차시에도 pH 수치나 "중화"라는 말을 등장시키지 않는다. (이 차시는 애초에 산-염기 반응이 아니라 "탄산 칼슘/단백질과의 반응"을 다루므로 중화 개념과 무관하다.)

## 2. 앱 종류 판단

**실험 시뮬레이션 앱(sim)**으로 만든다.
- 근거: 지도서 130~137쪽 전체가 "예상하기 → 실험해요(6홈판 2개에 물질 넣고 관찰) → 정리해요 → 평가"로 구성된 정식 탐구 활동(위 1.4)이며, 실제 교실에서도 묽은 염산·묽은 수산화 나트륨 용액·달걀 껍데기·조개껍데기·삶은 달걀흰자·삶은 닭 가슴살을 사용하는 손 실험이다.
- 참고: 지도서 130, 134쪽에 "가상 실험"(지능형 과학실 등 디지털 콘텐츠) 안내가 있어, 지도서 스스로도 이 차시를 시뮬레이션으로 보완 가능한 실험으로 다룬다. 또한 단백질 반응처럼 실제로는 여러 날이 걸려 교실에서 보기 어려운 부분을 시뮬레이션이 "빨리 감기"로 보여줄 수 있다는 점에서 오히려 실물 실험보다 학습 효과가 있다.

## 3. 화면 설계 (예상하기 → 실험하기 → 기록·분석하기 → 정리하기 → 궁금한 점)

### 3.0 공통 전제
- 2가지 용액(묽은 염산, 묽은 수산화 나트륨 용액) × 4가지 물질(달걀 껍데기, 조개껍데기, 삶은 달걀흰자, 삶은 닭 가슴살) = 8개 조합. A/B 같은 탐구 구분은 없고 한 번에 8칸을 자유 순서로 실험한다.
- 이 차시는 **색깔 지시약을 쓰지 않는다.** 앞 차시(`sci-6-1-1-2`)와 달리 지시약·색 변화 용어를 다시 등장시키지 않는다. 관찰 결과는 "기포가 발생하며 녹는다 / 변화가 없다 / 시간이 지나면서 녹아 흐물흐물해진다" 세 가지뿐이며, 1.3의 표값만 사용한다.
- 화면에 pH, 중화, "산과 염기의 정의" 같은 말은 쓰지 않는다(1.8).

### 3.1 예상하기
- 질문 1: "산성 용액과 염기성 용액은 어떤 성질을 가지고 있을까요? 알고 있는 것을 자유롭게 적어 보세요." (지도서 130, 135쪽 도입)
- 질문 2: "산성 용액인 식초에 달걀을 일주일 정도 담가 두면 달걀 껍데기는 어떻게 될까요? 그렇게 생각한 까닭도 적어 보세요." (지도서 130쪽 동기 유발 질문 그대로)
- 힌트 버튼(단계적, 답을 직접 주지 않음):
  1. "달걀 껍데기를 만져 본 적 있나요? 딱딱한 껍질이 어떤 물질과 오랫동안 만나면 어떻게 될지 생각해 보세요."
  2. "조개껍데기도 달걀 껍데기와 비슷한 딱딱한 재료로 되어 있어요. 두 재료를 같은 용액에 넣으면 비슷한 일이 생길까요?"
  3. (마지막 힌트) "식초에 달걀이나 메추리알을 넣어 껍데기를 벗기는 실험을 본 적 있나요? 그때 어떤 변화가 있었는지 떠올려 보세요."
- 답은 절대 제시하지 않는다("기포", "녹는다" 같은 단어는 힌트에 쓰지 않음). 입력값은 localStorage에 즉시 임시 저장.

### 3.2 실험하기 (3D 장면)
- **장면 구성**: 실험대 위에 6홈판 2개(왼쪽 "묽은 염산 실험대", 오른쪽 "묽은 수산화 나트륨 용액 실험대", 실험 도움판 ②를 단순화한 모형으로 라벨), 용액 병 2개(라벨: 묽은 염산 / 묽은 수산화 나트륨 용액, 실제 무색투명이므로 병 자체에 임의의 색을 칠하지 않고 글자 라벨로만 구분), 재료 접시 4개(달걀 껍데기 – 흰색 아치형 조각, 조개껍데기 – 회백색 부채꼴 조각, 삶은 달걀흰자 – 반투명 흰색 덩어리, 삶은 닭 가슴살 – 연분홍빛 덩어리), 핀셋 2개(용액마다 다른 색 손잡이로 구분해 "섞이지 않게 다른 핀셋 사용" 지도 내용을 반영). three.js로 각 오브젝트를 단순 형태(실린더/평판/불규칙 블록)로 표현하고 "모형" 라벨을 화면에 명시.
- **조작 흐름**:
  1. 물질 선택(4개 중 1개, 버튼 또는 접시 탭) → 3D에서 재료 조각이 강조됨.
  2. 용액 선택(묽은 염산 / 묽은 수산화 나트륨 용액 중 1개) → 해당 홈판·병이 강조됨.
  3. "넣기" 버튼 → 애니메이션: 핀셋이 재료를 집어 해당 용액이 담긴 홈에 넣는 모션(1~1.5초).
  4. 반응 애니메이션(조건별로 다르게, 아래 6절 참고), 끝나면 관찰 카드가 뜬다.
  5. "기록" 버튼으로 현재 조합(용액, 물질, 관찰된 결과)을 기록 목록에 저장. 같은 조합을 다시 실험하면 마지막 기록으로 덮어쓴다.
- **관찰 항목**: 용액명, 물질명, 결과(문자열, 표값과 동일 어휘: "기포가 발생하며 녹는다" / "변화가 없다" / "시간이 지나면서 녹아 흐물흐물해진다").
- **카메라 조작**: three.js `OrbitControls`, 터치 1-드래그 회전, 2-핑거 핀치 확대/축소, 더블탭으로 초기 각도 복귀.
- **기록 데이터 형식(예시)**:
```json
{
  "solution": "묽은염산",
  "material": "달걀껍데기",
  "result": "기포가 발생하며 녹는다",
  "recordedAt": 1737350000000
}
```
- 8칸을 모두 기록해야 "기록·분석하기"로 진행 가능(진행률 표시). 순서 제한은 없음(어떤 조합부터 실험해도 됨).

### 3.3 기록·분석하기
- **자동 생성 표**: 물질(행) × 용액(열, 2개) 매트릭스. 학생이 기록한 값을 그대로 채워 넣고, 지도서 표(1.3)와 다르면 "다시 실험해 볼까요?" 안내(정답을 알려주지 않고 재실험 유도).
- 결과가 범주형(3가지 문장)이라 수치 그래프 대신 **결과 유형 매트릭스**를 시각 자료로 쓴다. 칸 배지 색은 "기포 발생/변화 없음/흐물흐물"을 구분하기 위한 **화면 표시용 색일 뿐**, 실제 용액이나 물질의 색이 아님을 표 위에 문구로 밝힌다(지도서에 색 변화가 아니므로 혼동 방지).
- **분석 퀴즈(보기 중 고르기, 지도서 130~133쪽 근거)**:
  1. "달걀 껍데기를 ( ) 용액에 넣으면 기포가 발생하며 녹습니다." → 보기: 산성 / 염기성 (정답: 산성) — 실험관찰 11쪽·지도서 131쪽 유형.
  2. "다음 중 넣었을 때 반응이 일어나는(녹는) 짝을 모두 고르세요." → 보기: 묽은 염산+달걀 껍데기(정답) / 묽은 염산+조개껍데기(정답) / 묽은 염산+삶은 닭 가슴살(오답) / 묽은 수산화 나트륨 용액+삶은 달걀흰자(정답) / 묽은 수산화 나트륨 용액+달걀 껍데기(오답) — 지도서 132쪽 평가 문항 1(선 긋기)을 보기형으로 각색.
  3. "산성 용액이 달걀 껍데기와 조개껍데기를 녹이는 까닭은 무엇일까요?" → 보기: "달걀 껍데기와 조개껍데기의 주요 성분인 탄산 칼슘과 산성 용액이 반응하기 때문"(정답) / "달걀 껍데기와 조개껍데기가 원래 잘 부서지는 재료이기 때문"(오답) / "산성 용액의 냄새 때문"(오답) — 지도서 131, 133쪽 개념 근거.
  4. "묽은 염산에 조개껍데기와 같은 성분(탄산 칼슘)으로 된 대리암 조각을 넣으면 어떻게 될까요?" → 보기: 기포가 발생하며 녹는다(정답) / 변화가 없다(오답) / 흐물흐물해진다(오답) — 지도서 132~134쪽 개념 응용·보충 자료 근거.
  - 각 문항 오답에 지도서 문구를 바탕으로 한 짧은 피드백 제공(예: 오답 시 "표를 다시 살펴볼까요? 삶은 달걀흰자·삶은 닭 가슴살은 어떤 용액에서 반응했나요?").

### 3.4 정리하기
- 결론 질문: "실험 결과를 바탕으로 산성 용액과 염기성 용액의 성질을 각각 정리해 보세요." → 서술형 입력 후 모범 답안 표시: "산성 용액(묽은 염산)은 달걀 껍데기와 조개껍데기의 주요 성분인 탄산 칼슘과 반응해 기포를 내며 녹이고, 염기성 용액(묽은 수산화 나트륨 용액)은 삶은 달걀흰자와 삶은 닭 가슴살의 주요 성분인 단백질과 반응해 시간이 지나면서 녹아 흐물흐물해지게 합니다."(지도서 131쪽 근거) → 학생 답과 나란히 비교 표시.
- 발전 질문 1: "묽은 염산에 조개껍데기와 같은 성분(탄산 칼슘)으로 된 대리암 조각을 넣으면 어떻게 될지, 그 까닭도 함께 적어 보세요." → 모범 답안: "기포를 내며 녹습니다. 대리암의 주요 성분도 탄산 칼슘이고, 산성 용액은 탄산 칼슘과 반응하기 때문입니다."(지도서 132~134쪽 근거. 원한다면 "산성비가 대리암으로 만든 조각상을 훼손하는 것도 같은 원리입니다"를 덧붙일 수 있다 — 134쪽 보충 자료)
- 발전 질문 2: "식초(산성 용액)에 메추리알을 넣으면 어떤 변화가 나타날지, 그 까닭까지 적어 보세요." → 모범 답안: "식초는 산성 용액이고 산성 용액은 탄산 칼슘을 녹입니다. 따라서 식초에 메추리알을 넣으면 메추리알 껍데기에서 기포가 발생하며 녹습니다."(지도서 132~133쪽 서술형 평가 문항 근거)
- "더 탐구하고 싶은 점(또는 궁금한 점)" 자유 입력란.

### 3.5 단계 이동 / 저장
- 상단에 4단계 진행 표시(예상하기 → 실험하기 → 기록·분석하기 → 정리하기), 언제든 이전 단계로 돌아가 다시 볼 수 있음. "실험하기"는 언제든 다시 실행 가능(기록은 유지, 3D 장면만 초기화).
- localStorage 임시 저장 키 접두사(예): `sci611sim3:v1` — 앱 폴더명(`sci-6-1-1-3`)과 대응.

## 6. 3D 장면 스케치

- **오브젝트 목록**
  - 실험대(평판, 회색 모형)
  - 6홈판 2개(왼쪽 = 묽은 염산용, 오른쪽 = 묽은 수산화 나트륨 용액용, 각 홈판에 실제로 쓰는 4개 홈만 강조 표시)
  - 용액 병 2개(실린더, 라벨 텍스트만 "묽은 염산" / "묽은 수산화 나트륨 용액" — 실제로 둘 다 무색투명이므로 병 자체에 산/염기를 암시하는 색을 칠하지 않는다)
  - 재료 접시 4개 + 조각 모형: 달걀 껍데기(흰색 곡면 조각), 조개껍데기(연회색 부채꼴), 삶은 달걀흰자(반투명 흰색 덩어리), 삶은 닭 가슴살(연분홍빛 덩어리)
  - 핀셋 2개(손잡이 색으로 "염산용" / "수산화 나트륨 용액용" 구분 — 지도서의 "핀셋 2개로 섞이지 않게" 지도 반영)
  - "모형" 배지, 안전 안내(실험복·보안경 아이콘)
- **배치**: 실험대 중앙에 6홈판 2개를 좌우로 배치, 위쪽에 용액 병 2개, 옆에 재료 접시 4개와 핀셋 2개.
- **애니메이션**
  1. 물질·용액 선택 시 해당 접시/홈판 하이라이트(테두리 발광).
  2. "넣기" 버튼 → 핀셋이 재료를 집어 해당 홈으로 이동해 넣는 모션(1~1.5초).
  3. 결과별 반응 연출(`kind`에 따라 분기):
     - `fizz`(탄산 칼슘+산성): 작은 기포 파티클이 재료 표면에서 위로 올라가며 사라짐 + 재료 메쉬가 서서히 축소(약 3초) → 정지 후 관찰 카드.
     - `none`: 재료는 표면 잔물결 정도만 있고 형태 유지(약 1초) → 바로 관찰 카드.
     - `melt`(단백질+염기성): 화면 한쪽에 "시간 빨리 감기" 표시(작은 달력/시계 아이콘이 여러 번 넘어가는 연출, 약 3~4초) + 재료 메쉬가 점점 뭉개지듯 변형되며 표면이 흐릿해짐(불투명해짐) → 관찰 카드에 "모형: 실제로는 시간이 훨씬 오래 걸려요(여러 날)" 문구 고정 표시.
  4. 카메라: three.js `OrbitControls`, 1-드래그 회전, 핀치 확대/축소, 더블탭 복귀. 저폴리곤 프리미티브만 사용(태블릿 성능 고려, 공통 틀 sim3d.js 그대로 재사용).
- **색 사용 원칙**: 재료 색은 겉보기 실제 색(흰색/회백색/반투명 흰색/연분홍)만 반영하고, 용액 병에는 산성=빨강/염기성=파랑 같은 임의의 색을 절대 칠하지 않는다(지도서에 그런 색 구분이 없고, 실제로 둘 다 무색투명이기 때문). 결과 매트릭스의 배지 색(기포/변화없음/흐물흐물 구분)도 "화면 구분용 UI 색"이며 용액·물질의 실제 색이 아님을 화면에 명시한다.

## 7. 공통 틀 확장 필요

**새로운 공통 틀 파일/모듈 추가는 필요 없다.** `scripts/templates/science-sim/`의 기존 인터페이스(`experiment.js`의 `build3D/build2D`, `observe`, `makeRecord`, `quiz.js`의 `multi`/`wrongBy`, `table-chart.js`의 매트릭스 렌더)로 이 차시를 그대로 구현할 수 있다.
- 다만 아래는 **이 앱의 `app.js`(차시 전용 코드) 수준에서 처리**할 사항이며 공통 틀 변경은 아니다: "빨리 감기" 시간 경과 연출(3D 장면 자체 애니메이션 로직), 결과 매트릭스 배지 색이 실제 화학적 색이 아님을 알리는 문구, 핀셋 2개(용액별) 구분 표시.
- 확인이 필요한 부분: `table-chart.js`의 "색상 매트릭스" 렌더가 `color` 값을 받아 칩을 칠하는 방식이라면, 이 앱은 실제 색이 아닌 결과 유형(fizz/none/melt)별 UI 배지 색을 넘기면 되므로 인터페이스 변경 없이 그대로 쓸 수 있을 것으로 보인다(Build 단계에서 `table-chart.js` 실제 시그니처 확인 필요).

## 8. 열린 질문 (추천안 포함)

1. **"빨리 감기" 연출의 구체적인 시간(몇 초)과 시각 효과(달력/시계 아이콘 vs 다른 방식)를 어떻게 할지?**
   추천: 3~4초 정도로 짧게 하되, 화면에 "모형: 실제로는 시간이 훨씬 오래 걸려요"라는 고정 문구를 반드시 넣는다. 시계 아이콘이 빠르게 도는 정도의 단순한 연출로 충분하다(교육적으로 중요한 것은 "시간이 오래 걸린다"는 사실이지 정확한 날짜가 아니다).
2. **발전 질문 1에서 "산성비가 대리암 조각상을 훼손한다"는 문장까지 포함할지, 탄산 칼슘 반응만으로 그칠지?**
   추천: 모범 답안의 핵심은 "기포를 내며 녹는다 + 탄산 칼슘 반응"까지로 하고, 산성비·환경 문장은 "더 알아보기" 형태의 보충 설명으로만 살짝 덧붙인다. 산성화·환경 피해는 8차시(성취기준 [6과09-04]) 몫이므로 이 차시에서 깊이 다루지 않는다.
3. **분석 퀴즈 2번(반응 짝 다중 선택)에서 오답 선택지 개수와 배치를 지도서 원문(선 긋기)과 얼마나 다르게 할지?**
   추천: 원문은 선 긋기 형식이라 앱에서는 다중 선택(체크박스)으로 바꾸는 것이 자연스럽다. 오답도 그럴듯하게(예: "묽은 수산화 나트륨 용액 + 달걀 껍데기"처럼 실제로는 반응하지 않는 조합) 넣어 추측만으로 맞히기 어렵게 한다(위 5절 config 예시에 반영).
4. **핀셋 2개를 3D에서 실제로 다르게 조작하게 할지(각 용액에 지정된 핀셋만 쓸 수 있게), 아니면 시각적 구분만 둘지?**
   추천: 초등학생 인지 부하를 고려해 시각적 구분(손잡이 색)만 두고, 조작 자체는 자유롭게 한다. "핀셋을 따로 써서 용액이 섞이지 않게 한다"는 지도서 취지는 3D 안내 문구로 설명한다.
5. **묽은 염산·수산화 나트륨 용액의 농도(1 M, 다른 차시보다 진함)를 화면 안전 안내 문구에 구체적인 수치로 노출할지?**
   추천: 정확성을 위해 지도서 값(1 M)을 안전 카드에 "이 실험은 다른 차시보다 더 진한 용액을 사용해요"처럼 수치 없이 문장으로만 안내한다(초등학생에게 몰 농도 단위 설명은 불필요하고 단원 유의점에도 학생용 개념으로 pH 등 수치를 노출하지 말라는 원칙과 결이 같다).
