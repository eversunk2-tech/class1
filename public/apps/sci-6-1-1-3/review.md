## 5. 보안·품질

- XSS: 결론·발전 입력에 `<img src=x onerror=…>`를 넣었다. 글자 그대로 보이고 `img` 0개, 스크립트 실행 안 됨. 공통 틀에 `innerHTML` 사용은 없다(persist.js:118 주석뿐).
- CDN SRI: three.js 0.169.0(importmap integrity와 modulepreload integrity), supabase-js 2.116.0 script integrity와 crossorigin이 있다.
- 저장 크기: textarea 6개 모두 maxlength 1000이다. 최악(따옴표만 6천 자면 이스케이프로 1.2만 자)에 기록 8칸을 더해도 약 1.35만 자로 16,000자 제한 안이다.
- 접근성: textarea 6개 모두 레이블이 있다. 2D 홈 버튼 aria-label에 결과 상태가 들어 있다. 표 칸은 색 칩과 아이콘·글자를 같이 써서 색만으로 정보를 주지 않는다. 다크모드 결과 표 글자는 밝은 글자에 투명 배경이고, 칩은 글자 없는 작은 색 조각이라 대비 문제가 없다.
- 공통 틀 사본: `diff -r scripts/templates/science-sim public/apps/sci-6-1-1-3/science-sim` 결과 차이 없음.
- 시범 앱 리뷰의 M2(세로 화면 애니메이션 안 보임)와 D1(3D↔2D WebGL 누적)은 현재 공통 틀에서 **고쳐져 있다**. 실행 전에 3D 화면으로 스크롤하고 whenVisible을 기다린다. 3D↔2D를 15번 왕복해도 캔버스는 0/1개이고 콘솔 경고가 없었다.

## 6. 확인한 것 vs 못 한 것

**확인한 것** (개발 서버 `http://localhost:3000/class1/apps/sci-6-1-1-3/index.html`, 자기 탭)
- 지도서 130~137쪽, 107쪽(단원 개요), 113쪽(용액 겉보기)을 텍스트로 뽑아 화면의 모든 사실, 결과, 분석 정답, 모범 답안, 힌트와 대조했다.
- 전체 흐름: 예상(힌트 3개) → 실험 8칸(1칸 일부러 틀리게 기록) → 분석 표(🔁 1칸 표시) → 퀴즈 4문항 오답 피드백과 정답 → 결론·발전 2 → 궁금한 점 → 마치기(비로그인 안내, 완료 카드 "8칸, 4/4").
- 탭이 보이는 상태의 세로형 창(691×837)에서 실행 버튼이 3D 아래 있을 때 눌렀다. 3D로 스크롤된 뒤 애니메이션이 약 7.5초 재생되고 관찰 카드가 떴다.
- 흐물흐물 칸의 '시간 빨리 감기 (모형)' 오버레이 표시와 문구 변화를 확인했다.
- 새로고침 복원, `?no3d=1`(캔버스 0개, 3D 버튼 비활성 "3D를 쓸 수 없는 기기예요", 2D 8홈 복원·aria-label), 3D↔2D 15번 왕복, 375×812 모든 단계 scrollWidth 375, 다크모드 배경과 표 색, 앱 자원 모두 200(404 없음), 콘솔 오류 없음.
- 3D 장면 캡처 1장(홈판 2개, 병 2개, 이름표, 핀셋 2개, 접시 4개, 결과 상태).
- 끝난 뒤 `sci611sim3:*` localStorage 키 11개를 지우고 탭을 닫았다.

**못 한 것 / 한계**
- 브라우저 창을 다른 리뷰 에이전트와 같이 써서 내 탭이 자주 숨겨졌다. 그때는 설계상 애니메이션이 즉시 끝나므로 **세로 화면 애니메이션은 한 번만** 실제 시간으로 확인했다. 휴대폰 크기와 태블릿 가로에서는 애니메이션 중 화면을 캡처하지 못했다(스크롤 위치에서 캡처가 어긋나는 문제도 있음).
- 실제 터치 기기, 핀치 줌, 로그인 상태의 실제 저장·RLS, `npm run build` 뒤 정적 경로는 확인하지 못했다(개발 서버의 `/class1/` 경로로만 확인).
- 키 삭제 뒤 탭을 닫을 때 앱이 unload 때 meta 키를 다시 쓸 수 있는데, 그것까지는 다시 확인하지 못했다.
