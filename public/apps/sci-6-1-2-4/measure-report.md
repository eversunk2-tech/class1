## 바뀐 흐름
예상하기 → 실험하기(자동차 고르기 → 출발 → 초시계가 **처음부터 소수 첫째 자리**로 0.0 → 4.2초(초록) / 5.8초(노랑) → 멈춘 값을 **그대로 적기** → 기록, 두 자동차 1번씩 = 2회) → 기록·분석하기(표·막대그래프·보기 2개) → 정리하기(결론 1개, 선택 한 줄, 마치기).
적은 값이 초시계 값과 다르면 "초시계에 나온 숫자를 다시 확인해 보세요."만 나오고 기록 버튼이 꺼진다.

## 삭제한 코드·문구
* 무작위 차이: `measureCs`의 ±0.1초 노이즈, 설정 `noiseCs`, 모형 안내 "잴 때마다 … 0.1초 안팎으로 조금씩 달라져요".
* 1/100초 표시: `csText`(toFixed(2)), 초시계 초기값 `0.00`, `lastCs` → 1/10초 단위 `measureTs`·`tsText`·`lastTs`.
* 반올림: `roundTenths`, 소수 둘째 자리 숫자별 피드백 2종, "소수 첫째 자리까지만 적어요…반올림해요" 피드백, 접는 도움말 "🔢 반올림이 헷갈리면 눌러요"(+예시), 관찰 질문 "반올림해 소수 첫째 자리까지 적어요", 실험 방법 ②의 "반올림해 소수 첫째 자리까지", CSS `.round-help`(→ `.round-msg`는 `.read-msg`로 이름만 바꿈).
* 반복·평균: `avg`(records.mean) → `timeOf`(한 번 기록 값), `C.trials` 설정과 `trials > 1` 분기(회차 열·평균 열·평균 설명 문장·다음 단계 잠금 문구의 "N번씩"), 기록 설명의 "(N회)", 저장 detail의 `trial`, `averages` → `times`.
* 문구 정리: 완료 안내 "모든 측정을 기록했어요 … (다시 재면 기록이 바뀌어요)" → "두 자동차를 모두 기록했어요. …", 잠금 문구 "(다 잰 칸: n/2)" → "(기록한 자동차: n/2)".
* 수치 형식: 거리 표시 `100 cm` → `100.0 cm`(방법 안내, 관찰 카드, 3D·2D 거리 이름표, 한눈에 보기 표, 결과 표·막대그래프 제목, 분석 q1 피드백).
* 저장 키 `sci612sim4:v3` → `sci612sim4:v4`.

## 확인한 것
자기 전용 headless Chrome(CDP, 임시 프로필, 스크래치) + 로컬 정적 서버. supabase-js CDN은 가짜 클라이언트로, `*.supabase.co`는 모두 가로채 메모리 가짜 응답(실제 DB 요청 0건). 앱 키(`sci612sim4:*`)만 지웠고 `localStorage.clear()`는 쓰지 않았다.

| 환경 | 결과 |
|---|---|

| 768×1024 태블릿 세로 3D | 같음 |
