# spec: sci-6-2-3-1 — 3단원 "전기의 이용" 탐구 1
## "전구에 불을 켜려면 어떻게 해야 할까?"

적용 기준: 2026-09-22 새 기준(7분·질문 축소·측정 1회·소수 첫째 자리). `docs/science/6-2-unit3/plan-common.md`, `CLAUDE.md` 과학 차시 앱 규칙을 따른다. **구현 전 사용자 승인 필요.**

## 1. 지도서 분석 (근거 쪽수)

* 대상: `science-curriculum.ts` term "6-2" unit 3 lesson id "2" (지도서 표기 2/12차시). 교과서 60~61쪽, 실험관찰 36~37쪽, 지도서 인쇄 262~273쪽(오프셋 확인: PDF 5쪽=인쇄 258쪽 "단원 지도 계획" → 인쇄 = PDF쪽 + 253. 지도서 PDF 9~20쪽 = 인쇄 262~273쪽, 확인함).
* **학습 목표**(지도서 262쪽): 전지, 전구, 전선 등을 연결해 전구에 불을 켤 수 있다 / 전구에 불이 켜지는 전기 회로의 특징을 설명할 수 있다. 성취기준 [6과15-01](지도서 265쪽).
* **핵심 실험 1 "전구에 불 켜기"**(지도서 263쪽, 실험관찰 36쪽): 전기 회로 카드 (가)~(라) 4가지를 놓고 "스위치를 닫았을 때 불이 켜질지" 예상 → 실제 연결해 확인.
  * 카드 이미지(지도서 268쪽 "탐구 결과 예시" 확대본으로 배선 확인함):
    * **(가)**: 전지 끼우개 한쪽 극(+)에서 나온 도선 1개가 전구를 거쳐 스위치까지 이어지지만, **스위치와 전지의 반대쪽 극 사이에 도선이 없음** → 회로가 끊어져 있음.
    * **(나)**: 전지의 (+)극 → 전구 → 스위치 → 전지의 (-)극까지 도선이 끊어진 곳 없이 모두 연결됨 → **불이 켜짐(정답)**.
    * **(다)**: 도선 2개가 **모두 전지의 같은 극(+)에서** 나와 각각 전구와 스위치로 연결됨(반대쪽 극에는 아무것도 연결 안 됨) → (+)극에만 연결되어 회로가 닫히지 않음.
    * **(라)**: 전구·스위치는 도선으로 이어져 있지만 **그 도선이 전지에 아예 연결(집게로 물리지 않음)되어 있지 않음** → 연결이 끊어져 있음.
  * 지도서 결과(263쪽): "전구에 불이 켜지는 전기 회로는 (나)입니다. 전기 회로 (가), (다), (라)는 전구에 불이 켜지지 않습니다."
  * 특징(263~264쪽): "스위치를 닫았을 때 전지, 전구, 전선 등 전기 부품이 끊어진 곳 없이 연결되어 있다" / "전기 부품이 전지의 (+)극부터 (-)극까지 연결되도록 전기 회로가 구성되어 있다."
* **핵심 실험 2 "전기가 흐르는 물질 확인하기"**(지도서 264쪽, 실험관찰 37쪽): (나) 회로에서 스위치 자리에 **플라스틱 막대 → 고무 막대 → 금속 막대**를 차례로 연결.
  * 결과(264쪽): 플라스틱 막대·고무 막대 연결 시 **안 켜짐**, 금속 막대 연결 시 **켜짐**. "플라스틱, 고무, 금속 중에서 전기가 잘 흐르는 물질은 금속입니다."
* **부품의 역할·용어**(264쪽): 전지 = 전기 에너지 공급, 전선 = 전기가 흐르는 통로, 전구 = 전기가 흐르면 불이 켜짐. 전기 부품은 전기가 흐르는 **도체**(금속 등)와 전기가 잘 흐르지 않는 **부도체**(플라스틱·고무·비닐·종이·유리 등) 부분으로 이루어짐. 회로를 만들 때는 전기 부품의 도체(금속) 부분끼리 서로 닿도록 연결해야 함.
* **지도상 유의점**(262쪽): "도체, 부도체의 용어에 집중하기보다는 전기 부품을 구성하는 여러 가지 물질에는 전기가 흐르는 물질과 흐르지 않는 물질이 있다는 것을 인식하도록 지도한다." → 화면에서 도체·부도체 용어를 앞세우지 않고 "전기가 흐르는 물질(도체)" 식으로만 가볍게 병기.
* **오개념**(263쪽): "전구 끼우개는 전기가 흐르는 부분의 연결이 끊어져 있다" → 바로잡기: 금속 막대 부분과 전구를 끼우는 부분이 전구 끼우개 아랫면에서 전선으로 서로 연결되어 있음. (화면 반영은 8절 참고 — 시간 예산상 선택 정보로만 다룸.)
* **안전**(262쪽): 전구가 깨지지 않도록 조심 / 젖은 손으로 실험하지 않음. 시뮬레이션이라 실제 파손 위험은 없지만 실습 상황을 상상하도록 짧게 안내.
* **차시 예고**(271쪽): 다음 시간(탐구 2)은 전지 한 개 vs 두 개 직렬연결 비교 — **스포일러 금지**(전자석·직렬연결 언급 안 함).

## 2. 앱 종류 판단

**실험 시뮬레이션 앱**으로 만든다(plan-common 사용자 결정). 지도서 262~264쪽에 실제 학생 실험(전기 회로 카드 연결, 막대 재질 바꾸기)이 있으므로 새 기준의 실험 앱 형식이 그대로 맞는다. 3D 장면에서 전지·전구·스위치(또는 막대)·전선을 배치해 학생이 드래그로 시점을 돌려 배선을 관찰하고, 카드/재질을 골라 "회로 연결하기"를 실행해 불이 켜지는지 확인한다.

## 3. 화면 설계

### 예상하기 (질문 1개만)
* 도입 문구: "손전등 스위치를 누르면 불이 켜져요. 전지, 전구, 전선을 어떻게 연결해야 전구에 불이 켜질까요?"(262쪽 도입 재구성, "지도서"라는 말 없이)
* **탐구형 질문(직접 타이핑)**: "전지, 전구, 전선을 어떻게 연결해야 전구에 불이 켜질지 자신의 생각을 써 봅시다."
* 힌트(답을 말하지 않음, 2단계):
  1. "손전등 스위치를 누르면 손전등 안에서 어떤 부분이 이어질까요?"(262쪽 도입 발문 재사용)
  2. "전지에는 서로 다른 두 극(+, -)이 있어요. 전기 부품이 두 극에 어떻게 이어져야 할지 생각해 보세요."
* 근거: 지도서 262쪽 도입 발문 그대로(스포일러 아님, 결론 미제시).

### 실험하기 (3D, two phases)
* 인트로 안전 안내(짧게): "전구가 깨지지 않도록 조심해요. 젖은 손으로 전기 부품을 만지지 않아요. 실제 콘센트나 가정용 전기로는 절대 실험하지 않아요."(262쪽 안전 유의점)
* 3D 장면(공통): 전지 끼우개(파란 원통 전지, + 표시), 전구 끼우개(유리 전구), 스위치 받침대, 빨강·검정 집게 전선. 드래그로 회전(Sim3D 기본 제공). "실제 전류의 흐름은 눈에 보이지 않아 화살표(모형)로 표현합니다"라는 모형 안내(도선을 따라 빛나는 화살표 애니메이션 사용 시).
* **실험 1 — 전기 회로 카드 고르기** (조건 선택 버튼: 가/나/다/라, **4개 모두 측정**):
  * 카드를 고르면 3D 장면이 그 카드의 배선 상태로 바뀐다(위 1절에서 확인한 배선 그대로: 가=스위치↔전지 도선 없음, 나=완전 연결, 다=도선 2개가 모두 전지 + 극에서 나옴, 라=전지에 도선이 물려 있지 않음).
  * "회로 연결하기(스위치 닫기)" 실행 → 완전한 회로(나)만 전구가 빛나는 애니메이션(짧게, 1초 내외), 나머지는 켜지지 않는 채로 정지 화면.
  * 결과는 물리 법칙에 따른 확정 결과이며 **측정 오차 없음**(수치 아님, 켜짐/안 켜짐의 이분 결과).
  * 관찰 즉시 **기록하기** 버튼으로 저장(가~라 4칸, 반복 측정 없음 — 조건이 4가지이므로 실험관찰에 제시된 대로 4가지 모두 측정, 임의 축소 없음).
* **실험 2 — 막대 재질 바꾸기** (조건 선택 버튼: 플라스틱/고무/금속, **3개 모두 측정**):
  * (나)와 같은 완전한 배선에서 스위치 자리에 막대(원통, 재질별 색: 플라스틱=주황, 고무=검정, 금속=은색)를 연결.
  * "연결하기" 실행 → 금속만 전구가 켜짐. 기록하기로 3칸 저장.
* 두 실험 합쳐 **7개 조건을 모두 측정**(임의로 줄이지 않음, plan-common 측정 규칙 준수).

### 기록·분석하기
* 기록으로 **표 자동 생성**(`TableChart.renderMatrix` 활용): 실험 1 표(가/나/다/라 × 켜짐 여부, 아이콘 💡 켜짐 / ⚫ 안 켜짐), 실험 2 표(플라스틱/고무/금속 × 켜짐 여부).
* **보기 고르기 2개**(학생 자신의 기록을 보고 답함):
  1. "실험 1의 기록을 보고, 전구에 불이 켜지는 전기 회로의 특징으로 알맞은 것을 골라 봅시다." 보기: ① 전기 부품이 전지의 (+)극부터 (-)극까지 끊어진 곳 없이 연결되어 있다 / ② 전지가 두 개 연결되어 있다 / ③ 스위치가 열려 있다. 정답 ①. 오답 피드백(`wrongBy`): ②→"이 차시는 전지 한 개만 사용해요. (다음 시간에 전지 두 개를 다뤄요는 언급하지 않음, 단순히 '전지 개수가 아니라 연결 방법을 보세요'로 안내)", ③→"기록에서 스위치를 닫았을 때만 비교했어요. 표를 다시 살펴보세요."
  2. "실험 2의 기록을 보고, 전기가 흐르는 물질은 무엇인가요?" 보기: 플라스틱 / 고무 / 금속. 정답: 금속. 오답 피드백: 플라스틱·고무 선택 시 "그 막대를 연결했을 때 기록에서 전구가 어떻게 되었는지 다시 확인해 보세요."

### 정리하기 (질문 1개만, 발전 질문 없음)
* **탐구형 질문(직접 타이핑)**: "전구에 불이 켜지는 전기 회로를 만들려면 전지, 전구, 전선을 어떻게 연결해야 할지 자신의 말로 정리해 봅시다."
* 모범 답안(제출 후 비교, 264~265쪽 재구성): "전기 부품을 전지의 (+)극부터 (-)극까지 끊어진 곳 없이 연결해야 합니다. 그리고 전기 부품의 전기가 흐르는 부분(금속 부분)끼리 서로 닿도록 연결해야 합니다."

### 궁금한 점
* 선택 입력 한 줄(비워도 마칠 수 있음), 안내: "전기 회로에 대해 더 궁금한 점이 있다면 써 보세요(선택)."

## 7. 3D 장면 스케치

* 공통 오브젝트(Sim3D 팩토리로 제작): 전지 끼우개(파란 원통 + 검은 홀더, "+" 라벨 텍스처 또는 색 구분), 전구 끼우개(작은 유리구 + 은색 소켓, 유리구 안 필라멘트를 emissive 재질로 두고 lit=true일 때 밝기 올림), 스위치 받침(회색 판 + 금속 레버, 항상 "닫힘" 위치로 표시—배선 유무가 변수이지 스위치 개폐가 변수는 아님), 빨강·검정 원통형 전선(구간별로 보이거나 숨김 처리해 배선 차이 표현).
* 실험 1의 4가지 배선은 전선 세그먼트의 표시/숨김과 연결 지점만 바꿔 표현(가: 스위치-전지 구간 전선 숨김, 나: 전 구간 표시, 다: 전지 쪽 두 전선이 모두 같은 단자에서 나오도록 배치, 라: 전지 쪽 전선 끝이 단자에 닿지 않고 살짝 떨어진 채로 표시).
* 실험 2는 스위치 레버 대신 짧은 원통 막대 오브젝트를 그 자리에 배치, 재질별로 색만 교체(플라스틱=주황 반투명, 고무=무광 검정, 금속=금속성 은색 + 강한 반사).
* 카메라: 초기 시점은 전체 회로가 한눈에 보이는 대각선 위(Sim3D 기본 시점), 드래그로 자유 회전. `viewDir` 기본값 사용.
* 실행 애니메이션: 켜질 때 필라멘트 emissive 강도를 0→최대로 0.3초 트윈, 화살표(작은 원뿔 3~4개)가 도선을 따라 흐르는 짧은 이동 애니메이션(1초, "모형" 라벨 동반). 안 켜질 때는 애니메이션 없이 즉시 "불이 켜지지 않았어요" 카드 표시.
* `?no3d=1` 2D 대체 화면: 회로 다이어그램을 SVG/캔버스로 단순화해 동일 정보 제공(배선 유무를 선/점선으로 표시).
