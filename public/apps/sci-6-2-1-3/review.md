| 단계 잠금 | 예상 10자 미만, 12달 미만("지금 0/12"), 분석 미확인, 결론 미제출이면 넘어가거나 마칠 수 없음 |
| 가로 스크롤 | 모든 크기·모든 단계에서 0 |
| 다크모드(375) | 달 바, 값 패널, 표, 그래프 모두 읽힘 |
| 콘솔 | 오류 0, 경고 0(모든 실행) |
| 학생 입력 innerHTML | 앱·공통 틀 모두 textContent/`el()`만 씀. `S.rich`는 innerHTML 없이 "**굵게**"만 처리하고 설정 글에만 쓰임 |
| 색만으로 정보 전달 | 계절: 색 + 이름 + 아이콘. 기록 여부: ✓ + aria-label. 그래프: 계절 띠에 이름 표시 ✅ |
| 접근성 | 값 패널 `aria-live`, 진행 막대 `role=progressbar`, 3D 캔버스 `role=img` + aria-label, 달 버튼 aria-label("3월, 봄, 아직 기록 안 함"). 장식 배지는 aria-hidden(값은 패널에서 읽힘). L-1 참고 |

## 6. 확인한 것 vs 확인하지 못한 것

**확인한 것**(headless Chrome + 가짜 세션/가짜 Supabase): 위 1·2·5절의 모든 항목, 지도서 원문과 수치 대조, 3D 확대 캡처로 경로·그림자·남중 표시 확인, 로그인 없는 상태의 가림막, 다른 탭 로그아웃 뒤 sci6 삭제.

**확인하지 못한 것**
* 실제 iPad/태블릿 터치: 3D 한 손가락 드래그와 페이지 스크롤, 두 손가락 확대, 달 바 터치 느낌(터치 에뮬레이션에서는 클릭만 확인), 실제 기기의 WebGL 성능·발열, WebGL 컨텍스트 잃음 → 2D 전환.
* 실제 로그인·실 DB(RLS) 저장, 두 학생 계정을 바꿔 가며 하는 흐름, 블로그 로그아웃 버튼으로 하는 삭제(다른 탭에서 세션 키 삭제로만 확인).
* 실제 학생 소요 시간(4절은 추정), 관리자 대시보드 "학생 응답" 표시(R-4).
* `prefers-reduced-motion` 켠 상태(코드만 읽음: 재생 없이 결과를 바로 보여 줌), Enter/Space로 달 누르기(기본 button 동작이라 따로 시험하지 않음).
