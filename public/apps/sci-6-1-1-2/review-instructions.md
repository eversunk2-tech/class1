## 검증 항목
1. **과학적 정확성 (최우선)**: 앱에 나오는 모든 사실·색·분류·용어·힌트·분석 정답·모범 답안·발전 질문 답을 지도서 원문과 대조. 3D 장면과 2D 대체 화면의 실제 색이 표와 일치하는지. 지도서에 없는 주장(예: 발전 질문의 예시 물질)은 일반 과학 지식으로 사실 여부 판단. 오개념을 유발할 표현. pH·중성·중화 언급 여부.
2. **규칙 준수**: 과학 차시 앱 규칙 항목별 체크(예상 단계 답 누설 여부 — 힌트 포함, 직접 타이핑, 힌트 버튼, 3D + 드래그, 다각적 실험, 기록 버튼 → 표/그래프, 보기 고르기 분석, 결론 작성 후 모범 답안, 발전 질문, 궁금한 점, 다시 하기·앞 단계 이동, localStorage, 결과 저장, 상대경로, 자체 완결).
3. **브라우저 동작**: 전체 흐름을 끝까지. 태블릿 가로/세로, 휴대폰 375px, 터치 드래그(가능하면 터치 에뮬레이션), 다크모드, 새로고침 복원, 3D 불가 대체(`?no3d=1` 등), 콘솔 오류, 성능(프레임, 메모리 누수: 단계 이동 반복 시 렌더러 정리). 정적 빌드 경로(`out/apps/sci-6-1-1-2/`)에서 basePath `/class1` 하위로 서빙해도 모든 자원이 로드되는지.
4. **보안/품질**: CDN 버전 고정·SRI, innerHTML에 학생 입력 삽입 여부(XSS), `class1-record.js` 저장 payload 크기(16KB 제한)·세션 공유 동작, 접근성(버튼 레이블, 포커스, 색만으로 정보 전달하지 않기), 공통 틀과 앱 사본의 차이(템플릿 재사용성).
5. **공통 틀**: 다른 차시 앱이 config만 바꿔 쓸 수 있는 구조인지, 그래프(수치 실험용, 예: 물체의 운동 속력) 지원이 충분한지 평가.
