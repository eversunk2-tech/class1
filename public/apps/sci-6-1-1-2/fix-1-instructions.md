# Build(수정) 서브에이전트 지침: sci-6-1-1-2 review 1차 수정

## 목표
`public/apps/sci-6-1-1-2/review.md`의 **모든 Major·Medium과 Minor**를 수정한다(Info는 판단해 반영하고 보고). 각 항목의 수정 제안을 기본으로 하되, 더 나은 방법이면 이유를 보고서에 적는다.

## 특히
* **M1 (수업 목표)**: 지도서 118쪽 목표에 맞게 — ① 실험하기 시작 전 "지시약"의 뜻을 짧게 안내(지도서 표현), ② 기록·분석하기에 **학생이 6가지 용액을 산성 용액/염기성 용액으로 직접 분류하는 활동**(드래그 또는 탭 선택, 태블릿 친화) 추가 + 분류 근거(어떤 지시약 변화로 판단했는지) 선택, ③ 붉은 양배추 결과와 리트머스·페놀프탈레인 결과를 **비교하는 질문** 추가. 용어 "산성 용액", "염기성 용액"은 분류 활동에서 처음 소개되도록 흐름 정리. 예상하기의 답 누설 금지 원칙은 유지.
* **D2 (용액 겉모습)**: 지도서 113쪽(앞 차시 관찰 결과)을 원문 확인해 6가지 용액의 색·투명도를 3D·2D에 반영. 페놀프탈레인 "변화 없음"을 "무색"으로 표현하지 말 것(지시약을 떨어뜨려도 용액 원래 색 유지로 표현).
* **M2**: 세로 태블릿·휴대폰에서 실행 버튼을 누르면 3D 장면이 화면 안에 보이도록(자동 스크롤 또는 레이아웃 변경) 하고, 애니메이션이 실제 시간 동안 보이게.
* **D1**: 3D↔2D 전환·단계 이동 시 WebGL 렌더러/컨텍스트를 확실히 해제(`renderer.dispose()`, `forceContextLoss()`, 리스너 해제)하거나 렌더러를 하나만 재사용.
* **D3 (공통 틀)**: 앞으로 24개 차시가 재사용할 수 있게 공통 틀을 정리한다. 실험 화면의 앱 전용 로직과 공통 로직(실험 패널 틀, 3D 장면 헬퍼, 조건 선택 UI, 기록 버튼, 수치 기록)을 분리하고, **수치 실험용 그래프(꺾은선/막대, 축 제목·단위)**를 공통 틀에 추가한다(예: 물체의 운동 — 이동 거리·시간·속력). 공통 틀 `README.md`에 새 차시 앱 만드는 절차와 config 예시(색 관찰형, 수치 측정형 두 가지)를 적는다. 시범 앱은 정리된 공통 틀을 다시 복사해 사용하고 동작이 유지되어야 한다.
