**과학적 정확성 결론**: 색 변화표(6 용액 × 4 지시약 = 24칸)는 3D·2D·표·퀴즈 정답 모두 지도서와 **완전히 일치**한다(묽은 수산화 나트륨 + 붉은 양배추 = 노란색 포함). pH·중성·중화는 화면에 나오지 않는다. 문제는 값이 아니라 **개념 누락(M1)** 과 **용액 자체 색 단순화에서 생긴 표기(D2)** 이다.

## 5. 보안/품질

- CDN: three@0.169.0(importmap integrity + modulepreload SRI + crossorigin), supabase-js@2.116.0(SRI) 정확한 버전 고정. 브라우저에서 모두 200·실행됨(3D 렌더 확인).
- XSS: `innerHTML`/`insertAdjacentHTML` 사용 없음. 결론에 `<img src=x onerror=alert(1)>` 입력 → 비교 화면에 글자로만 표시됨(확인).
- config.js: anon key(JWT role=anon)만. service_role 없음.
- 저장 payload: 정상 최대 약 8.7천 자, 따옴표/줄바꿈 최악 14.7천 자 < 16,000자 제한(m5). DB 쪽은 `octet_length(details) <= 65536` 제약(마이그레이션 20260922000000).
- 세션 공유: 블로그와 같은 SUPABASE_URL, storageKey 미지정 → 같은 출처 세션 공유 구조(코드 확인). 실제 로그인 저장은 하지 않음.
- 접근성: 색 칩 옆 항상 글자, '색 이름 보기' 버튼, focus-visible 윤곽선, 진행바 role/aria 값 있음. m8 참고.
- 공통 틀 ↔ 앱 사본: 완전 동일(diff 없음).

## 7. 사용자가 실제 태블릿으로 확인할 체크리스트

1. 가로 모드: 한 손가락 드래그로 3D 회전, 두 손가락으로 확대/축소, 빈 곳 두 번 탭으로 처음 방향 복귀가 되는지.
2. 세로 모드: '실험하기' 버튼을 누를 때 3D 화면이 보이는지, 병이 기울고 방울이 떨어지는 애니메이션이 보이는지(M2 — 현재는 안 보일 것으로 예상).
3. 3D 병·홈을 손가락으로 탭하면 선택되는지, 드래그 중에 잘못 선택되지 않는지.
4. 3D 글자 라벨(용액 이름)이 읽히는지, 붉은색/푸른색/노란색/자홍이 화면에서 구별되는지(밝은 곳·다크모드 둘 다).
5. 실험 A 18칸을 마치면 붉은 양배추가 열리고, 묽은 수산화 나트륨 용액에서 노란색이 나오는지.
6. 앱을 닫았다 다시 열어도(새로고침) 적은 글과 기록이 남는지. '처음부터 다시 하기' 후 모두 지워지는지.
7. 학생 테스트 계정으로 로그인한 뒤 '학습 마치기' → "결과를 저장했어요" → 블로그 '내 학습 활동'에 보이는지(관리자 계정으로 테스트하지 않기).
8. 3D↔2D 전환을 여러 번 눌러도 3D가 꺼지지 않는지(D1 수정 후).
9. 교실 Wi-Fi에서 첫 로딩 시간(three.js 약 1.2MB CDN)과 오래된 태블릿에서 버벅임.
10. 수업 흐름상 산성/염기성 용어 도입을 앱에 넣을지, 교사가 수업에서 먼저 설명할지 결정(M1).
