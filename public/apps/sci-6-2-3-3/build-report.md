## 2. 실험 구성 (7칸, spec 3.2 + 개정 1)

| 단계(phase) | 칸 | 연출 | 관찰·기록 |
|---|---|---|---|
| 실험 1 · 스위치 실험 | 1칸 | 끝부분으로 카메라를 옮기고 **스위치 열림(고리 안 붙음) → 닫힘(고리가 올라붙음)** | 보기 고르기 4개(정답: "스위치를 닫았을 때만 붙는다"). 카드에 **① 열었을 때 / ② 닫았을 때 두 장면 사진**(둥근 철 고리 자리에 점선 표시)을 나란히 보여 준다 |
| 실험 2 · 전지 개수 실험 | 2칸(1개 / 2개 직렬연결) | 스위치를 닫으면 고리가 하나씩 끝부분에 매달린다 | **타이핑 없음**: 값 패널에 "붙은 둥근 철 고리 **4개 / 8개**"와 고리 아이콘이 바로 보이고 `기록하기` |
| 실험 3 · 전지 방향 실험 | 4칸(바꾸기 전·뒤 × 왼쪽·오른쪽 끝) | 방향을 바꿀 때만 전지 회전 → 스위치 닫힘 → 나침반 바늘 회전, 그다음 고른 쪽 나침반으로 카메라 이동(파란 고리로 표시). **같은 방향의 두 번째 칸은 재연출 없이 카메라만** 이동 | 보기 고르기 "N극 / S극". 카드에 그 나침반을 **위에서 본 확대 그림**(빨간 끝 = N극 표시) |

* 조건 고르기는 공통 틀 제약(모든 factor가 채워져야 실행됨) 때문에 **① 실험 고르기(3개) → ② 조건 고르기(해당 실험의 보기만 보임)** 두 단계로 만들었다(spec의 factor 구성과 다른 점은 3절).
* 과학적 사실: 고리 4개/8개, 바꾸기 전 왼쪽 N·오른쪽 S, 바꾼 뒤 왼쪽 S·오른쪽 N — 모두 교과서·실험관찰 예시 값 그대로. 개수는 **자연수**(개정 1).
* 나침반 바늘은 "다른 극끼리 끌어당긴다"에 맞게 돌아간다(바꾸기 전에는 두 바늘의 빨간 끝이 모두 왼쪽, 바꾼 뒤에는 모두 오른쪽). **자기장선·전류 방향 화살표는 그리지 않았다.**
* 전지의 (+)극과 전자석의 극을 연결해 설명하지 않는다. 전자석 사용 예·전기 절약(다음·다다음 차시)은 화면에 없다. 화면에 "지도서"라는 말이 없다(출처 표기는 "교과서·실험관찰").

## 3. spec과 다른 점 (모두 의도한 것)

1. **단계 수 4개**(예상·실험·기록/분석·정리). spec 6절 config 초안은 `curiosity`를 다섯 번째 단계로 두었지만, spec 3절 제목("정리하기(+궁금한 점)")과 2학기 1·2단원 앱들을 따라 **궁금한 점 한 줄을 정리하기 화면 안에** 두었다.
2. **실험 2의 관찰이 수치 입력이 아니라 값 패널 + `기록하기`**. spec 3.2는 학생이 고리 개수를 세어 입력하는 `numeric` 칸이었으나, **개정 1("값은 화면에 바로 보이고 기록하기로 저장, 타이핑 없음")**과 build-common의 핵심 요구를 우선했다. 개수는 3D 화면·HUD·값 패널·고리 아이콘 네 곳에 보인다.
3. **Phase 2의 조건을 factor 2개(방향×위치)가 아니라 조건 1개(4가지 조합)로** 만들었다. 공통 틀은 모든 factor가 채워져야 실행되므로, 실험 1·2 칸에서 방향·위치 factor를 비워 둘 수 없다. 칸 수(1+2+4=7)와 기록 내용은 spec과 같다.
4. **기록 한눈에 보기(miniTable)를 넣지 않았다.** 실험마다 조건 개수가 달라 표가 빈칸투성이가 되기 때문이며, 대신 단계별 진행 막대(1/1·2/2·4/4)로 남은 칸을 알려 준다.
5. 실험 1에 **고리 1개**만 쓴다(실험관찰의 "끝부분을 둥근 철 고리에 가까이 해 본다"). 실험 2의 개수(4·8개)와 헷갈리지 않게 했다.
6. 실험 3의 연출은 spec의 4~5초보다 짧은 **약 2.4~3.3초**로 줄였다(7분 기준).

## 5. 확인하지 못한 것

* **실제 Supabase DB**: 로그인·`app_progress` 이어서 하기·`app_results` 저장은 모두 **가짜 객체**로만 확인했다(실 DB 쓰기 금지). 두 학생 계정을 번갈아 쓰는 흐름(주인 바뀜 삭제)도 확인하지 못했다.
* **실제 태블릿·휴대폰 터치**: 3D 드래그 회전, 두 손가락 확대/축소, 세로 화면 자동 스크롤은 headless Chrome(SwiftShader)로만 확인했다. 실제 GPU·터치 확인 필요.
* `npm run build`(Next.js 빌드)는 **하지 않았다**. 다른 앱 두 개를 동시에 만들고 있어 공유 빌드 폴더를 건드리지 않으려 했고, 이 앱은 `public/` 안의 정적 파일이라 빌드 결과에 영향을 주지 않는다.
* 개발 서버(`localhost:3000`)가 실행 중이 아니어서 `/class1/apps/…` 경로로는 열어 보지 못했다. 앱 내부 참조가 모두 상대경로라 basePath와 무관하지만, 배포 전 한 번 확인하면 좋다.
