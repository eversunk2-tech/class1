## 2. 낮음-2 — 3D↔2D를 바꾸면 장면만 '실험 전'으로 돌아가던 문제 → **고침**

`app.js`에 **화면에만 있는 표시** `liveResultAt`(저장하지 않는 변수)을 두어, 실험을 마쳐 관찰 카드가 열려 있는 칸이면 새 화면에서도 결과 장면을 되살린다.

* `view.run()` 끝에 `liveResultAt = 칸id`, `clear()`·다음 실행 시작 때 비운다.
* `showInstant()` 조건: `sceneAt === 칸id && (기록됨 || liveResultAt === 칸id)`.
* **새로고침하면 `liveResultAt`이 비므로**, 기록 전에 새로고침한 경우에는 예전처럼 '실험 전' 모습으로 남는다(관찰 카드 없이 결과만 보이는 일이 없다 — 직접 확인, 아래 5절 ④).

## 3. 낮음-3 — 다크 모드 2D 나침반 "북" 글자 대비 → **고침**

`style.css`에 `.s2-dial-t`(고정 색 `#444c56`)를 새로 두고, **나침반판(흰색) 안쪽 글자**만 이 색을 쓰게 했다. 판 바깥 글자("왼쪽 끝 나침반" 등)는 그대로 `var(--ss-muted)`. 다크 모드 + `?no3d=1`에서 직접 확인했다.

## 4. 낮음-4 — 장면 나침반이 색으로만 극을 구분 → **고침** (지도서 288쪽 "붙임딱지에 N극·S극 표시" 안내 반영)

* **3D**: 바늘 그룹에 `N`(빨강)·`S`(파랑) 글자 라벨을 붙여 바늘과 함께 돈다. 나침반 이름표가 판을 가리던 것도 위로 올렸고(`y 0.45 → 0.85`), "북" 표시를 옆으로 옮겨 글자끼리 겹치지 않게 했다. 고른 나침반으로 가는 카메라도 더 가깝게(비율 0.62 → 0.46, 좁은 화면 0.95 → 0.72) 해 바늘이 크게 보인다.
* **2D 인세트**: 바늘을 조금 짧게 하고 끝 바깥에 `N`(빨강)·`S`(파랑) 글자를 넣었다.
* **관찰 카드의 확대 그림**: 이미 있던 "빨강(N극)"에 더해 반대쪽에 **"파랑(S극)"**을 넣어 좌우가 짝이 맞게 했다.
