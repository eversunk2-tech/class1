## 7. 확인한 것 / 확인하지 못한 것

### 확인한 것 (모두 내 전용 headless Chrome에서 직접 실행)
* 전체 흐름 끝까지 × 1024×768 · 768×1024 · 375×812 · 1100×1300 · 다크 모드 · `?no3d=1`
* 로그인 가림막, 로그아웃 삭제, **기록 주인 바뀜 삭제**, 새로고침 복원(가짜 충돌 0회), `app_progress` 읽기/쓰기(가짜 서버)
* `app_results` 저장 내용(`completed`, `duration_seconds`, `detail.qa` 8개) 전문
* 3D↔2D 5회 반복 전환, 오답 처리, 단계 게이트, "실험 전 모습으로", "처음부터 다시 하기"
* 3D·2D·확대 그림의 나침반 바늘 방향을 확대해 하나씩 대조
* 지도서 PDF(인쇄 284~288쪽)와 실험관찰 PDF(40~42쪽) 원문 대조

### 확인하지 못한 것
* **실제 iPad·태블릿 터치**: 3D 드래그 회전, 두 손가락 확대/축소, 두 번 탭 초기화, 세로 화면 자동 스크롤은 headless Chrome(SwiftShader)으로만 확인했다. **실제 기기 확인이 필요하다.**
* **실제 Supabase DB**: 로그인·`app_progress` 이어서 하기·`app_results` 저장은 모두 **가짜 객체**로만 확인했다(실 DB 쓰기 금지). 두 학생 계정을 실제로 번갈아 쓰는 흐름은 확인하지 못했다.
* **실제 학생 소요 시간**: 6절 표는 글자 수·조작 수 기반 추정이다.
* `npm run build`(Next.js 빌드)·개발 서버(`localhost:3000/class1/...`)로 여는 것은 하지 않았다. 앱 내부 참조가 모두 상대경로라 basePath와 무관하지만, 배포 전 한 번 열어 보면 좋다.
* 실제 CDN 차단 환경(three.js를 못 받는 경우)의 2D 자동 대체는 확인하지 못했다(`?no3d=1`로만 확인).

## 8. 결론

**배포에 막는 문제는 없다(높음 0건).** 과학적으로는 수치·극·연결 방식이 모두 교과서·실험관찰·지도서와 일치하고, 도입하지 말아야 할 개념(자기장, (+)극↔N극, 철심 없는 전자석, 감는 횟수)도 모두 피했다.

다만 **중간-1**(실험 1의 결론 문장 "전자석은 전기가 흐를 때만 자석의 성질이 나타납니다"가 화면에 없음)은 이 차시 학습 목표·평가와 직결되므로 **한 줄 추가를 권한다**(`data/lesson-config.js`의 `switchCheck.correct` 또는 `knowCard`). 낮음 4건은 시간이 있을 때 손보면 된다.
