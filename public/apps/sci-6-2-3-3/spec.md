## 1. 지도서 분석

### 1.1 차시 개요 (지도서 284쪽)
- 학습 목표: ① 전자석을 만들 수 있다. ② 전자석의 성질을 영구 자석의 성질과 비교하여 탐색할 수 있다.
- 성취기준 `[6과15-03]` 전자석을 만들어 전자석의 성질을 탐색하고 전자석이 사용되는 예를 조사할 수 있다(288쪽 차시 평가 방법).
- 탐구 목표(286쪽): "전자석을 만들고 전자석의 성질을 영구 자석의 성질과 비교하여 탐색할 수 있다." 탐구 태그: **탐구 설계 | 자료 수집 및 비교 분석 | 결론 도출 및 적용**.
- 교수·학습 흐름(287쪽 활동 흐름표, 도입 5분 → 전개 65분 → 정리 10분): 도입(자석이 될 수 있는 것 이야기하기) → 전개([탐구 활동] 전자석의 성질을 영구 자석의 성질과 비교하여 탐색하기: 실험 1 전자석 만들기, 실험 2 전자석의 성질 알아보기) → 정리(전자석의 성질 정리하기). `CLAUDE.md`의 예상하기→실험하기→기록·분석하기→정리하기 4단계와 대응된다.

### 1.2 준비물 및 안전 (284, 286쪽)
- 모둠: 둥근 머리 볼트(철 막대, 길이 8 cm·굵기 0.4 cm), 에나멜선(굵기 0.5 mm), 종이, 셀로판테이프, 전지(1.5 V) 2개, 전지 끼우개 2개, 집게 달린 전선 여러 개, 스위치, 사포, 둥근 철 고리 여러 개(두께 0.1 cm·지름 1 cm, 자화 안 된 것), 나침반 2개, 나침반 붙임딱지(실험관찰 77쪽). 개인: 면장갑.
- 안전 수칙(284, 286쪽): 젖은 손으로 실험하지 않는다 / 둥근 머리 볼트·에나멜선의 날카로운 부분에 찔리지 않도록 조심한다 / 에나멜선 끝부분을 사포로 문지를 때 손을 다치지 않도록 주의한다 / **스위치를 오래 닫고 있으면 전자석이 뜨거워지므로 스위치는 필요할 때만 닫는다** / 전자석에 전지를 오랫동안 연결해 두지 않는다.
- 지도상 유의점(284쪽): 3학년 "자석의 이용" 단원 사전 지식과 연계 지도 / **전류에 의한 자기장 개념은 도입하지 않으며, 전자석에 전기가 흐를 때 철로 만든 물체를 끌어당기거나 나침반 바늘을 움직이는 등 현상에 초점을 맞춰 지도한다** → 이 앱은 자기장·전류 방향 화살표 같은 물리 개념도를 쓰지 않고, "붙는다/붙지 않는다", "나침반이 가리키는 방향" 등 **관찰 가능한 현상**만 다룬다.

### 1.3 실험 내용 · 측정값·관찰 결과 (지도서 284~287쪽, 실험관찰 39~42쪽 — 반드시 이 표현·수치만 사용)

**실험 1 — 전자석 만들기 (실험관찰 39~40쪽)**
- 둥근 머리 볼트에 종이를 감고 셀로판테이프로 고정 → 에나멜선을 한쪽 방향으로 촘촘히 100번 정도 감음(양쪽 끝 5 cm씩 남김) → 끝부분을 사포로 문질러 코팅을 벗김 → 전기 회로에 연결.
- 전자석의 끝부분을 둥근 철 고리에 가까이 하고 스위치를 닫기 전/닫은 뒤를 비교: **닫기 전 = 붙지 않음, 닫은 뒤 = 붙음**. 결론(실험관찰 40쪽 빈칸 정답): "전자석은 (전기가 흐를 때만) 자석의 성질이 나타납니다."

**실험 2 — 전자석의 성질 알아보기 (지도서 285~287쪽, 실험관찰 41~42쪽)**
1. 전지 개수를 달리하며(1개 / 2개 직렬연결) 스위치를 닫은 뒤 전자석 끝부분에 붙는 **둥근 철 고리 개수**를 셈.
   - 전지 1개 연결: **철 고리 4개**
   - 전지 2개 직렬연결: **철 고리 8개**
   - 알게 된 성질(지도서 287쪽): "전자석은 직렬연결한 전지의 개수가 많을수록 **세기가 세집니다**."
2. 전자석 양쪽 끝에 나침반을 놓고, 전지의 방향을 바꾸며 스위치를 닫은 뒤 나침반 바늘이 가리키는 방향(=전자석의 극)을 관찰.
   - 전지 방향을 바꾸기 전: 왼쪽 끝 **N극**, 오른쪽 끝 **S극**
   - 전지 방향을 바꾼 뒤: 왼쪽 끝 **S극**, 오른쪽 끝 **N극**
   - 알게 된 성질(지도서 287쪽): "전자석에 연결한 전지의 방향을 반대로 바꾸면 전자석의 극이 반대로 바뀝니다."
- **정리해요(지도서 287쪽, 실험관찰 42쪽 — 모범 답안 원문 그대로)**: "영구 자석의 세기는 일정하지만 전자석의 세기는 전자석에 직렬연결한 전지의 개수가 많아질수록 세집니다. 영구 자석의 극은 변하지 않지만 전자석에 연결한 전지의 방향이 반대로 바뀌면 전자석의 극이 반대로 바뀝니다."

### 1.4 오개념 및 지도상 유의점 (284, 287쪽)
1. **"전자석을 만들려면 철로 만든 막대가 꼭 필요하다"는 오개념**(287쪽) → 실제로는 전선만 감아도 전자석이 되지만 세기가 매우 약해 철심을 쓴다는 것은 **전류·자기장 개념과 얽혀 있어 이 차시 범위를 넘는 심화 설명**이다(1.2의 "자기장 개념 미도입" 원칙과 함께 이 앱은 다루지 않는다).
2. **"전지의 (+)극에 연결한 쪽이 항상 N극"이라는 오개념**(285쪽 참고 누리집 안내) — 생기지 않도록, 이 앱은 극을 전지의 +/- 극과 연결해 설명하지 않고 **나침반으로 관찰해 알아내는 활동**으로만 제시한다(1.2와 동일 원칙).
3. 전자석에 둥근 철 고리를 오랫동안 붙여 두면 자화되어 결과가 부정확해질 수 있음(287쪽) — 시뮬레이션이므로 실제 자화 오차는 없지만, 화면에는 "매번 새 철 고리로 잰 것처럼" 안내해 이 유의점을 반영한다.

### 1.5 평가 (지도서 288쪽)
- 평가 목표: [지식·이해] 전자석의 성질을 영구 자석의 성질과 비교하여 설명할 수 있다 / [과정·기능] 전자석을 만들 수 있으며 전자석의 성질을 영구 자석의 성질과 비교하여 탐색할 수 있다 / [가치·태도] 흥미를 가지고 실험에 적극적으로 참여했다.
- 차시 평가 문항 1(288쪽, OX): "⑴ 세기를 바꿀 수 없다(X, 전자석은 바꿀 수 있음) ⑵ 극의 방향을 바꿀 수 있다(O) ⑶ 전기가 흐를 때만 자석의 성질이 나타난다(O)" → 이 앱 분석 단계 문항의 근거로 쓴다.

### 1.6 이전·다음 차시 연계 (스포일러 주의)
- **이전(탐구 2, "전기 회로에 전지 한 개를 더 연결하면 어떻게 될까?")**: 전지 직렬연결·전구 밝기 변화. 이 차시의 "전지 개수 → 세기" 결과와 원리는 이어지지만, 전구·전류 세기 개념을 다시 설명하지 않는다.
- **다음(탐구 4, "전자석을 사용하는 예를 알아볼까?")**: 전자석 활용 사례(스피커, 자기 부상 열차 등) 조사. **이 앱에서 활용 사례를 언급하지 않는다.**
- **다음 다음(탐구 5, "전기, 어떻게 사용해야 할까?")**: 전기 절약·안전. 이 앱과 무관하므로 다루지 않는다.

## 3. 화면 설계 (예상하기 → 실험하기 → 기록·분석하기 → 정리하기(+궁금한 점))

### 3.0 공통 전제
- 태블릿 가로·세로, 큰 터치 영역, 6학년 눈높이 한국어. 로그인 필수, `app_progress` 자동 저장·이어서 하기.
- "전자석 사용 예"(다음 차시), "전기 절약·안전"(다다음 차시) 언급 없음(1.6). "자기장", "전류의 방향"(화살표 다이어그램) 같은 도입하지 않는 개념·용어는 쓰지 않는다(1.2·1.4).
- 실험하기 도입에 안전 안내 한 줄: "실제 실험은 선생님과 함께, 스위치는 오래 닫아 두지 않아요. 이 화면은 안전한 모형 실험이에요."
- 전자석 내부의 눈에 보이지 않는 자기 작용은 다루지 않고(1.2), **관찰 가능한 결과**(고리가 붙는 개수, 나침반이 가리키는 방향)만 3D로 보여준다. 코일에 전류가 흐를 때 살짝 빛나는 표시 정도는 "전기가 흐르고 있음을 보여주는 모형" 배지로 밝힌다.

### 3.1 예상하기 (탐구형 질문 1개)
- 질문: "전자석에 연결한 전지의 개수나 방향을 바꾸면 전자석에는 어떤 변화가 생길까요?"(최소 글자 수 5자)
- 힌트(답을 말하지 않고 순서대로 열림):
  1. "3학년 때 배운 자석의 성질(세기·극)을 떠올려 보세요."
  2. "막대자석 같은 영구 자석과 전자석을 비교하며 생각해 보세요."

### 3.2 실험하기 — 3단계 phase (앞 phase를 마쳐야 다음이 열림)

**Phase 0 — 스위치와 전자석 (1칸)**
- 단일 조건(factor 없음 또는 옵션 1개짜리 factor `switch: "test"`). 실행: 전자석(둥근 머리 볼트+에나멜선 코일)과 둥근 철 고리를 3D로 보여주고, 스위치를 열었을 때(고리가 붙지 않음) → 닫았을 때(고리가 달라붙음) 순서로 짧게 연출(3~4초, 드래그로 회전 가능).
- 관찰 카드(보기 고르기): "스위치를 열었을 때와 닫았을 때, 전자석의 끝부분에 둥근 철 고리는 언제 붙었나요?" 보기: **"스위치를 닫았을 때만 붙는다"(정답)** / "스위치를 열었을 때만 붙는다" / "항상 붙는다" / "전혀 붙지 않는다".

**Phase 1 — 전지 개수 (factor `battery`: 1개 / 2개 직렬연결, 2칸)**
- 실행: 스위치를 닫은 뒤 전자석 끝부분에 둥근 철 고리 여러 개가 쌓인 통을 가까이 하는 연출(3~4초). 전지 2개 칸은 전지 끼우개 2개를 직렬로 잇는 모습도 보여준다.
- 관찰 카드(수치 입력, `type: "numeric"`): "전자석에 붙는 둥근 철 고리의 개수를 세어 봅시다." 필드 `rings`(단위 "개", `step: 1`, `min: 0`, `max: 20`) — 화면에 붙은 고리 개수가 바로 보이므로 학생은 세어서 입력(추천값은 미리 채우지 않고 직접 세어 입력하게 한다).
  - **측정값 표기 관련**: 이 값은 "개수"(이산량)이므로 `CLAUDE.md`의 "소수 첫째 자리로 제시" 규칙(연속량 측정 규칙)을 적용하지 않고 **정수(개)**로 다룬다. 자세한 이유는 9절 "열린 질문" 참고.

**Phase 2 — 전지 방향 (factor `direction`: 바꾸기 전 / 바꾼 뒤 × factor `position`: 왼쪽 나침반 / 오른쪽 나침반, 2×2=4칸)**
- 실행: 전자석 양쪽 끝에 나침반 2개를 놓은 장면. `direction`이 바뀌면 전지의 방향을 반대로 꽂는 애니메이션(4~5초) 후 나침반 바늘이 새 방향으로 정지. 같은 `direction`에서 `position`만 바꾸는 두 번째 칸은 카메라만 반대쪽 나침반으로 이동(2초, 재연출 없음).
- 관찰 카드(보기 고르기): "나침반 바늘이 가리키는 방향을 보고 이 끝의 극을 골라 봅시다." 보기: "N극" / "S극".
  - 정답: 바꾸기 전 왼쪽=N극·오른쪽=S극 / 바꾼 뒤 왼쪽=S극·오른쪽=N극(1.3).
  - 나침반 바늘의 N극(빨간) 끝은 전자석과 다른 극 쪽으로 끌리는 모습으로 표현한다(자석의 다른 극끼리 끌어당김 — 3학년 "자석의 이용" 사전 지식과 일치, 287쪽 5 지도 길잡이). 자기장 화살표 등은 그리지 않고 "나침반 바늘의 움직임"만 보여준다(1.2).

### 3.3 기록·분석하기
- 표 1(수치 기록, Phase 1): 전지 개수 1개 / 2개 — 내가 기록한 고리 개수(개).
- 표 2(보기 기록, Phase 2): 방향(바꾸기 전/바꾼 뒤) × 위치(왼쪽/오른쪽) — 내가 고른 극.
- 보기 고르기(퀴즈) **2개**(규칙 "1~2개" 범위, 학생 자신의 기록을 보고 답함):
  1. "내 기록을 보면, 전자석에 연결한 전지의 개수가 많아질수록 전자석의 세기는 어떻게 될까요?" 보기: **세진다(정답)** / 약해진다(`wrongBy`: "내가 기록한 고리 개수를 다시 비교해 보세요.") / 변화가 없다(`wrongBy`: "전지 1개일 때와 2개일 때 고리 개수가 같았는지 다시 확인해 보세요.").
  2. "내 기록을 보면, 전자석에 연결한 전지의 방향을 바꾸면 전자석의 극은 어떻게 될까요?" 보기: **반대로 바뀐다(정답)** / 변화가 없다(`wrongBy`: "방향을 바꾸기 전과 바꾼 뒤에 고른 극이 같았는지 다시 확인해 보세요.") / 항상 N극이 된다(`wrongBy`: "방향을 바꾼 뒤 왼쪽·오른쪽에 고른 극을 다시 확인해 보세요.").

### 3.4 정리하기 (탐구형 질문 1개, 발전 질문 없음)
- 질문: "전자석의 성질을 영구 자석의 성질과 비교하여 정리해 써 봅시다."
- 모범 답안(지도서 287쪽 "정리해요" 원문 그대로): "영구 자석의 세기는 일정하지만 전자석의 세기는 전자석에 직렬연결한 전지의 개수가 많아질수록 세집니다. 영구 자석의 극은 변하지 않지만 전자석에 연결한 전지의 방향이 반대로 바뀌면 전자석의 극이 반대로 바뀝니다."

### 3.5 궁금한 점 (선택, 한 줄)
- "전자석에 대해 더 궁금한 점이 있으면 적어 보세요(안 적어도 괜찮아요)."

## 7. 3D 장면 스케치 (three.js, `sim3d.js` 활용)

- 공통 배경: 책상 위 실험대(모형). 카메라 드래그 회전, 핀치/휠 확대·축소.
- **전자석**: 회색 원통(둥근 머리 볼트) 위에 구리색 코일(에나멜선을 감은 모습, 촘촘한 나선 텍스처 또는 반복 링 메시)을 감고, 양 끝에 검은 집게 전선이 전지 끼우개(전지 1~2개)·스위치로 이어지는 회로.
- **Phase 0**: 전자석 끝부분 앞에 은색 둥근 철 고리 여러 개가 놓인 접시. 스위치 토글(구체/레버 클릭 대신 "닫기" 버튼) → 스위치 닫히는 애니메이션 → 고리 1~2개가 톡 붙는 트윈.
- **Phase 1**: 같은 장면에서 전지 1개/2개(직렬) 회로를 보여주고, 스위치를 닫으면 고리 여러 개가 차례로 달라붙는 트윈(전지 2개 칸은 더 많이 달라붙어 시각적으로도 차이가 보이게). 학생이 화면에 붙은 고리를 세어 입력.
- **Phase 2**: 전자석을 수평으로 놓고 양 끝에 나침반(원판+빨강/파랑 바늘) 배치. 처음엔 두 나침반 모두 같은 방향(북쪽, 모형). 스위치를 닫으면 두 바늘이 각각 정해진 각도로 회전해 멈춤(코일 축과 나란히, N쪽 반대 극으로 끌리는 모습). 전지 방향을 바꾸는 애니메이션(전지 끼우개 안에서 전지가 180도 회전하는 트윈, 1.5~2초) 후 두 바늘이 반대로 회전.
- 모든 자기 작용은 "모형" 배지로 표시(코일에 전류가 흐를 때 은은한 노란빛 표현 정도만, 자기장선·화살표 없음 — 1.2 지도상 유의점 반영).
- `?no3d=1`(2D 대체)에서는 위 장면을 정적 도해(고리 개수는 아이콘 나열, 나침반은 회전한 화살표 이미지)로 대체.

## 9. 공통 틀 확장 필요: **없음**

Phase 0(factor 없이 단일 cell)·Phase 1(수치 측정형)·Phase 2(보기 고르기, factor 2개 조합)는 모두 README 3절의 기존 패턴(색 관찰형·수치 측정형)을 그대로 조합해 구현 가능하다. 다만 Phase 2에서 "같은 `direction`의 두 번째 `position` 칸은 재연출 없이 카메라만 이동"하는 것은 `run(sel)` 함수 내부 로직(이미 같은 방향으로 바늘이 멈춰 있으면 카메라 트윈만 실행)으로 처리하며, 이는 앱 자체의 `view.run` 구현 문제이지 공통 틀 확장이 필요한 부분이 아니다.

2. **나침반 바늘의 물리적 방향 표현 수준** — 나침반 바늘이 "다른 극끼리 끌어당긴다"는 원리로 실제 물리에 맞게 회전하는 모습을 보여줄지, 아니면 단순히 "붙임딱지에 쓸 극"만 정답으로 판정하고 바늘은 상징적으로만 움직일지. **추천안: 3학년 자석 단원과 연계된 "다른 극끼리 끌림" 원리를 반영해 바늘을 회전시키되, 자기장 개념 설명 없이 결과만 보여준다**(1.2·3.2 참고). 승인 부탁드립니다.
3. **Phase 0(스위치)을 1칸으로 줄인 것** — 실험관찰 39~40쪽 원문은 "닫기 전"/"닫은 뒤" 두 상태를 각각 표시하는 칸이 있지만, 이 앱은 시간 절약을 위해 **하나의 비교 관찰 카드(보기 고르기)**로 합쳤다. 이미 만든 6-1-2 계열 앱들의 "핵심 활동만, 질문은 최소로" 원칙과 일치한다고 판단했다(추천안: 그대로 진행). 승인 부탁드립니다.
