## 1. 지도서 분석

### 1.1 차시 개요 (지도서 138쪽)
- 학습 목표
  1. 산성 용액과 염기성 용액을 섞으면서 지시약의 색깔 변화를 관찰할 수 있다.
  2. 용액의 성질 변화를 실험을 통해 추론할 수 있다.
- 성취기준 `[6과09-02]` 산성 용액과 염기성 용액의 성질을 관찰하고, 산성 용액과 염기성 용액을 섞을 때 용액의 성질 변화를 실험을 통해 추론할 수 있다. (지도서 138, 141, 146쪽)
- 이 차시의 핵심 탐구 활동은 하나다: **묽은 염산과 묽은 수산화 나트륨 용액을 섞을 때 용액의 색깔 변화 관찰하기**(지도서 138~140, 144~145쪽 / 실험관찰 12~13쪽). 직전 차시(5차시, 지도서 130~137쪽)에서 산성·염기성 용액이 탄산 칼슘·단백질과 반응하는 성질을 배운 뒤, 이번 차시에서 두 용액을 "섞을 때"의 성질 변화로 이어진다.
- 앞 차시(탐구 2, 118~129쪽)에서 이미 "지시약"·"산성 용액"·"염기성 용액"·붉은 양배추 용액의 색 변화표를 배웠으므로, 이 차시는 그 지식을 전제로 진행한다(새로 정의하지 않음).

### 1.2 준비물·안전 (지도서 138, 144~145쪽)
- 모둠: 묽은 염산, 묽은 수산화 나트륨 용액, 24홈판, 실험 도움판 ③(실험관찰 75쪽), 붉은 양배추 용액, 12색 색연필.
- 개인: 실험복, 보안경, 실험용 장갑.
- 안전(138, 145쪽): 실험복·보안경·실험용 장갑 필수, 유리 기구 파손 주의, 용액이 피부/눈에 닿으면 흐르는 물로 충분히 씻기(필요시 보건실·병원), 맛보거나 냄새 맡지 않기(묽은 염산 냄새 흡입 시 신선한 공기 마시고 휴식), 환기가 잘 되는 곳에서 실험, 실험 후 사용한 물질은 교사 안내에 따라 폐기(묽은 염산 → 폐수통(산), 묽은 수산화 나트륨 용액 → 폐수통(알칼리계), 145쪽).
- 준비물 길잡이(138쪽): 묽은 염산과 묽은 수산화 나트륨 용액은 **같은 몰 농도(0.1 M)** 로 준비 — 이 수치는 교사 준비용이며 학생 화면에는 노출하지 않는다(중성·중화·몰 농도 개념은 이 단원에서 다루지 않음, 106쪽).

### 1.3 실험 절차와 정량 조건 (지도서 138~140, 144~145쪽 — 반드시 이 값만 사용)
24홈판(4행×6열) 중 **두 줄만** 사용한다.
1. 실험 도움판 ③을 24홈판에 올리고, **첫째 줄** 6칸 각각에 **묽은 염산을 10방울씩** 넣는다.
2. 그 6칸에 **붉은 양배추 용액을 5~6방울씩** 떨어뜨린다(처음 색: 산성 + 붉은 양배추 용액 = **붉은색**, 지도서 121·122·126·139쪽에서 이미 확립된 값).
3. 실험 도움판 ③에 표시된 방울 수만큼(**0, 5, 10, 15, 20, 25방울**, 실험관찰 75·144쪽 표) **묽은 수산화 나트륨 용액**을 그 6칸에 각각 넣고 색깔 변화를 관찰한다(0방울 칸은 비교용 대조군).
4. **넷째 줄**에서 묽은 염산과 묽은 수산화 나트륨 용액의 역할을 바꿔 같은 방법으로 반복한다: 6칸에 **묽은 수산화 나트륨 용액을 10방울씩**, **붉은 양배추 용액 5~6방울**(처음 색: **노란색**, 지도서 122·126쪽에서 이미 확립된 값), 그 후 **묽은 염산을 0, 5, 10, 15, 20, 25방울**씩 넣는다.
5. 실험 결과(실제로는 색연필로 그려 기록, 144쪽)를 "붉은 양배추 용액의 색깔 변화표"(실험관찰 12~13쪽, 산성이 강함 ↔ 염기성이 강함 스펙트럼 그림)와 비교한다.
- 총 12칸(6칸×2줄)을 모두 관찰·기록해야 한다. 24홈판의 나머지 2줄은 이 실험에서 쓰지 않는다.
- 지도 길잡이(140, 144쪽): "용액의 농도나 떨어뜨린 방울의 크기에 따라 지시약의 색깔 변화는 예시 답안과 다르게 나타날 수 있다. 특정 색깔을 찾아내려고 하기보다는 학생들의 관찰 결과를 색연필로 표현하도록 하며, 전반적인 색깔 변화를 중점으로 관찰한다." → **정확한 색상 하나가 아니라 "계열"로 판단**하는 것이 지도서의 공식 방침이다.

### 1.4 색 변화 값 — 지도서 근거 + 일반 지시약 지식(지도서 외 표시)
- **지도서에 문자로 직접 적힌 값(그대로 인용, 139~140, 144쪽)**:
  - 묽은 염산(10방울) + 붉은 양배추 용액 → **붉은색 계열**.
  - 묽은 염산에 묽은 수산화 나트륨 용액을 많이 넣을수록 → 붉은색 계열에서 **푸른색(노란색) 계열**로 변함.
  - 묽은 수산화 나트륨 용액(10방울) + 붉은 양배추 용액 → **노란색 계열**(평가 문항 1, 141쪽: "노란색 계열에서 붉은색 계열로 변하였습니다").
  - 묽은 수산화 나트륨 용액에 묽은 염산을 많이 넣을수록 → 푸른색(노란색) 계열에서 **붉은색 계열**로 변함.
  - 일반 규칙(탐구 2, 121쪽, 같은 지시약이므로 이 차시에도 적용): "붉은 양배추 용액은 산성 용액에서는 붉은색 계열, 염기성 용액에서는 푸른색이나 노란색 계열로 변한다."
- **끝값(0방울 대조군)은 탐구 2(지도서 122, 126쪽)에서 이미 확립된 정확한 색과 반드시 일치시킨다**: 묽은 염산 + 붉은 양배추 용액 = 붉은색, 묽은 수산화 나트륨 용액 + 붉은 양배추 용액 = 노란색(다른 염기성 용액과 달리 노란색인 것도 이미 확립됨). 시범 앱(`sci-6-1-1-2`)의 실제 색상값(`data/lesson-config.js`)과 동일한 헥스를 재사용해 앱 간 일관성을 유지한다: 붉은색 `#d23a57`, 노란색 `#e7c52c`, 붉은 양배추 원액(보라색) `#7b3fa0`.
- **지도서 외(일반 과학 지식, 안토사이아닌 지시약의 연속 스펙트럼)**: 0방울과 25방울 사이(5·10·15·20방울)의 정확한 중간 색은 지도서에 수치나 색 이름으로 나와 있지 않다(그림 자료만 있고 텍스트로 추출되지 않음). 안토사이아닌계 지시약은 강산에서 붉은색, 중간 산도에서 분홍·자주색, 약염기~중간 염기에서 푸른색, 강염기에서 노란빛으로 **연속적으로** 변하는 것이 일반적인 화학 지식이다. 이 값은 "지도서 외"로 표시하고, 화면에는 정확한 색 이름 대신 지도서가 실제로 쓰는 세 범주만 고르게 한다: **"붉은색 계열" / "그 사이의 색(분홍·보라 등)" / "푸른색이나 노란색 계열"**. 3D 애니메이션은 부드러운 색 보간(모형)으로 보여주되, 학생이 실제로 고르는 관찰 보기는 이 세 범주로 제한해 지도서에 없는 정밀한 색 이름을 사실처럼 단정하지 않는다.
- 두 용액은 같은 몰 농도(0.1 M, 138쪽)이므로, 25방울(반대 용액의 2.5배 부피)을 넣은 칸은 반대쪽 용액이 크게 우세해져 사실상 반대쪽 대조군 색(노란색 계열 / 붉은색 계열)에 가까워진다 — 이는 평가 문항 1(141쪽, "노란색 계열에서 붉은색 계열로 변하였습니다")과 정확히 들어맞는 결과이므로, 25방울 칸의 "정답 계열"은 대조군과 동일한 계열로 설계한다.

### 1.5 지도상 유의점 (지도서 106, 138~140, 145~147쪽)
- **다루지 않는 개념(106, 138, 140쪽에서 3번 반복)**: 중성, pH, 중화(반응·중화점·중화열 포함). 앱 화면·피드백·모범 답안 어디에도 이 용어들을 쓰지 않는다. 지도서 142쪽의 중화 반응 화학식(H⁺+OH⁻→H₂O 등)과 수국 색 변화 보충 자료는 **이 차시 범위 밖의 심화 자료**이므로 앱에 넣지 않는다.
- 색깔 변화는 "정확한 색"이 아니라 "전반적인 경향(계열)"으로 판단하도록 지도(140, 144쪽) → 1.4 참고.
- 두 용액을 떨어뜨릴 때 방울 크기를 일정하게 유지하도록 지도(139, 144쪽) — 3D 애니메이션에서 방울 크기를 일정하게 표현.
- 실험 전 안전 수칙(138, 139쪽), 실험 후 폐기 방법(145쪽) — 앱에는 안전 안내 문구로만 반영(실제 폐기 조작은 없음).
- 학생이 성질이 변하는 까닭을 궁금해하면, "농도가 같은 두 용액을 섞으면 혼합 용액은 더 많이 섞은 용액의 성질을 나타낸다" 수준까지만 안내(140쪽 지도 길잡이 5) — 정리하기의 보충 설명으로 활용 가능.
- 색깔이 예시와 다르게 나올 수 있음을 학생에게도 안내(140쪽) — 실험하기 화면에 "실제 교실 실험처럼, 넣는 방울 수·진하기에 따라 색이 조금씩 다르게 보일 수 있어요"라는 모형 안내 문구를 둔다.

### 1.6 오개념
- 이 차시 범위(138~147쪽)에는 별도의 "오개념" 박스가 없다.
- 지도서가 명시적으로 경계하는 오해는 "산성 용액과 염기성 용액을 섞으면 성질이 사라지거나 즉시 반대로 바뀐다"이다 — 실제로는 "점점 약해지다가" 변하는 **점진적 변화**이며(140, 145, 147쪽 "산성이 점점 약해지다가"), 이 표현을 결론 모범 답안과 분석 퀴즈에 정확히 반영한다.
- 예상하기 단계에서 나올 법한 학생 반응(139쪽 지도 길잡이 예시): "산성도 염기성도 아닌 용액이 될 것 같다", "둘 다 성질이 약해질 것 같다" — 이는 오개념이 아니라 지도서가 제시하는 자연스러운 예상 답 예시이므로, 힌트에서 이런 방향의 생각을 유도하되 정답으로 단정하지 않는다.

### 1.7 평가 (지도서 141, 146쪽)
- 평가 목표: [지식·이해] 산성 용액과 염기성 용액을 섞었을 때 용액의 성질 변화를 추론하여 설명 / [과정·기능] 성질 변화를 실험을 통해 관찰 / [가치·태도] 실험 도구를 옳게 사용하고 안전에 유의하며 적극적으로 참여.
- 평가 문항 1(141쪽, 3지선다, 그대로 인용 가능): "붉은 양배추 용액을 떨어뜨린 묽은 수산화 나트륨 용액에 묽은 염산을 계속 넣었더니 용액의 색깔이 노란색 계열에서 붉은색 계열로 변하였습니다. … 옳은 것을 보기에서 골라 봅시다." 보기 ㉠용액의 성질은 변하지 않았다 / ㉡염기성 용액의 성질이 점점 강해졌다 / ㉢염기성 용액의 성질이 약해지다가 산성 용액이 되었다(정답).
- 평가 문항 2(141쪽, 서술형 → 앱에서는 보기형으로 각색): "페놀프탈레인 용액을 떨어뜨린 묽은 염산에 묽은 수산화 나트륨 용액을 계속 넣었더니 용액의 색깔이 붉은색으로 변하였습니다. 이 결과로 알게 된 용액의 성질 변화를 써 봅시다." 채점 기준(141쪽): 상 = 산성→염기성 변화 과정을 모두 옳게 씀 / 중 = 염기성으로 변한다고만 씀 / 하 = 변화를 쓰지 못함. 예시 답: "산성 용액에 염기성 용액을 계속 넣으면 산성이 점점 약해지다가 염기성으로 변한다."
- 이 상/중/하 톤을 "기록·분석하기" 분석 퀴즈 피드백 문구에 반영한다(오답이면 "산성이 약해지다가"라는 점진적 변화 표현을 쓰도록 유도).

## 2. 앱 종류 판단

**실험 시뮬레이션 앱**으로 만든다.
- 근거: 지도서 138~147쪽 전체가 "동기 유발 → 실험해요(1~5단계, 24홈판·붉은 양배추 용액·색연필을 쓰는 실제 손 실험) → 정리해요 → 평가"로 구성된 정식 탐구 활동(위 1.1, 1.3)이며, 138쪽 학습 목표 자체가 "…색깔 변화를 관찰할 수 있다", "…실험을 통해 추론할 수 있다"로 실험 중심이다. "조사하기" 차시가 아니다.
- 이 차시는 이미 확립된 6가지 용액 지식(탐구 2)을 두 용액(묽은 염산·묽은 수산화 나트륨 용액)만으로, **혼합 비율(방울 수)**이라는 새로운 조건 축을 추가해 다루므로, 조건을 바꿔 가며 다각적으로 실험한다는 규칙에 정확히 들어맞는다.

## 3. 화면 설계 (예상하기 → 실험하기 → 기록·분석하기 → 정리하기 → 궁금한 점)

### 3.0 공통 전제
- 조건은 두 축이다: **단계**(A: 산성 시작 / B: 염기성 시작, 지도서 1~2줄·4번째 줄에 대응) × **넣는 방울 수**(0, 5, 10, 15, 20, 25방울, 지도서 표 그대로). 총 12칸(6칸×2단계).
- 색은 1.4의 세 범주(붉은색 계열 / 그 사이의 색 / 푸른색이나 노란색 계열)만 관찰 보기로 쓴다. 0방울 칸은 대조군으로, A단계는 반드시 "붉은색 계열", B단계는 반드시 "푸른색이나 노란색 계열"이 정답이다(1.4의 확립값).
- 이미 탐구 2 앱에서 다룬 지시약 개념·6가지 용액은 다시 설명하지 않는다. 다만 "붉은 양배추 용액"만 이 차시에서 쓴다는 점, 묽은 염산·묽은 수산화 나트륨 용액이라는 두 용액만 쓴다는 점은 실험하기 도입에서 짧게 안내한다.

### 3.1 예상하기
- 질문 1(지도서 139쪽 동기 유발 질문 그대로 활용): "염기성 용액인 빨랫비누 물에 산성 용액인 식초(산성 용액)를 섞으면 어떻게 될까요? 그렇게 생각한 까닭도 함께 적어 보세요." → 서술형 입력.
- 질문 2(지도서 146쪽 가설 설정 질문 각색): "묽은 염산에 묽은 수산화 나트륨 용액을 아주 조금씩 계속 넣으면 묽은 염산의 성질은 어떻게 될까요? 반대로 묽은 수산화 나트륨 용액에 묽은 염산을 계속 넣으면 어떻게 될까요?" → 서술형 입력.
- 힌트(단계적, 답을 직접 주지 않음):
  1. "지난 시간에 산성 용액과 염기성 용액은 서로 다른 성질을 가졌다는 것을 배웠어요. 성질이 다른 두 용액이 만나면 어떤 일이 일어날지 생각해 보세요."
  2. "눈에 잘 보이지 않는 변화도 지시약을 사용하면 색깔로 알아챌 수 있어요."
  3. "한 번에 많이 넣을 때와 아주 조금씩 여러 번 나누어 넣을 때, 성질이 갑자기 뒤바뀔지 서서히 바뀔지 비교해 생각해 보세요."
- 답은 절대 제시하지 않는다. 입력값은 localStorage에 즉시 임시 저장.

### 3.2 실험하기 (3D 장면)
- **도입 카드(실험 전에 알아 두기, 답 누설 아님)**: "이번 실험은 붉은 양배추 용액 한 가지만 지시약으로 써요. 묽은 염산과 묽은 수산화 나트륨 용액을 섞는 비율(방울 수)을 바꿔 가며 색깔 변화를 살펴봅시다." (지도서 138, 144쪽 준비물·절차 요약, 새 개념 설명이 아니라 이 차시의 실험 방법 안내이므로 예상하기 뒤에 배치 가능)
- **장면 구성**: 실험대 위에 실험 도움판 ③을 얹은 24홈판(2줄만 강조, 나머지 2줄은 흐리게 표시해 "이번 실험에서 쓰지 않음"을 시각적으로 알림), 묽은 염산 점적병(무색투명 라벨), 묽은 수산화 나트륨 용액 점적병(무색투명 라벨), 붉은 양배추 용액병(보라색 `#7b3fa0`), 색연필 통(12색, 장식용). three.js로 단순 형태(실린더=점적병, 평판=홈판)로 표현하고 "모형" 배지를 표시.
- **조작 흐름**:
  1. 단계 선택(A: 묽은 염산 시작 / B: 묽은 수산화 나트륨 용액 시작, B는 A를 6칸 모두 마쳐야 열림) → 시작 용액 10방울 + 붉은 양배추 용액 5~6방울이 자동으로 부어지는 애니메이션(대조군 색으로 표시).
  2. 넣는 방울 수 선택(0/5/10/15/20/25 중 1개) → 반대쪽 점적병이 강조됨.
  3. "▶ 넣기" 버튼 → 스포이트로 방울을 떨어뜨리는 애니메이션(방울 수가 많을 때는 숫자 카운터로 표시해 25번 반복 렌더링하지 않음) → 홈 안 색이 1.4의 세 범주 값으로 서서히 바뀐다(0.6~1초 트랜지션, 방울 수가 많을수록 최종 색에 더 가깝게 보간).
  4. "기록" 버튼으로 현재 조합(단계, 방울 수, 관찰된 색 범주)을 기록 목록에 저장. 같은 칸을 다시 실험하면 마지막 기록으로 덮어쓴다.
- **관찰 항목**: 단계, 넣은 방울 수, 색 범주(문자열, "붉은색 계열" / "그 사이의 색(분홍·보라 등)" / "푸른색이나 노란색 계열").
- **카메라 조작**: three.js `OrbitControls`, 터치 1-드래그 회전, 2-핑거 핀치 확대/축소, 더블탭으로 초기 각도 복귀.
- **기록 데이터 형식(예시)**:
```json
{
  "phase": "A",             // "A"(묽은 염산 시작) | "B"(묽은 수산화 나트륨 용액 시작)
  "drops": 15,               // 0 | 5 | 10 | 15 | 20 | 25
  "colorFamily": "그 사이의 색(분홍·보라 등)",
  "recordedAt": 1737350000000
}
```
- A단계 6칸, B단계 6칸을 모두 기록해야 "기록·분석하기"로 진행 가능(진행률 표시).

### 3.3 기록·분석하기
- **자동 생성 표**: 단계(행, 2개) × 방울 수(열, 6개) 매트릭스. 학생이 기록한 색 범주를 그대로 채워 넣은 "색상 매트릭스"(칩+글자, 시범 앱과 동일 방식). 0방울과 25방울 칸이 1.4의 확립값(붉은색 계열/푸른색이나 노란색 계열)과 다르면 "다시 실험해 볼까요?" 안내(정답을 알려주지 않고 재실험 유도만).
- 이 실험은 범주형 결과이므로 시범 앱과 같은 이유로 수치 그래프 대신 **색상 매트릭스 표**를 시각 자료로 쓴다. (보충: 방울 수가 늘수록 색이 어느 방향으로 이동하는지 화살표 아이콘으로 표의 좌→우 방향에 표시해, "점점 변한다"는 경향을 시각적으로 강조한다.)
- **분석 퀴즈(보기 중 고르기, 지도서 141쪽 근거)**:
  1. (141쪽 평가 문항 1 그대로) "붉은 양배추 용액을 떨어뜨린 묽은 수산화 나트륨 용액에 묽은 염산을 계속 넣었더니 용액의 색깔이 노란색 계열에서 붉은색 계열로 변했어요. 이 실험에 대한 설명으로 옳은 것은?" 보기: ㉠용액의 성질은 변하지 않았다 / ㉡염기성 용액의 성질이 점점 강해졌다 / ㉢염기성 용액의 성질이 약해지다가 산성 용액이 되었다(정답).
  2. (141쪽 평가 문항 2 각색) "페놀프탈레인 용액을 떨어뜨린 묽은 염산에 묽은 수산화 나트륨 용액을 계속 넣었더니 색깔이 붉은색으로 변했어요. 이 결과로 알 수 있는 용액의 성질 변화는?" 보기: 산성이 점점 약해지다가 염기성으로 변한다(정답) / 염기성이 점점 더 강해지기만 한다 / 성질이 전혀 변하지 않는다 / 즉시 반대 성질로 뒤바뀐다(점진적 변화 오개념 겨냥, 1.6 참고).
  3. (139~140쪽 실험 방법 이해) "이 실험에서는 산성 용액과 염기성 용액을 섞을 때 성질이 변하는 것을 무엇으로 알아보았나요?" 보기: 지시약(붉은 양배추 용액)의 색깔 변화(정답) / 용액의 온도 변화 / 용액에서 나는 냄새 / 용액의 무게 변화.
  4. (147쪽 적용하기) "염기성으로 변한 용액을 다시 산성 용액으로 만들려면 어떻게 해야 할까요?" 보기: 산성 용액(묽은 염산 등)을 계속 넣는다(정답) / 염기성 용액을 더 넣는다 / 아무것도 넣지 않고 기다린다 / 지시약을 더 넣는다.
  - 각 문항 오답에는 지도서 문구를 바탕으로 한 짧은 피드백 제공(예: "표를 다시 볼까요? 방울 수가 늘어날수록 색이 어느 계열로 가까워지나요?").

### 3.4 정리하기
- 결론 질문: "산성 용액과 염기성 용액을 섞으면 용액의 성질이 어떻게 될까요? 실험 결과를 바탕으로 자신의 말로 정리해 보세요." → 서술형 입력 후 모범 답안 표시(지도서 140, 145, 147쪽 인용): "산성 용액에 염기성 용액을 계속 넣으면 산성이 점점 약해지다가 염기성으로 변하고, 반대로 염기성 용액에 산성 용액을 계속 넣으면 염기성이 점점 약해지다가 산성으로 변합니다." → 학생 답과 나란히 비교.
- 발전 질문 1(147쪽 적용하기 그대로): "묽은 염산에 묽은 수산화 나트륨 용액을 넣어 염기성으로 변한 용액을 다시 산성 용액으로 만드는 방법을 예상해 적어 보세요." → 모범 답안(147쪽): "염기성으로 변한 용액에 묽은 염산과 같은 산성 용액을 계속 넣습니다. 염기성 용액에 산성 용액을 계속 넣으면 염기성이 점점 약해지다가 산성으로 변합니다."
- 발전 질문 2(140쪽 전개 2 실생활 적용 활용): "산성 용액과 염기성 용액을 섞을 때 나타나는 성질 변화는 우리 생활에 어떻게 도움이 될 수 있을까요? 한 가지를 예상해 적어 보세요." → 모범 답안(140쪽): "공장이나 운반 차량에서 염산이 새어 나오는 사고가 발생하면 염기성을 띤 물질(예: 석회 가루)을 뿌려 산성을 약하게 합니다. 또 산성화된 토양에는 염기성 물질을 뿌려 식물이 잘 자랄 수 있게 합니다."
- "더 탐구하고 싶은 점(또는 궁금한 점)" 자유 입력란.

## 6. 3D 장면 스케치

- **물체 목록**: ① 실험대(평판), ② 24홈판(6열×4행, 실린더 배열, 첫째·넷째 줄만 밝게, 나머지 2줄은 반투명 처리해 "사용 안 함" 표시), ③ 실험 도움판 ③ 라벨(홈판 위 얇은 판, 열마다 "0/5/10/15/20/25방울" 텍스트), ④ 묽은 염산 점적병(무색투명 실린더, 라벨 "묽은 염산"), ⑤ 묽은 수산화 나트륨 용액 점적병(무색투명 실린더, 라벨 "묽은 수산화 나트륨 용액"), ⑥ 붉은 양배추 용액병(보라색 `#7b3fa0`, 라벨), ⑦ 스포이트(선택된 점적병 위에 나타남), ⑧ 색연필 통(12색, 장식용 소품 — 지도서 138쪽 준비물 반영).
- **배치**: 실험대 중앙에 24홈판(첫째 줄 앞쪽, 넷째 줄 안쪽), 왼쪽에 묽은 염산·묽은 수산화 나트륨 용액 점적병 2개, 오른쪽에 붉은 양배추 용액병과 색연필 통.
- **애니메이션**:
  1. 단계(A/B) 진입 시: 해당 줄 6칸에 시작 용액(10방울)이 순간적으로 채워지는 모션 → 곧이어 붉은 양배추 용액이 스포이트로 5~6방울 떨어지는 모션 → 6칸이 모두 대조군 색(A=붉은색, B=노란색)으로 바뀜.
  2. 방울 수 선택 후 "▶ 넣기": 반대쪽 점적병이 강조되고 스포이트가 해당 홈 위로 이동, 방울이 떨어지는 모션(방울 수가 많으면 숫자 카운터 오버레이로 대체해 프레임 낭비 방지) → 홈 색이 0.6~1초 동안 대조군 색에서 목표 계열 색으로 서서히 보간(트랜지션 곡선은 방울 수 비율에 비례).
  3. "기록" 버튼 클릭 시 해당 홈 위에 작은 색연필 아이콘이 잠깐 표시(색연필로 기록한다는 지도서 표현을 시각화).
- **색·모양 근거**: 점적병은 무색투명(1.2 준비물, 실제 용액 색), 붉은 양배추 용액병은 보라색(§1.4, sci-6-1-1-2와 동일 헥스), 홈 안 색은 §1.4의 세 범주 값을 보간해 표현(모형, 정밀한 중간색은 지도서에 없으므로 단정하지 않음). "모형" 배지를 3D 화면 상단에 항상 표시.
- **카메라**: `OrbitControls`, 1-포인터 드래그 회전, 핀치 확대/축소, 더블탭 초기 각도 복귀(시범 앱과 동일 규칙).

## 7. 공통 틀 확장 필요

**추가 확장은 필요 없다.** 이 차시는 `scripts/templates/science-sim/` 기존 기능만으로 구현 가능하다.
- `factors`/`phases`/`cellKey`/`observe`(`type: "choice"`)/`makeRecord`/`miniTable`은 README §3 (1) "색 관찰형" 패턴을 그대로 따른다(조건 축이 2개→1개로 단순화됐을 뿐, 구조는 동일).
- `TableChart`의 색상 매트릭스 렌더링(칩+글자)도 그대로 재사용 가능하다. 방울 수 증가 방향을 나타내는 화살표(§3.3 보충 아이디어)는 표 옆에 정적 아이콘/텍스트로 추가하면 되며, `table-chart.js` 자체를 고칠 필요는 없다.
- `sim3d.js`의 물체 팩토리(실린더=점적병, 평판=홈판)와 색 트랜지션 헬퍼도 탐구 2와 동일하게 재사용 가능하다.
- 굳이 개선하면 좋은 점(선택, 급하지 않음): 현재 `table-chart.js` 색상 매트릭스는 칩 배열 방향(행/열)에 화살표나 그러데이션 배경을 얹는 기능이 없다 — 이 차시는 없어도 되지만("→" 텍스트로 대체 가능), 앞으로 "농도·비율에 따라 점점 변하는" 차시가 more 있다면 매트릭스에 그러데이션 배경을 까는 옵션을 템플릿에 추가하는 것을 고려할 만하다(지금은 필수 아님, 구현하지 않음).

## 8. 열린 질문 (추천안 포함)

1. **중간 색 범주의 표현 방식** — §1.4처럼 "그 사이의 색(분홍·보라 등)"이라는 뭉뚱그린 범주로 관찰 보기를 3개만 둘지, 아니면 시범 앱처럼 정확한 색 이름을 더 세분화해서 보여줄지. **추천**: 지도서가 명시적으로 "정확한 색보다 전반적 경향"을 강조하므로(140, 144쪽) 3범주 안을 유지한다.
2. **0방울 칸을 "실험"으로 취급할지** — 0방울은 사실 시작 용액 그 자체(반대 용액을 넣지 않음)라 "넣기" 애니메이션이 없다. 이를 별도의 "관찰만 하는 대조군 카드"로 자동 완료 처리할지, 아니면 학생이 그래도 한 번 확인 버튼을 눌러야 기록되게 할지. **추천**: 학습 흐름의 일관성을 위해 0방울도 똑같이 "확인 → 기록" 버튼을 누르게 한다(자동 완료로 건너뛰면 진행률 계산이 헷갈릴 수 있음).
3. **25방울 칸의 목표 계열 단정 여부** — §1.4에서 25방울 칸을 대조군과 같은 계열(A=푸른색이나 노란색 계열, B=붉은색 계열)로 "정답" 처리하도록 설계했는데, 이는 "같은 몰 농도·25:10 비율이면 반대쪽이 우세해진다"는 화학적 추론(지도서 외)에 기반한다. 지도서에 이 비율의 최종 색이 명시돼 있지는 않다. **추천**: 141쪽 평가 문항 1이 정확히 이 상황(노란색 계열↔염산 다량 투입 후 붉은색 계열)을 다루므로 현재 설계를 유지하되, Review 단계에서 "다시 실험해 볼까요?" 재유도 문구가 학생을 막다른 골목에 몰지 않는지(0/25방울 외 칸은 정오 판정을 아예 안 하므로 문제 없음) 한 번 더 확인한다.
