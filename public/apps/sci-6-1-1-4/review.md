## 5. 확인한 것 vs 못 한 것

### 확인한 것 (헤드리스 Chrome 153 + CDP, `http://localhost:3000/class1/apps/sci-6-1-1-4/index.html`)
- **1024×768 전체 흐름**: 예상하기 잠금(토스트) → 힌트 3개 → 실험하기(3D 캔버스 1개) → B 잠금 토스트 → A 6칸·B 6칸 실행·기록. 칸마다 걸린 시간은 줄 준비를 포함한 첫 칸이 약 8초, 나머지는 4~5초. 견본 색 12개가 lesson-config pos와 일치했다. A25를 일부러 "붉은색 계열"로 기록 → 분석 표에 🔁 플래그와 "다시 확인해 보면 좋은 칸이 1개" 표시. 분석 4문항(오답 → 보기별 피드백 → 정답). 정리 3문항은 순서대로 열리고, 제출한 뒤에 모범 답안이 나옴. 궁금한 점을 적기 전에는 마치기가 막히고, 적은 뒤 마치기 → 비로그인 안내와 요약(12칸, 4/4, 학습 시간).
- **768×1024 세로 + 다크모드**: 실행 버튼이 3D 아래 604px에 있어도 누르면 3D가 머리말 바로 아래(top 127px)로 스크롤된다. 애니메이션 약 11.5초 동안 계속 화면 안에 있고 방울 카운터가 보였다. 가로 스크롤 없음(scrollWidth 768).
- **375×812(모바일 에뮬레이션, 터치 포인트 5, 다크)**: 예상하기·실험하기 scrollWidth 375, 오른쪽으로 넘치는 요소 없음. 실행하면 3D가 top 165px에 보이고, 관찰 카드가 이어서 나옴.
- **`?no3d=1`**: 캔버스 0, 2D 홈판, "3D를 쓸 수 없는 기기예요" 버튼 비활성, 2D에서 실행·카운터·기록 동작.
- **3D↔2D 40번 클릭(20회 왕복)**: 캔버스 1개, isContextLost=false, 경고 토스트 없음, 그 뒤 3D 실행 정상.
- **새로고침 복원**: 단계(analyze/experiment), 기록, 홈 상태, 퀴즈, 정리 복원. 현재 선택은 복원 안 됨(m3).
- **정적 경로**: 별도 정적 서버에서 `/class1/apps/sci-6-1-1-4/`(폴더 URL) → 로컬 js/css 17개 + CDN 3개 모두 200. "← 차시로" = `/class1/science/?term=6-1&unit=1&lesson=6`.
- **콘솔**: 모든 시나리오에서 오류·예외 0건.
- **보안/품질**: `innerHTML`·`insertAdjacentHTML`·`outerHTML` 사용 0건(학생 입력은 textContent, `SciSim.rich`는 DOM 생성). three.js·OrbitControls·supabase-js 모두 정확한 버전 + SRI(importmap integrity + modulepreload). config.js에는 anon key만 있음. 색만으로 전달하지 않기: 표 칸은 색 칩 + 글자, 관찰 카드에는 "색 구별이 어려우면" 변화표 ▲ 표시 + 글자, 퀴즈는 fieldset/legend + radio, 진행률은 role=progressbar, focus-visible 스타일 있음, prefers-reduced-motion 대응.
- **공통 틀 사본**: `diff -r scripts/templates/science-sim public/apps/sci-6-1-1-4/science-sim` 차이 없음(단 HEAD와는 다름, i2). `class1-record.js`도 정본과 같음.
- **지도서 대조**: 138~147쪽, 106쪽 텍스트 + 144·145쪽 그림(결과 예시·색깔 변화표). 탐구 2의 색 계열 표현(119·121·122·126·127쪽).

### 못 한 것
- 공유 Browser 패널에서 자기 탭 열기(탭 한도 오류). 그래서 헤드리스 Chrome으로 대신했고, 스크린숏은 직접 보고 확인했다.
- 실제 터치 기기에서 드래그·핀치·더블탭, iOS Safari WebGL(i4).
- 로그인한 상태에서 실제 저장(실 DB 쓰기 금지). 코드상 detail 구성과 크기만 확인했다.
- 3D 홈을 탭해서 고르기(레이캐스트)는 코드만 봤다.
- 테스트는 별도 Chrome 프로필에서 했으므로 사용자 브라우저의 localStorage에는 남긴 키가 없다. Chrome과 정적 서버는 종료했지만, 스크래치 폴더(`scratchpad/r4`, 테스트 프로필·스크린숏)는 삭제 권한이 거부되어 남아 있다.
