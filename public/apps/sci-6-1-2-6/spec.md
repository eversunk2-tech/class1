## 1. 지도서 분석

### 1.1 차시 개요 (지도서 232쪽)
- 학습 목표
  1. 속력과 관련된 안전 수칙과 안전장치를 설명할 수 있다.
  2. 속력과 관련된 안전 수칙과 안전장치를 조사하고 공유할 수 있다.
- 성취기준 `[6과10-03]` 속력과 관련된 안전 수칙과 안전장치를 조사한 결과를 공유하고 일상생활에서 교통안전을 실천할 수 있다. (지도서 181, 232, 237쪽 반복)
- **실험·측정 활동이 없다.** 지도서 232~241쪽 전체가 "조사해요 → 공유해요 → 정리하기"로 구성된 **조사 활동**이며, 준비물이 "개인별 스마트 기기" 하나뿐이다(1.2). 바로 앞 차시(6차시, 220~231쪽)는 스마트 기기로 속력을 **계산**하는 탐구였지만, 이 차시부터는 계산 없이 **조사·공유**로 바뀐다(단원 지도 계획, 184쪽). 다음 차시(9~10차시 "창의가 팡팡: 교통안전 실천 점검표 만들기", 242~247쪽)는 **점검표를 직접 만들어 실천을 점검**하는 별도 활동이므로, 이 앱에서 "점검표 만들기"를 미리 구현하거나 스포일링하지 않는다(§3.3, §8-3 참고).

### 1.2 준비물 (지도서 232쪽)
- 개인별: 스마트 기기.
- 모둠 준비물 없음 — 실험 시뮬레이션 앱이 아니라는 판단의 핵심 근거.
- 안전/윤리(232, 234, 236, 239, 241쪽): 스마트 기기 활용 조사 환경 사전 확인, 조사 전 **인터넷 사용 윤리** 지도, 학생 수준에 맞지 않거나 유해한 정보 주의, 믿을 만한 자료인지 확인하고 출처 밝히기, 공유 플랫폼에 **나와 다른 사람의 개인 정보를 함부로 올리지 않기**, 댓글은 **바르고 고운 말** 사용, 스마트 기기에서 열·냄새 발생 시 즉시 사용 중지 후 선생님께 알리기.

### 1.3 조사 활동 내용 (반드시 이 사실·예시만 사용)

**출처: 지도서 232~241쪽 / 교과서 48~51쪽 / 실험관찰 30~31쪽 원문**

#### (1) 도입 — 지그재그 차선 (지도서 234쪽)
- 질문: "지그재그로 그려진 차선의 의미는 무엇일까요?"
- 답(지도 길잡이, 234쪽): "'어린이 보호 구역 안 횡단보도 예고 표시'는 차선을 지그재그로 그려 운전자의 서행을 유도하는 표시이다. **착시 현상**을 이용한 것으로, 같은 너비의 도로라도 차선을 지그재그로 그리면 일직선보다 도로 폭이 좁아 보이기 때문에 운전자가 속력을 줄이게 된다."

#### (2) 속력이 빠를 때의 위험 상황 (지도서 234쪽 조사해요 1)
- 예시: 계단에서 뛰어다니면 다른 사람과 부딪히거나 넘어져 다칠 위험이 있다 / 자동차의 속력이 빠르면 위험한 상황에서 갑자기 속력을 줄일 수 없어 더 큰 사고가 날 수 있다.

#### (3) 속력과 관련된 안전 수칙 — 상황별 (지도서 234, 240쪽 실험관찰 정답·추가 예시 답안, 235쪽 정리하기)
| 상황 | 안전 수칙 |
|---|---|
| 계단을 오르내릴 때 | 뛰지 않고 걸어서 오르내린다 |
| 자동차를 운전할 때(어린이 보호 구역) | 정해진 속력보다 천천히 운전한다 |
| 자동계단을 이용할 때 | 손잡이를 잡고 서서 이용한다 |
| 자전거를 탈 때 | 보호 장비를 착용하고 적당한 속력으로 탄다 |
| 횡단보도에서 신호를 기다릴 때 | 인도에서 기다린다 (240쪽 추가 예시 답안) |
| 골목에서 나올 때 | 잠깐 멈추고 좌우를 살핀다 (240쪽 추가 예시 답안) |
| 길을 걸을 때 | 스마트 기기를 보지 않고 주위를 살핀다 (235쪽 정리하기) |
| 횡단보도를 건널 때 | 자전거나 킥보드 등에서 내려서, 좌우를 살피며 천천히 건넌다 (232, 235쪽) |

#### (4) 속력과 관련된 안전장치 — 기능별 (지도서 233·235·241쪽 실험관찰 정답표)
| 안전장치 | 설치 위치 | 기능 |
|---|---|---|
| 차간 거리 유지 장치 | 자동차 | 자동차의 속력을 조절해 앞차가 갑자기 정지했을 때 속력을 줄일 수 있는 안전거리를 유지하게 한다 |
| 에어백 | 자동차 | 자동차가 빠른 속력으로 충돌할 때 공기주머니를 부풀려 탑승자가 받는 충격을 줄여 준다 |
| 안전띠 | 자동차 | 자동차가 충돌하거나 갑자기 멈출 때 탑승자를 자동차의 좌석에 고정해 준다 |
| 자동 긴급 제동 장치 | 자동차 | 자동차가 충돌할 위험이 있을 때 자동차의 속력을 줄여 자동차가 멈출 수 있도록 도와준다 (235쪽 지도 길잡이 4) |
| 과속 경보 시스템 | 도로 | 자동차의 속력을 실시간으로 측정하여 운전자에게 알려 준다(운전자가 스스로 속력을 줄이도록 돕는다) |
| 과속 방지턱 | 도로 | 운전자가 자동차의 속력을 줄이도록 유도한다 |
| 안전 울타리 | 도로 | 속력이 빠른 자동차 등이 충돌했을 때 충격을 흡수하고 보행자를 보호한다 |

- 233쪽 학생면 그림(과학 51쪽)에 안전띠·에어백·안전 울타리·과속 경보 시스템 4개가 나오고, 234~235쪽 조사해요/공유해요 지도 길잡이에서 차간 거리 유지 장치·과속 방지턱·자동 긴급 제동 장치가 추가된다. 앱은 이 7개 밖의 안전장치를 "정답"으로 만들지 않는다(학생이 새로 조사해 오는 것은 자유 기록).

#### (5) 공유해요 (지도서 232, 235쪽)
1. 모둠원이 조사한 내용을 살펴보고 비슷한 것끼리 모아 공유 플랫폼에 올려 공유(사용법은 과학 114쪽 참고 — 지도서 원문 인용, 이 앱에서 재현하지 않음).
2. 다른 모둠이 공유한 내용을 읽고 새롭게 알게 된 점을 댓글로 달기 — 지도서 예시: "길을 걸을 때 스마트 기기를 보지 않고 주위를 살펴야 한다는 것의 중요성을 알게 되었습니다." / "에어백, 안전띠, 과속 방지턱과 같은 속력과 관련된 안전장치가 다양하다는 것을 알게 되었습니다."(235쪽)
3. 댓글 예절: "나와 다른 사람의 개인 정보를 누리망에 함부로 올리지 않고, 댓글을 달 때는 바르고 고운 말을 사용해요."(232, 241쪽)

#### (6) 정리하기 (지도서 235쪽, 교과서 50~51쪽 그림 설명)
- 속력이 빠른 물체는 바로 멈추기 어려워 안전사고가 발생할 위험이 더 커진다.
- 안전사고를 예방하려면 ① 안전 수칙을 잘 지키고 ② 자동차·도로에 안전장치를 설치해야 한다. 일상생활에서 교통안전 수칙을 실천하면 안전사고를 줄일 수 있다.

#### (7) 형성평가 문항 소재 (지도서 236쪽, 각색해 사용 — §3.4)
1. 자동차가 충돌·급정지할 때 탑승자를 좌석에 고정해 주는 안전장치 → 안전띠.
2. 안전장치 설명 중 옳지 않은 것 고르기: "안전 울타리는 자동차의 속력을 실시간으로 측정하여 알려 준다"(옳지 않음 — 이는 과속 경보 시스템의 기능. 에어백·차간 거리 유지 장치 설명은 옳음).
3. 자동계단 이용 상황에서 지켜야 할 안전 수칙 서술(손잡이를 잡고 서서 이용).
4. 빈칸: "속력이 빠를수록 안전사고의 위험이 커지므로 자동차나 도로에는 ( 안전장치 )을/를 설치합니다."
5. 비·눈이 내리는 날의 안전 수칙: "자동차가 미끄러질 수 있으므로 자동차가 완전히 멈춘 것을 확인하고 횡단보도를 건넌다 / 운전자는 더 느린 속력으로 운전한다."(236쪽)

#### (8) 보충 자료 — 배경지식 (지도서 238~239쪽, 교사용 참고. 정확한 값이므로 "지도서 근거"로 인용하되 §1.6처럼 표현을 순화)
- **제동 거리**(238쪽): 브레이크를 밟은 뒤 자동차가 완전히 멈출 때까지 움직인 거리. 자동차의 속력이 빠를수록, 도로가 미끄러울수록(비·눈) 제동 거리가 길어진다. 지도서 표 값(마른 노면/빙판길, 자료 출처 한국교통안전공단): 30 km/h → 1.5 m/10.7 m, 50 km/h → 4.6 m/33.2 m, 60 km/h → 10.1 m/49.9 m.
- **어린이 보호 구역**(238쪽): 교통사고 위험으로부터 어린이를 보호하기 위해 도로교통법에 따라 지정된 구역. 속도 제한 표지판, 단속 카메라, 과속 방지턱 등이 설치되고 주정차가 전면 금지된다.
- **보행자 우선 도로**(238쪽): 차도·보도가 분리되지 않은 도로에서 보행자 통행이 우선하도록 지정한 도로. 운전자는 보행자 옆을 지날 때 안전거리를 두고 **20 km/h 이하로 서행**해야 한다.
- **에어백 작동 원리**(239쪽, 초등 수준으로 순화): 충돌 센서가 충격을 감지하면 기계 팽창 장치가 작동해 매우 짧은 시간에 에어백에 기체가 채워져 부풀어 오르며 탑승자의 충격을 줄여 준다.
- **안전거리**(239쪽, 도로교통법 제19조): 도로교통공단은 일반 도로에서 "주행 속도에서 15를 뺀 값(m)"만큼의 안전거리를 확보하도록 권고한다. 차간 거리 유지 장치가 이를 돕는다.

### 1.4 지도상 유의점
- 단원 전체(182쪽): 조사 활동이 필요한 학습 요소는 모둠별 협동 학습 활용 가능. 조사 결과는 발표하거나 사회 관계망 서비스 등에 올려 학급에서 공유. 교통안전을 **꾸준히 실천하는 습관 형성**에 주안점.
- 이 차시(232~236쪽): 컴퓨터실·스마트 교실 활용 가능, 학교안전지원시스템·한국도로교통공단 교통안전 교육센터 등 도움되는 누리집 소개, 검색 방법·공유 플랫폼 사용법 사전 지도, 조사 전 인터넷 사용 윤리 지도, 발표·공유 과정에서 경청·공감하는 태도로 의사소통·협업 능력 함양, **물체의 속력이 생활에 긍정적 영향뿐 아니라 부정적 영향(사고 위험)도 줄 수 있음**을 알게 한다(233쪽).
- 평가(232, 237쪽): 구술·발표, 자기 평가·동료 평가. 협동 학습 역량 평가 기준(241쪽): 의사소통 능력, 협업 능력, 비판적 사고력.

### 1.5 다루지 않는 개념 / 오개념 주의
- 이 차시 범위(232~241쪽)에는 별도 "오개념" 박스가 없다.
- 단원 지도상의 유의점(182쪽): "속력의 산술적 계산이나 단위 변환보다는 속력의 의미 이해와 정량적 표현·소통에 중점"을 둔다 — 이는 4~6차시(속력 계산)의 원칙이지만, 이 차시에도 제동 거리·안전거리 수치(§1.3-(8))를 **계산 문제로 만들지 않는다**(정성적 설명으로만 제시, §3.2·§8-2).
- 단원 배경지식(183쪽)의 "이동 거리와 변위", "속력과 속도(스칼라·벡터)", "순간 속력과 평균 속력"은 **교사용 심화 배경지식**이며 이 단원(6학년) 학습 요소가 아니다. 화면에 "속도", "변위", "스칼라/벡터", "순간 속력/평균 속력" 같은 용어를 넣지 않는다.
- 자동차 안전장치의 정밀한 작동 원리(센서 회로, 물리 공식)는 다루지 않는다. 에어백 원리는 §1.3-(8) 수준까지만 순화해 "더 알아보기"로만 제시한다(핵심 조사 활동에는 넣지 않음).

### 1.6 지도서 외 배경지식
- 없음. 이 spec의 모든 사실·수치·용어는 지도서 180~241쪽 안에서만 가져왔다. 화면에 지도서 밖 사실을 넣을 경우 "지도서 외"로 표시한다(현재 계획에는 없음).

## 8. 열린 질문 (추천안 포함)

1. **정리 틀 ①(안전 수칙)·②(안전장치)의 최소 행 수를 몇 개로 할지?**
   추천: 각 4행(안전 수칙은 지도서가 상황 4가지를 제시하고, 안전장치는 자동차·도로 각 1개 이상을 포함해 4행). 최종 숫자는 config 값이라 쉽게 바꿀 수 있다.
2. **제동 거리·안전거리(도로교통법 15 뺀 값) 수치를 조사 활동 소재로 넣을지, "더 알아보기"로만 둘지?**
   추천: **"더 알아보기"로만** 둔다(§3.2 tips.items, §3.4 발전 질문 2는 계산 없이 정성적 설명만 요구). 단원 지도상의 유의점(182쪽)이 "속력의 산술적 계산보다 의미 이해"를 강조하고, 이 차시는 계산 차시가 아니므로 "주행 속도 − 15 = 안전거리(m)" 같은 계산 문제는 만들지 않는다.
3. **발표 준비 단계의 체크리스트가 다음 차시(9~10차시)의 "교통안전 실천 점검표 만들기"와 겹칠 위험?**
   추천: 겹치지 않도록 이 앱의 체크리스트는 "발표 하나를 준비할 때 확인할 점"(1회성, 3문항)으로 짧게 두고, 지속적으로 실천을 기록하는 "점검표" 형태(날짜별 체크, 항목 목록 만들기 등)는 절대 만들지 않는다. Build 단계에서 이 경계를 지킨다.
4. **"학교안전지원시스템"을 조사 팁의 클릭 가능한 링크로 넣을지?**
   추천: **아니오.** 지도서 학생면(232, 240쪽)에 이름만 나오고 URL이 없다(공식 URL을 추정해 넣지 않는다 — "지도서 값만" 원칙, §1.4·§4). 넣고 싶다면 이름만 텍스트로 언급하고 "선생님이 알려 주시는 주소로 찾아봐요" 정도로 안내한다. 이번 spec의 config에는 넣지 않았다.
5. **정리 틀 ②(안전장치)의 `mineField`(설치 위치) 오분류 표시가 학생에게 "틀렸다"는 인상을 줄 수 있는데, 문구 톤을 어떻게 할지?**
   추천: worksheet.js의 기본 문구("⚠ ○○이 달라요")를 그대로 쓰되 `diffText`를 "설치 위치를 지도서 예시와 다시 비교해 보세요."처럼 재확인을 유도하는 톤으로 둔다(채점이 아니라 다시 생각해 보라는 안내, §3.2에 이미 반영).

## 9. 앞선 조사형 앱에서 반복하지 않을 점 (sci-6-1-1-5 review.md 대조)

- **도입 힌트가 답을 누설하는 문제(6-1-1-5 review D1) 재발 방지**: §3.1 힌트 2개 모두 "비교해 보라"는 관점만 주고, "착시 현상", "서행", "도로 폭이 좁아 보인다" 같은 정답 표현을 넣지 않았다. 정답은 조사하기 단계의 참고 자료 카드(§3.2 카드 A)에서만 공개한다.
- **정리(결론) 모범 답안이 지도서 정리의 축을 빠뜨리는 문제(6-1-1-5 review D2) 재발 방지**: §3.4 결론은 지도서 235쪽 정리하기의 두 축(① 안전 수칙 지키기 ② 안전장치 설치)을 모두 담았다.
- **학생의 잘못된 분류를 긍정 표시로 되돌려 주는 문제(6-1-1-5 review M1) 재발 방지**: 정리 틀 ②에 `mineField: "place"`를 적용해, 안전장치 이름은 맞아도 설치 위치(자동차/도로)를 잘못 골랐으면 ✔ 대신 "⚠ 설치 위치가 달라요"를 보여준다(§3.2, §8-5).
- **발전 질문이 분석 질문·피드백과 겹치는 문제(6-1-1-3 review D2/m5) 재발 방지**: 퀴즈(3문항)는 안전장치 이름·기능·빈칸 채우기를 다루고, 발전 질문 1(비·눈 오는 날)과 발전 질문 2(안전거리를 넓혀야 하는 까닭)는 퀴즈·공유 단계에서 다루지 않은 새 소재(제동 거리 적용)로 배분했다(§3.4).
- **다음 차시 스포일링 금지**: "교통안전 실천 점검표 만들기"(9~10차시)의 핵심 산출물(점검표)을 이 앱에서 미리 만들지 않는다(§1.1, §3.3, §8-3).
- **공통 틀 알려진 버그(science-guide README "고친 기록") 재발 금지**: 375px 가로 스크롤(topic-picker, 이번 앱은 topic-picker 미사용), `fixed` 틀 완료 문구, 제출 전 글 반영, 잠긴 단계 ✓ 표시 — 모두 2026-09 수정 1차가 반영된 정본을 그대로 복사해 쓰면 재발하지 않는다. Build 단계에서 정본 버전(수정 1차 포함)을 복사했는지 확인한다.
