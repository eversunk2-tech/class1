## 2. spec과 다른 점

1. **정리 틀 ②의 칸 이름 "설치 위치" → "설치된 곳"**: `worksheet.js`가 불일치 문구를 "⚠ ○○**이** 달라요"로 붙여 "설치 위치이 달라요"가 되기 때문(틀 수정 금지). 비교 표 머리글도 "설치된 곳"으로 맞춤. 표시는 "⚠ 설치된 곳이 달라요".
2. **"더 알아보기: 제동 거리" 카드에서 "도로가 미끄러울수록" 부분을 뺐다**: 조사하기에 그대로 두면 발전 질문 2(미끄러운 도로에서 거리를 더 두는 까닭)의 답을 미리 알려 주게 된다(리뷰 반복 문제 "발전 질문이 앞 내용과 겹침"). 카드는 뜻 + "속력이 빠를수록 길어져요"만 두고, 미끄러운 도로·자전거/킥보드 빙판길 내용(238쪽)은 발전 질문 2 모범 답안·비교 팁에서 보여 준다. 수치 표는 넣지 않음.
3. **도입 힌트 2 문구 순화**: spec의 "도로 폭이 좁아 보이면 …"은 힌트 1의 답(좁아 보인다)을 전제로 말해 버려서, "도로가 넓게/좁게 느껴질 때 운전자는 어떻게 운전하게 될까요? 이런 차선이 주로 어디에 있는지도 떠올려 보세요"로 바꿨다. 힌트마다 [질문 1]/[질문 2] 머리를 붙였다.
4. **참고 자료 카드 1장 추가**: "속력이 빠를 때의 위험 상황(예)"(234쪽 조사해요 1 예시 2개). 도입 질문 2와 비교할 곳이 없어서 넣었다. 카드는 도입 두 질문을 다 적어야 열린다.
5. **에듀넷 안내**: spec의 "'물체의 운동'·'속력' 검색"(183쪽) 대신 이 차시 쪽인 233쪽의 "'안전띠', '안전벨트' 검색"을 썼다.
6. 결론 모범 답안은 232쪽 학생면 요약과 235쪽 정리 1·2 문장에 더 가깝게(예: 횡단보도 좌우 살피기, 안전띠·과속 방지턱) 다듬고, 세 축 비교 팁을 붙였다. 발전 질문 1은 "보행자와 운전자로 나누어"를 덧붙였다(모범 답안이 두 축이라서).
7. **저장 키**: `refcard-open`, `worksheet-rule`, `worksheet-device`, `share`, `quiz`, `step`은 spec대로다. 도입·결론은 공통 모듈의 고정 키(`predict`/`hints`, `conclude`)를 쓴다(틀 수정 금지). 접두사는 `sci6126guide:v1`.
8. 발표 준비의 예시는 지도서가 "댓글"로 제시하므로(235쪽) 제목을 "다른 모둠이 단 댓글 예시"로 했다. 체크리스트는 발표 전 3문항 한 번만(점검표 아님).

## 3. 확인한 것

dev 서버 `http://localhost:3000/class1/apps/sci-6-1-2-6/index.html`, 내 탭 하나(tab-18)만 사용.

- 전체 흐름: 도입 미입력 → 다음 단계 막힘(토스트), 참고 자료 카드 잠김 → 입력 뒤 열림 / 정리 틀 ①은 4줄로 통과, ②는 자동차만 4줄이면 "도로에 설치된 안전장치를…" 안내로 막힘 / 비교 표: "안전 울타리(자동차)" → "⚠ 설치된 곳이 달라요" + 표 아래 경고, 지도서에 없는 "과속 카메라"는 "더 찾았어요"로 표시 / 발표 요약에 ⚠ 표시, 알게 된 점 제출 전에는 막힘 / 퀴즈 3문항 오답·정답 피드백, 확인 전에는 결론 잠김 / 결론·발전 1·2 순서대로 공개 / 궁금한 점 미입력이면 마치기 막힘 / 가짜 `Class1Record.save`로 저장: detail 1,200자(rules, devices, placeDiffers, comparedWithModel, share, quiz 선택 글·정답·시도 수, conclusion, extension, curiosity), 마침 카드 "처음 고른 답으로 맞힌 문제 0개".
- 새로고침 복원(단계·마침 카드). 조사하기로 돌아가 ②를 자동차만으로 바꾸면 뒤 단계가 `is-locked`(✓ 없음), 비교 표 접힘 → 고치면 복귀.
- 처음부터 다시: `sci6126guide:v1:*`만 지워짐(다른 키 보존).
- 375×812, 768×1024(다크), 1024×768 다섯 단계 모두 `scrollWidth` = 뷰포트. 375px에서 보이는 버튼·입력 높이 모두 40px 이상. 다크 배경 `rgb(17,22,31)`.
