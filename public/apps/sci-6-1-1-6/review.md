## 5. 확인한 것 vs 못 한 것

**확인한 것** (개발 서버 `http://localhost:3000/class1/apps/sci-6-1-1-6/index.html`, 내 탭만 사용, 끝난 뒤 탭 닫고 뷰포트 되돌림, `sci611guide6:*` 키 모두 삭제)
- 전체 흐름 끝까지: 도입 질문 → 힌트 3단계 → 개념 카드·주제 고르기(해양 산성화) → 조사 팁·검색어 칩·누리집 → 정리 틀(미완성 잠김 → 완성 시 사실 카드 + 탄산 칼슘 카드) → 초안 만들기(학생 글 그대로 들어감)·알게 된 점 → 빈칸 → 보기 오답/정답 피드백 → 서술형·발전·결론 순서 공개 → 궁금한 점(빈칸이면 마치기 막힘) → 마치기(비로그인 문구, 가짜 로그인 save 호출 detail 확인).
- 게이트: 앞 단계 미완성 시 다음 단계·진행바 이동 모두 막힘. 조사하기 칸을 비우면 뒤 단계로 못 감.
- 주제 바꾸기(확인 → 조사·공유만 지워지고 새 주제 검색어로 바뀜, 정리하기는 남음), 새로고침 복원, 처음부터 다시 하기.
- 가로 스크롤: 375×812, 768×1024, 1024×768 다섯 단계 모두 scrollWidth = clientWidth. 정본 topic-picker 결함은 앱 보완을 끄면 546px로 재현(D2).
- 다크모드(1024×768, 768×1024): 배경·글자·카드 색이 다크 토큰으로 바뀌고 읽기에 문제 없음.
- 콘솔 오류 0건, 리소스 로드 실패 0건.
- 지도서 PDF 106~107, 130~139(검색), 156~165쪽 원문 대조.

**못 한 것**
- 실제 태블릿 터치·Safari, 실제 로그인 후 저장과 RLS(실 DB 쓰기 금지), 정적 빌드(`out/`)로 연 확인(out/에 이 앱이 아직 없음 — 대신 dev 서버의 `/class1/apps/sci-6-1-1-6/` 경로에서 모든 자원이 상대경로로 200 로드됨을 확인).
- 클립보드 복사 결과 붙여 넣기(백그라운드 탭이라 권한 확인 불가).
- 학습 시간(activeSec): 백그라운드 탭에서는 `document.hidden`이라 0초로 셈 — 설계대로 동작, 실제 앞에 띄운 화면에서의 초 수는 확인 못 함.
- 스크린샷은 뷰포트 캡처가 일부 비어 나와 레이아웃은 치수 측정과 텍스트로 확인했다.
- "← 차시로" 대상 페이지와 차시 화면에서 앱 연결(Embed 단계 전).
