## 2. spec과 다른 점
- **쪽수 표기**: spec은 보충 자료(산성비·토양·해양 산성화)를 160쪽, 해양 산성화 실험을 161쪽이라 했지만 PDF 대조 결과(인쇄 쪽 = PDF 쪽 + 103) 실험·차시 평가가 160쪽, 보충 자료가 161쪽이다. 화면 출처는 실제 쪽수로 적었다. 국가환경교육 통합플랫폼은 164쪽(9~10차시)에 나온다.
- **발표 대본 템플릿**: spec 문장형("○○은/는 △△ 때문에 생기고…")에 학생 문장을 끼우면 "녹아서 때문에"처럼 어색해져, "제가 조사한 주제는 {주제}입니다. 먼저 원인입니다. {원인}. 다음은 피해입니다. …이 내용은 {출처}에서 찾았습니다." 발표 틀로 바꿨다(학생이 다듬는 것은 같음).
- **공유해요-2 추가**: spec 3.3에는 없지만 지도서 탐구 과정(§1.3-7)과 평가(가치·태도)에 있는 "새롭게 알게 된 점"을 넣었다. 지도서 158쪽 산성비 모둠 공유 예시(원인/현황/대책) → 적고 제출 → 지도서 158쪽 예시 답 비교.
- **정리 순서**: 빈칸(산성화) → 보기 2문항(지도서 159쪽 ㉠ 산성비, ㉡ 토양 산성화 둘 다 문항으로) → 서술형(염기성 물질) → 발전 → 결론. 공통 틀 구조(퀴즈를 다 확인하면 서술형 공개)에 맞춰 spec 순서(빈칸→서술형→보기→발전→결론)를 조금 바꿨다. 결론 모범 답안은 지도서 159쪽 정리 문구(원인/현황 및 전망/대책 + 탄산 칼슘)를 그대로 썼다.
- **빈칸 채우기 저장**: Conclude 모듈을 하나 더 쓰느라 하위 저장소(`sci611guide6:v1:fill:*`)를 쓴다(처음부터 다시 하기에서 함께 지워짐). 그 밖의 키: `predict`·`hints`, `topic`, `research`, `refOpen`, `share`, `quiz`, `conclude`, `curiosity`, `step`, `meta`(spec 예시 키 이름과 다름, 동작 같음).
- 주제를 바꾸면 확인 후 `research`·`refOpen`·`share`를 지우고 새로고침(정리하기·궁금한 점은 주제와 무관해 남김).
