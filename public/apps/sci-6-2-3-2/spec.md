# spec.md — sci-6-2-3-2 (전기의 이용 · 탐구 2)

차시: 6학년 2학기 3단원 "전기의 이용" 탐구 2 "전기 회로에 전지 한 개를 더 연결하면 어떻게 될까?"
교과서 62~63쪽 · 실험관찰 38~39쪽 · 지도서 인쇄 274~283쪽(PDF `[과학]623_지도서 3.전기의 이용.pdf` 21~30쪽, 인쇄=PDF+253, PDF 5쪽 "단원 지도 계획" 표에서 확인함).
적용 기준: 2026-09-22 새 기준(7분 이내).

## 1. 지도서 분석

* **학습 목표**: 전지 한 개를 연결한 전기 회로와 전지 두 개를 직렬연결한 전기 회로의 특징을 비교할 수 있다. (지도서 274쪽)
* **성취기준** [6과15-02] (지도서 277쪽)
* **준비물**(모둠): 전지(1.5V) 3개, 전지 끼우개 3개, 전구(3.0V) 2개, 전구 끼우개 2개, 집게 달린 전선 여러 개, 스위치 2개, 전동기(3.0V) 2개, 버저(3.0V) 2개 / (개인) 면장갑 (지도서 274쪽, 실험관찰 38쪽)
* **실험 내용**(실험관찰 38~39쪽):
  1. 전지 한 개를 연결한 전기 회로와 전지 두 개를 직렬연결한 전기 회로를 각각 만들고 스위치를 닫아 **전구의 밝기**를 비교한다. (실험관찰 학생용 표기는 `＞, ＝, ＜` 부등호 선택이며 정답은 "＜" — 전지 1개 회로 < 전지 2개 직렬 회로)
  2. 두 회로에서 전구 대신 **전동기**, **버저**를 각각 연결하고 스위치를 닫아 모습을 비교한다.
* **측정·관찰 결과(지도서 예시, 정확한 값)**:
  | 부품 | 전지 한 개를 연결한 전기 회로 | 전지 두 개를 직렬연결한 전기 회로 |
  |---|---|---|
  | 전구 | 어둡다(밝기가 약하다) | 밝다(밝기가 더 밝다) |
  | 전동기 | 날개가 느리게 회전한다 | 날개가 빠르게 회전한다 |
  | 버저 | 소리가 작다 | 소리가 크다 |

  (지도서 275쪽 "실험해요"·280쪽 실험관찰 정답, 부등호 예시는 실험관찰 38쪽)
* **정리 문장(모범답안, 지도서 276·280쪽)**: "전지 한 개를 연결한 전기 회로보다 전지 두 개를 직렬연결한 전기 회로에서 전구의 밝기가 더 밝고, 전동기에 달린 날개가 더 빠르게 회전하고, 버저에서 더 큰 소리가 난다."
* **전지의 직렬연결 방법**: 한 전지의 (+)극을 다른 전지의 (-)극에 연결한다(지도서 274·282쪽, 실험관찰 38쪽 "실험하는 동안"). 지도서는 **직렬연결만** 다루고 병렬연결은 다루지 않는다(274쪽 "전지의 연결은 직렬연결만 다룬다").
* **버저 연결**: 빨간색 전선은 전지의 (+)극 쪽, 검은색 전선은 (-)극 쪽 (지도서 275·279쪽).
* **지도상 유의점**: 두 회로를 동시에 만들어 동시에 스위치를 눌러 비교하게 한다(275쪽). 전동기는 날개가 회전할 수 있도록 세워진 상태로 연결한다(275쪽).
* **안전**(275·279쪽): 젖은 손으로 실험하지 않는다 / 전구가 깨지지 않도록 조심한다 / 전동기 날개에 손가락이 닿지 않도록 주의한다 / 버저 소리를 들을 때 귀를 너무 가까이 하지 않는다.
* **오개념(276쪽)**: "전기 회로에 연결된 전지의 개수가 많아지면 항상 전구의 밝기가 더 밝아진다" → 바로잡기: "전지의 개수가 같아도 연결 방법(직렬/병렬)에 따라 밝기가 다르다. 더 밝게 하려면 직렬연결해야 한다." → **병렬연결은 실험으로 측정하지 않았으므로(위 "직렬연결만 다룬다" 참고) 이 앱에서는 오개념을 다루되 병렬 값은 제시하지 않는다**(구체적 판단은 §10 참고).
* **차시 예고(283쪽)**: 다음 차시는 전자석 — **스포일러 금지**, 이 앱에서 "전자석" 언급하지 않는다.
* **평가 서술형 예시답(277쪽)**: "전기 회로에 직렬연결한 전지의 개수가 많아질수록 전구의 밝기가 밝아진다." → 정리하기 모범답안과 일치하는 방향으로 참고.

## 2. 앱 종류 판단

**실험 시뮬레이션 앱.** 지도서 274~277쪽에 실험(전구·전동기·버저 비교) 활동이 명시되어 있고, 이미 3단원 탐구 1(`sci-6-2-3-1`, 전구 회로)과 같은 형식으로 이어진다. 조사 차시가 아니다.

## 3. 화면 설계

### 예상하기 (탐구형 질문 1개)
* 질문: "전기 회로에 전지를 한 개 더 연결하면 전구의 밝기는 어떻게 달라질까요? 그렇게 생각한 까닭도 함께 써 보세요." (직렬연결이라는 용어는 아직 쓰지 않는다 — 새 용어이므로 실험하기에서 소개)
* 힌트(2단계, 답 말하지 않음):
  1. "리모컨처럼 전지를 두 개 넣어 쓰는 물건을 떠올려 보세요."
  2. "전지를 하나 더 연결하면 전기 회로에 전달되는 힘이 어떻게 달라질지 생각해 보세요."
* 최소 글자 수 5자.

### 실험하기
* **도입**: "전지 두 개를 연결할 때 한 전지의 (＋)극을 다른 전지의 (－)극에 연결하는 것을 **전지의 직렬연결**이라고 해요." + 안전 안내 카드(젖은 손 금지 / 전구 깨짐 주의 / 전동기 날개 주의 / 버저 소리 너무 가까이 X). "모형" 배지: 이 화면의 밝기·회전·소리는 실제 실험을 본떠 만든 모형입니다.
* **조건(factor 1개)**: 부품 고르기 — 전구 / 전동기 / 버저 (3개, phase A/B/C).
* **각 phase(부품)의 cell(2개, factor 없이 phase 내부에서 회로 2종 모두 표시·기록)**: "전지 한 개를 연결한 전기 회로" / "전지 두 개를 직렬연결한 전기 회로" — 총 3부품 × 2회로 = **6칸**(실험관찰 38~39쪽에 제시된 조건 전부, 임의로 줄이지 않음). 같은 칸 반복 측정 없음(회로마다 1회).
* **3D 장면**: 회로판(브레드보드 느낌의 판) 위에 전지 끼우개(선택한 회로에 따라 전지 1개 또는 2개, 극 표시 + / − 명확히), 집게 달린 전선, 스위치, 그리고 선택한 부품(전구/전동기/버저)을 소켓에 꽂은 모습. 드래그로 회전 가능.
* **실행**: "▶ 스위치 닫기" → 스위치가 닫히는 애니메이션 → 부품 반응(§7). 애니메이션은 2초 내외로 짧게(길게 기다리는 연출 없음 → "빨리 감기" 불필요).
* **관찰(observe, type: choice)**: 부품별로 다른 2지선다
  * 전구(phase A): "어둡다" / "밝다"
  * 전동기(phase B): "느리게 회전한다" / "빠르게 회전한다"
  * 버저(phase C): "소리가 작다" / "소리가 크다"
* 관찰 후 "기록하기"로 저장. 실험은 언제든 다시 할 수 있다.

### 기록·분석하기
* **표**: 부품(행) × 회로 종류(열) 관찰 결과 매트릭스(3행×2열, `TableChart.renderMatrix` 활용 — 수치가 아니므로 선·막대그래프 대신 표 사용, 색 관찰형 6-1-1-2와 동일한 방식).
* **보기 고르기 2개**(학생 자신의 기록을 보고 답함):
  1. "내가 기록한 결과를 보면, 전지를 한 개 더 직렬연결했을 때 전구·전동기·버저는 모두 어떻게 되었나요?" → ① 셋 다 더 세게 나타났다(전구 더 밝게, 전동기 더 빠르게, 버저 더 크게) / ② 셋 다 변화 없었다 / ③ 부품마다 다르게 나타났다. 정답 ①.
     * 오답 피드백(②): "내 기록표를 다시 확인해 보세요. 전지를 두 개 직렬연결했을 때 그대로인 부품이 있었나요?"
     * 오답 피드백(③): "세 부품의 기록을 다시 비교해 보세요. 세 부품 모두 같은 방향으로 바뀌었어요."
  2. "전지 두 개를 직렬연결할 때는 두 전지를 어떻게 연결해야 하나요?" → ① 한 전지의 (+)극을 다른 전지의 (-)극에 연결한다 / ② 두 전지의 (+)극끼리 연결한다 / ③ 아무 극이나 연결해도 된다. 정답 ①.

### 정리하기 (탐구형 질문 1개, 발전 질문 없음)
* 질문: "전지 한 개를 연결한 전기 회로와 전지 두 개를 직렬연결한 전기 회로는 어떤 점이 다른가요? 내가 관찰한 내용을 바탕으로 써 보세요."
* 모범답안: "전지 한 개를 연결한 전기 회로보다 전지 두 개를 직렬연결한 전기 회로에서 전구의 밝기가 더 밝고, 전동기에 달린 날개가 더 빠르게 회전하고, 버저에서 더 큰 소리가 난다."

### 궁금한 점 (선택, 한 줄)
* "전기 회로에 대해 더 궁금한 점이 있나요? (선택)"

## 7. 3D 장면 스케치

* **판**: 나무 색 회로판(넓은 사각 베이스) 위에 부품 배치. 카메라 초기 시점은 비스듬히 위(약 40~50도)에서 내려다보는 각도, 드래그로 자유 회전(`Sim3D` 기본 컨트롤).
* **전지 끼우개**: `circuit=single`이면 전지 끼우개 1개(전지 1개, (+)/(−) 극 색·기호 표시), `circuit=series2`이면 전지 끼우개 2개를 나란히 배치하고 집게 전선으로 앞 전지의 (−)극과 뒤 전지의 (+)극을 잇는 모습(직렬연결 시각화). 새 회로를 고르면 짧은 전환 애니메이션(전지 개수 변화)으로 보여준다.
* **전선·스위치**: 색이 있는 전선(빨강/검정)으로 전지 → 스위치 → 부품 → 전지로 이어지는 고리. 스위치는 레버 형태, 실행 시 딸깍 닫히는 애니메이션(0.3초).
* **부품별 반응**(스위치 닫힌 뒤 1.5~2초 애니메이션, 이후 정지 상태 유지 = `showInstant`로 복원 가능):
  * **전구**: 필라멘트 발광 색·halo 반경으로 밝기 표현 — 전지 1개는 옅은 주황 halo(작게), 전지 2개 직렬은 밝은 노랑 halo(크게). 화면에 "모형: 실제 밝기(럭스) 수치가 아니에요" 배지.
  * **전동기**: 프로펠러(날개) 회전 애니메이션 — 전지 1개는 느린 각속도, 전지 2개 직렬은 빠른 각속도(+회전 잔상선으로 속도감 표현).
  * **버저**: 원판 부품이 미세하게 진동 + 소리 파동 고리(ring)가 퍼져나가는 애니메이션 — 전지 1개는 옅고 느리게 퍼지는 고리 1~2개, 전지 2개 직렬은 진하고 빠르게 퍼지는 고리 3~4개. 소리는 재생하지 않는다(모형, 무음).
* **2D 대체(`?no3d=1` 또는 WebGL 실패 시)**: 위 요소를 단순 아이콘·SVG로 표현(전지 개수 아이콘, 전구/전동기/버저 아이콘 + 밝기·속도·소리 막대 게이지)로 같은 정보를 전달.

3. **전구/전동기/버저 3부품을 모두 3D로 만들지, 전구만 3D로 정교하게 만들고 전동기·버저는 2D 카드로 단순화할지** — 추천: 셋 다 3D로(간단한 프리미티브 조합이라 구현 부담이 크지 않고, 이미 유사한 회로 3D를 탐구 1 `sci-6-2-3-1`에서 만들었으면 재사용 가능). 시간이 부족하면 버저만 2D 카드(진동 아이콘 + 게이지)로 단순화하는 대안도 가능.
