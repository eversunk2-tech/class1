## 5. 확인한 것 vs 못 한 것

### 확인한 것
- **지도서 대조**: 106, 110~117쪽 추출문과 lesson-config.js의 값·문구를 한 줄씩 대조했다(2절).
- **전체 흐름** (dev 서버 `http://localhost:3000/class1/apps/sci-6-1-1-1/index.html`, 내 탭만 사용): 예상하기(힌트 1·2) → 실험하기(식초 투명도·빨랫비누 물 거품은 UI로, 나머지는 DOM 클릭 자동화로 23칸 기록, 식초 색깔은 일부러 '무색'으로 오기록) → 분석 표 🔁 1칸 표시 → 🔁 누르면 실험하기로 가서 식초 × 색깔 선택 → 다시 기록하면 표시가 사라짐 → 기준 고르기(예쁜가 포함 → wrongBy / 냄새 빠뜨림 → missBy / 정답) → 라운드 1 오답(식초를 불투명으로) → 정답 → 라운드 2 정답 → 비교 문구(S1) → 정리하기 3문항 → 궁금한 점 → 학습 마치기(비로그인 안내).
- **묽은 염산 × 냄새**: 실행 버튼 비활성("🚫 안전을 위해 냄새를 맡지 않아요"), 안내 카드와 "왜 그럴까요?", 미니 표 🚫, 진행률 23칸, 분석 표 흐린 칸 "관찰하지 않음(안전)".
- **3D 모습**(800px): 식초 병이 글씨 종이 앞에서 노란빛인데 "가"가 비쳐 보임. 병 이름표가 잘림(m5).
- **저장 payload**: `Class1Record.save`를 잠시 가짜로 바꿔 받은 값은 2,574자, detail 키 8개. 확인 뒤 원래대로 되돌렸다. 실제 네트워크 저장은 하지 않았다.
- **XSS**: 예상하기에 `<img src=x onerror=alert(1)>`, 결론에 `<script>alert(1)</script>`를 넣었다. 둘 다 글자로만 표시되었고 문서에 img 요소 0개, 경고창 없음. 앱 코드에 innerHTML 사용 없음(persist.js `rich`도 DOM으로 만듦).
- **CDN SRI**: three.module.js·OrbitControls.js는 importmap integrity와 modulepreload integrity가 모두 있다. supabase-js@2.116.0에도 integrity와 crossorigin이 있다.
- **새로고침 복원**: 마친 상태에서 새로고침하면 궁금한 점 단계, 5단계 모두 '완료', 결론 3칸, 라운드 결과, 마친 카드가 그대로 남음.
- **휴대폰 375×812**: 5단계 모두 `scrollWidth = 375`, 가로 넘침 없음.
- **태블릿 세로 768×1024**: 실행 전 3D로 스크롤하는 동작이 있음(캔버스 top -657 → -36). 탭이 숨김 상태여서 재생 시간은 측정 못 함(i6).
- **3D↔2D 30번 전환**(375px): 캔버스 1개, 오버레이 1개, WebGL 컨텍스트 살아 있음, 콘솔 메시지 0.
- **`?no3d=1`**: 캔버스 0개, 버튼 "3D를 쓸 수 없는 기기예요"(비활성). 2D에서 빨랫비누 물 × 투명도를 실행하면 캡션 "용액에 가려서 뒤에 있는 글씨가 보이지 않아요", 관찰 카드 정상.
- **다크모드**: 배경 rgb(17,22,31), 글자 rgb(232,237,244), 카드·표·분류 칩 모두 어두운 배경 + 밝은 글자.
- **정적 경로**: 임시 정적 서버(`/class1/apps/` → public/apps 심볼릭 링크, 포트 8793)에서 `/class1/apps/sci-6-1-1-1/`(index.html 없이)를 열었다. 모든 자원이 로드되었고 실패 요청 0, "← 차시로"는 `/class1/science/?term=6-1&unit=1&lesson=2`로 풀림. science-curriculum.ts의 6-1 단원 1 `id: "2"`와 일치. 서버는 종료했다.
- **접근성**: textarea 6개 모두 label 연결, 선택 버튼 `aria-pressed`, 미니 표 칸 aria-label("식초, 🎨 색깔, 아직 기록 안 함"), 분류 탭 role=tab + 방향키, 표는 색 칩 + 아이콘 + 글자로 색만으로 전달하지 않음.
- **정리**: 테스트로 만든 `sci611sim1:*` 키는 localhost:3000과 127.0.0.1:8793 두 출처에서 모두 지웠다(다른 앱 키는 건드리지 않음). 뷰포트·색 모드를 되돌리고 내 탭을 닫았다. 임시 심볼릭 링크를 지웠다.
