## spec.md 구성
1. **지도서 분석**(쪽수 근거): 차시 목표, 활동/실험 내용, 준비물, 관찰 결과(정확한 값·색·현상), 지도상 유의점, 오개념, 평가.
2. **앱 종류 판단**: 실험 시뮬레이션(sim) / 조사 도우미(guide) 중 무엇인지와 근거. 실험이 있으면 sim, 실험 없이 조사 활동이면 guide.
3. **화면 설계**
   * sim: 예상하기(질문·힌트, 답 누설 금지) → 실험하기(3D 장면 구성, 조작, 조건 변화로 다각적 실험·측정, 기록 항목) → 기록·분석하기(표/그래프, 보기 고르기 분석 질문·정답·피드백) → 정리하기(결론 모범 답안, 발전 질문 1~2개와 모범 답안) → 더 탐구하고 싶은 점.
   * guide: 조사 주제 안내, 지도서 기반 조사 참고 자료(학생 수준의 사실 정리, 신뢰할 만한 출처 유형 — 특정 URL은 지도서에 있는 것만), 조사 팁(검색어 예시, 출처 확인, 정리 방법), 조사 결과 정리 틀(학생 입력), 공유/발표 준비, 정리 질문과 모범 답안, 더 탐구하고 싶은 점. 규칙의 단계 정신(학생이 직접 쓰고 나서 모범 답안 비교)을 살린다.
4. **과학적 정확성 체크리스트**: 앱에 들어갈 모든 사실을 지도서 쪽수와 함께. 지도서에 없는 사실은 일반 과학 지식으로 검증 가능한 것만, "지도서 외" 표시.
5. **config 초안**: 공통 틀 config 형식에 맞춘 주요 데이터(질문, 힌트, 조건, 결과표, 분석 문항, 모범 답안).
6. **3D 장면 스케치**(sim): 물체 목록, 배치, 애니메이션, 색·모양 근거.
7. **공통 틀 확장 필요**(있으면).
8. **열린 질문**(추천안 포함).
