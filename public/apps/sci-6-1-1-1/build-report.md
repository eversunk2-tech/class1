## 2. 화면 흐름 요약

- **예상하기**: spec 3.1 질문 2개(5글자 이상), 힌트 3단계. 답 제시 없음.
- **실험하기**: "관찰하는 방법 알아 두기" 카드(흰 종이/글씨 쓰인 종이/5초/손으로 바람 — 113·116쪽) → 용액 × 관찰 방법 선택 → 실행 → 관찰 카드(보기 고르기) → 기록. 23칸(24 − 묽은 염산 냄새).
  - 색깔: 병이 흰 종이 앞으로 이동 → 낮은 시점, 살짝 기울임. 관찰 카드에 종이 앞 병 모형 + "색 이름 보기".
  - 투명한 정도: 병이 "가" 종이 앞으로(글씨는 병 너비보다 작게, 112쪽) → 낮은 시점. 투명하면 글씨가 비치고 불투명(레몬즙·빨랫비누 물)이면 가려짐 + 글로도 안내.
  - 흔들어 보기: 0.8초 흔들기 → 실제 5초 카운트다운 → 빨랫비누 물만 거품이 남음(나머지는 약 1초 만에 사라짐).
  - 냄새 맡아 보기: 손 부채질 아이콘 2.6초. **묽은 염산**은 실행 버튼 비활성 + 빨간 안전 안내 카드("왜 그럴까요?" 한 줄 포함, 열린 질문 2 추천안), 미니 표 🚫.
- **기록·분석하기**: 관찰 결과 표(색깔 칸만 색 칩, 나머지 아이콘+글자, 묽은 염산 냄새 "🚫 관찰하지 않음(안전)"), 지도서 값과 다르면 🔁 "다시 관찰해 볼까요?" → 그 칸으로 이동. 분류 기준 고르기(다중 선택, 예쁜가? 오답 피드백, 냄새 정답+묽은 염산 제외 안내). 두 기준(투명한가? / 흔든 뒤 5초 이상 거품이 유지되는가?) 라운드 분류, 다 맞히면 "친구들과 비교해 보기"(114쪽 정리해요) 문구.
- **정리하기**: 결론·발전 1(겉보기 성질의 한계)·발전 2(투명≠무색 오개념) — 모범 답안은 spec 문장 그대로.
- **궁금한 점** → 학습 마치기(비로그인 안내 / 로그인 시 저장).

## 3. spec과 다른 점

- 용액 id를 spec 예시(`빨랫비누물` 등 공백 없음) 대신 이름 그대로(`빨랫비누 물`) 썼다(시범 앱과 같은 방식, 기록이 읽기 쉬움).
- 기록 형식은 spec대로 `{ solution, method, result, recordedAt }`. 저장 detail에 `skipped`(묽은 염산 냄새, 까닭)와 `classify: { transparent, foam }`(라운드별)를 넣었다.
- 레몬즙·빨랫비누 물의 모형 opacity를 spec 초안(0.85/0.95)보다 높여(0.97/0.98, 화면에서는 완전히 가림) 불투명 용액 뒤의 글씨가 희미하게라도 비치지 않게 했다(모형 값, 과학 값 아님).
- 3D 거품은 흰 빨랫비누 물 위에서 보이도록 하늘빛이 도는 흰색으로 그렸다(모형).
- 분류 기준 고르기 문항에서 빠뜨린 정답 보기별 도움말(`missBy`)을 추가했다(틀 확장, 아래 4절).
- 참고: spec은 "색깔이 있는가?" 분류표를 "지도서 외"로 적었지만, 실험관찰 117쪽 예시 답안에 같은 분류(그렇다: 식초·레몬즙·빨랫비누 물 / 그렇지 않다: 석회수·묽은 염산·묽은 수산화 나트륨 용액)가 실려 있다. 앱은 이 기준을 분류 라운드로 쓰지 않으므로(spec대로 투명도·거품 2라운드) 값에는 영향 없음. spec 정정은 사용자 몫.
- 산성·염기성·지시약·pH·중성·중화: 화면 문구에 없음(파일 검색으로 확인).

## 6. 못 한 것 / 알려진 제한

- 실제 태블릿 터치(한 손가락 회전·핀치·더블탭, 분류 칩 끌어다 놓기)는 확인 못 함(분류는 탭 방식으로 확인, 끌기는 기존 틀 코드 그대로).
- 공유 브라우저 창이라 다른 에이전트가 탭을 앞으로 가져가면 내 탭이 숨김 상태가 되어 애니메이션이 즉시 끝났다(틀의 의도된 동작). 애니메이션 실제 시간은 내 탭을 앞에 둔 동안 측정했다.
- `npm run build`는 다른 에이전트의 `next dev`/빌드와 `.next`를 함께 쓸 수 있어 돌리지 않았다(앱은 정적 파일만이라 빌드 영향 없음).
- 3D 라벨 글자가 휴대폰에서 작고, 가까운 관찰 시점에서 병 이름표가 화면 위로 잘릴 수 있다(관찰 카드에 용액 이름이 항상 있음).
- `science-curriculum.ts` 연결(앱 경로)은 Embed 단계 몫이라 하지 않았다.
